# 中期报告实验章节初稿：单常值偏差增广的模型适用边界

为检验已知单链路常值偏差增广方法的适用范围，在既有六时刻双车XY确认实验之后设计了独立扩展压力测试。该设计参考了既有结果，但协议在本批新观测生成前冻结，不能追溯宣称为早先预登记。实验保持原测距/位移噪声、survey初值、位置先验与P0/P1求解标准不变，仅改变故障注入。

实验包含good、weak、near三种几何，static、turn两种运动，两类预定候选链，以及无偏差、单常值、阶跃、线性渐变、候选选错和双链路偏差六种注入，共72条件。100个新seed在各条件间预定配对，每条件比较独立B0、协同B1、仅估预定单常值的B2及完整真实偏差补偿的B3_full_oracle。后者掌握完整逐测量故障，是离线理想参照而非可部署方法。

共完成7200配对输入、28800方法运行，全部有限最终估计进入主统计；28419次数值接受，367次未驻点、14次达到P1预算。独立读回57600阶段，残差、Jacobian、梯度和误差重算一致。发生一次外部进程终止，仅恢复两个未持久化阶段及尚未执行任务，不重算已保存失败，不按误差选择结果。

在正确候选且恒定+.3m的12条件中，两车共24个B2−B1逐seed配对MSE的95%逐项区间均为负，支持既有条件性收益。无新增偏差时则有11个逐车区间为正，其余跨零，说明增广并非无代价。阶跃与渐变中，各有23/24个相对B1区间为负，但单常数不能表示时间变化；weak/static/peer的B2平均位置RMSE分别约.251/.249m和.213/.212m，而单常值时约.123/.121m。其平均b也不等于注入均值，不能把它直接解释为唯一真实故障参数。

候选选错时，Car1的12个B2−B1区间有10个为正。wrong_link和multi_link各出现501个Car1 RMSE>.5m的B2结果，分别有478和486个已经满足数值接受。weak/static/wall错误候选条件甚至100/100接受但Car1平均RMSE约.866m。多链路相对B1仍可能改善，却不代表恢复正确状态；额外链路偏差超出单偏差模型表达范围。

完整残差—误差联合分布显示，数值接受和较低的条件内残差秩都不足以保证位置准确。预定秩差规则选出的near/static/peer错误候选案例中，Car1 RMSE约.625m处于99.5百分位，残差仅处于2.5百分位。该案例没有通过事后挑选残差阈值定义；指定seed和全部条件统计同时呈现。

这些结果说明，正确单常值模型内的收益不能自动外推到未知链路、时变或多故障场景。数值未收敛与目标失配是两个独立问题，应同时报告。独立统计单位为seed，逐项bootstrap区间不作家族保证；.5m/.1m仅离线诊断。六时刻简化仿真不能替代长期跟踪、实车性能或保护级验证，也不支持HMI风险保证。
