# 中期报告补充章节：独立噪声失配探索

在完成扩展故障压力测试后，另设72条件、每条件50个新观测种子的噪声探索，共14400次方法运行。该批单独在观测生成前冻结，不能与前批合称统一的事前登记实验。实际测距噪声分别为独立Gaussian（标准差0.04m）、独立Gaussian（0.08m）和链路内AR(1)（rho=0.7，平稳边缘标准差0.04m）；估计器始终采用独立0.04m的噪声假设。AR首项取平稳分布，创新标准差为0.04√(1−0.7²)。所有其他模型、初值、先验和求解规则固定。

全部最终估计有限；14047次满足数值接受标准，333次未驻点、20次达到P1预算。主误差统计保留所有有限结果。与同批iid004按seed配对，B2及只校正偏差的oracle各自48项逐车MSE差区间，在iid008和AR1情况下均为正。区间为固定10000次重采样得到的95%逐项区间，互相关联且不具有家族保证。

在弱几何、静止、peer、无偏差条件中，B2的Car1平均RMSE由iid004的0.1554m增至iid008的0.2176m和AR1的0.2042m；95百分位从0.3134m增至0.4530m和0.4236m。与此同时，AR1平均白化残差RMS由0.7818下降到0.7069。这说明相关噪声可使状态误差增加而拟合残差降低。B2在两类噪声失配中出现的12行Car1 RMSE大于0.5m结果全部满足数值标准；这些行跨条件共享seed，不能作为12个独立风险样本。

正式数据通过不调用优化器的独立读回和压缩证据复核。保存的输入、状态、配置及Jacobian重建信息可支持未来独立设计的覆盖率研究。本实验不计算HMI、不构造保护级；六时刻AR(1)仅作为相关噪声的初步探索，不能代表长期实测相关结构或实车性能。
