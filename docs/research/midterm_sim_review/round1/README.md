## 月面下一步已核验的部分

对于每个正常历元、每辆车，选四维证书中两个确定可行叶盒的逐车投影角点。若它们相距 d，任何包含两点的圆都须满足半径 ≥ d/2。使用有理数比较距离平方，每行保存两个叶 ID、角点及平方距离，可复现。这 8 项下界为 12.93–18.79 cm，全部超过 10 cm。在这些固定观测与模型允许的范围内，即使继续加密网格并更换发布圆心，也无法把所有可行位置包进 10 cm。该下界描述模型允许的位置集合，车辆实际误差另由轨迹真值计算。[证书端点与逐项结果](moon/moon_certified_radius.csv) · [复算程序](moon/moon_certified_radius.py)

从仓库根目录执行以下命令。地面脚本会校验每份输入的 SHA-256，月面脚本会校验四份细网格证书及发布点表。月面完整读回还需要 #146 README 指定的早期 Git 对象。

## 下一轮执行顺序与停点

1. 方法 A 先用开发轨迹冻结检验拒绝时的传播、连续拒绝、恢复以及过期规则。记录每次所用观测的最晚接收时刻、求解完成时刻和车辆首次收到决定的时刻。在故障开发轨迹核对一次拒绝及回退，在正常轨迹核对一次接受，再对两个既有留出种子的四个场景作配对回放。配置冻结前保留开发结果与选参依据。
2. 地面 B 将相同事件程序扩到车间阶跃和渐变解除。按车、场景、种子报告首次越限、报警、恢复以及到时仍越限且可用的事件数；把过期后失去位置单列。一条正常轨迹和一条带解除的轨迹逐行回读后，再把方法 A 纳入相同车辆时钟。
