# C2 地面留出轨迹的告警时间核验

两条留出噪声实现（2026111901、2026111902），分别回放正常与 Car1 四锚 +0.30 m 的共同偏差条件，考察两辆车的解分离方法 B2。在 [#143 固定提交](https://github.com/phyllis-TANG/uwb-coop-localization-ros1/tree/01e588021e7e3ddd918b1d1fc9561973373758c6) 归档上重构 FIFO 决定到达顺序、状态有效期、车辆当前显示的位置，并逐行用当前仿真天线真值核验。每车每段 64 s，每 50 ms 评价一次，共 8 个车轨迹、10,240 行。独立噪声实现仍只有两条。

[事件规则来源 #145](https://github.com/phyllis-TANG/uwb-coop-localization-ros1/blob/d3b39fa9003519f70aef4abfdd050fc969a4a513/tools/ground_b_round1/review.py)。误差首次可观察地超过 0.10 m 开始一个事件，直至再观察到误差 ≤ 0.10 m 或记录截止。期间无位置保留事件号，误差未知。起点可以是已报警、尚无声明或声明可用。按车辆表第一次显示 ALARM 的采样计时，已处于报警状态的起点记 0 s。不同车及同次运行内的事件存在相关性。

|全轨迹场景|事件数（起点可用）|1/2/5 s 内已显示报警|1/2/5 s 期限点仍越限且可用|
|---|---:|---:|---:|
|正常|99（94）|0 / 0 / 0|5 / 4 / 0|
|共同墙偏差|64（56）|3 / 3 / 5|7 / 5 / 0|

1、2、5 s 为三个研究示例 TTA，均从事件首个可观察越限采样起算。原 2 s 是带时标位置的有效期。全轨迹墙场景分母包括注入前及解除后的事件。期限点计数与整个事件累计暴露时长回答不同问题。已经恢复、截止时无有效位置、可见位置被停用、记录提前截止均单列。每个事件和每个 TTA 只属于一个类别，依次判断“已显示报警”“已观测恢复”“记录截尾”，其余按期限点的状态分为“无位置”“仍越限且可用”“仍越限且已停用”。一个事件可包含多次可用状态切换，此表不衡量每次报警后重新发布的风险。

|墙故障窗 [24,38) s|种子 2026111901|种子 2026111902|
|---|---|---|
|Car1，首次可观察越限→显示报警|26.85→31.15 s（4.30 s）|27.65→30.15 s（2.50 s）|
|Car2，首次可观察越限|36.10 s 时已显示报警|36.10 s 时已显示报警|

[summary.csv](results/summary.csv) 有 24 行（8 条车轨迹 × 3 档 TTA），列出每类事件、暴露时间及可用时间。[events_by_tta.csv](results/events_by_tta.csv) 有 489 行（163 个事件 × 3），其中 available_exceed_s 是该事件全部已观察到“越限且可用”的时长，按 TTA 重复显示。[wall_window.csv](results/wall_window.csv) 的 4 行单独针对注入窗口；Car2 的 0 s 表示首次可见越限时已经处于报警状态。

## 复现

Python 3.8 或以上，仅需标准库。工作区中如已有冻结的归档，程序直接读取并验证所有 12 个文件的 SHA-256。文件不在当前检出目录时，程序以 git show 读取 #143 固定提交下的同路径本地 Git 对象，支持在不同分支运行。若只有较浅的主分支克隆，应先取得 #143 的固定对象。本程序不下载数据。发现工作副本的哈希不匹配会停止。输入在仓库根目录的 docs/research/ground_continuous_b/runs 下，[source_sha256.txt](source_sha256.txt) 列出每个相对路径及预期哈希。

从本说明所在目录运行，用实际仓库路径替换 path/to/repo，--out 指向新的输出目录。原始归档只读，新目录生成三份表。

    python3 -B -m unittest -v test_replay_tta
    python3 replay_tta.py --repo path/to/repo --out ./reproduced
    diff -ru results reproduced

复核包含按归档 FIFO 服务时间重构 10,240 个车辆时刻，并检查车号、方法、AL、状态戳、接收时刻、声明、显示位置及其相对仿真真值的误差；误差容差为 1e-12 m。单元测试覆盖跨过期空档、在到期时收到报警、起点已报警、恢复到 AL 等号、无有效声明以及右截尾。三个结果表已与调用 #145 原 episodes 实现生成的 24、489、4 行对照逐字段匹配。复验使用留出归档和原记录的服务时间，无需重跑定位求解器。
