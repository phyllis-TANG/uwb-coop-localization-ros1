# 决策备忘

当前不应把sigma=.05m称为平台实测先验精度，也不应依据本实验调强先验作为部署改进。固定错误中心产生明显均值偏移，单报随机协方差或H逆遗漏这一项。

1. **优先梳理已归档测量依据。** 将参考点定义、坐标原点、工具/校准说明、同点重复读数、时间/姿态及天线-底盘-odom映射分开关联。11月停车点记录确实存在，但1–2cm为自报估计；不要用不同停止位置作重复测量。此建议不要求本轮重新现场采集，也不改历史记录。
2. **研究确定偏移项与随机波动分开的不确定性表达。** 在明确假设中心集合下传播方向偏移，与随机噪声协方差并列。先声明半径无实际标定依据，不命名为HCPL或保护级，不把固定偏移包装成零均值Gaussian。
3. **补充弱几何的非线性余项/分支证据。** 精确H在小扰动优于GN，但5cm跨车效应及既有大survey偏移仍有失准；现有证据不能将残差曲率、有限停止和分支变化全部分离。后续应给出局部范围条件及不可用判据，不能以本轮结果反向选有利方向或调权。

因此是“测量来源解释优先，偏移与非线性表达并行”，不是现在选一个新在线定位算法。实际可信先验半径、外参/锚点相关误差及跨分支非线性界仍缺证据。
