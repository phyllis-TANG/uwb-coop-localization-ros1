# 固定中心偏移的局部传播

状态 x=(p₀₁x,p₀₁y,p₀₂x,p₀₂y,…,p₅₂y[,b])ᵀ，24或25维，单位 m。E=[I₄ 0]，c=(Car1 X,Y,Car2 X,Y)ᵀ 为首时刻位置先验中心，δc∈R⁴，单位 m。正扰动意味着先验中心坐标增大，不是残差观测加号。

原白化残差 r=[r_d;r_p]，r_p=(Ex−c)/σp；测距 residual=(预测距离[+b]−观测)/.04，运动 residual=(相邻状态位移−带噪全局位移)/.02。目标 F=½rᵀr，J=∂r/∂x。B0 不包含 peer，B2 仅 peer 增广自由常值 b。原权重与目标不变。

## GN 与精确局部导数

g=∇F=Jᵀr，∂g/∂c=−Eᵀ/σp²。在线性仿射模型中，中心扰动等价于残差右侧增加 [0;δc/σp]，故

δx_GN=T_GN δc，T_GN=(JᵀJ)⁻¹Eᵀ/σp²。

式中 T 为无量纲，映射 m→m，亦包含 B2 的 b 偏移。实现用物理状态尺度相似变换求解，不改变公式、不加正则。独立 `lstsq(J,[0;δc/σp])` 验证符号和恒等式。

若 x*(c) 是光滑、孤立的驻点分支、测距距离非零，且精确 Hessian H 可逆，则隐函数定理给出

dx*/dc = T_exact = H⁻¹Eᵀ/σp²；H=JᵀJ+Σᵢrᵢ∇²rᵢ。

局部极小还需适当的二阶条件；本实现只在尺度 H 数值正定时给出预测。记录基准物理梯度和是否数值接受；梯度很小并不证明唯一全局极小，换分支不受该导数约束。对距离 d=||v||，u=v/d，有 ∇²d=(I−uuᵀ)/d；anchor 用对应车的2×2块，peer 用 L=[−I I] 的 LᵀQL，Q=(I−uuᵀ)/(dσrange)。b、运动和先验残差均线性，二阶项为零。以中心差分梯度独立复核完整 H，中心差分 c 复核负号。

端点 GN/精确 H 使用当前估计点；真值 GN 使用仿真真实位置及 B2 真 b=.3。真值通常不是当前带噪目标驻点，其 T 仅是理想一阶仿射参照，不是当前估计器的精确导数。真值不能用来部署选权、选初值或选结果。

## 固定偏移不是随机协方差

在指定线性模型中，误差 e≈K_d ε_d+T δc，加上其他漏建模项。固定未知 δc 贡献确定均值 μ=Tδc，随机协方差 C_d=K_d Cov(ε_d)K_dᵀ；二阶矩 E[eeᵀ]=C_d+μμᵀ，不能把 μμᵀ叫中心协方差，不能把未知固定偏移假定零均值。

若另有独立、零均值随机先验中心误差 η_c，才可加 T Cov(η_c)Tᵀ。当所有白化观测及先验都符合单位独立噪声假设且线性模型正确时，曲率逆 H_GN⁻¹才与包含随机先验波动的协方差吻合。固定先验只传播测距/运动随机性，不包含先验行的随机噪声。精确非线性局部噪声传播使用 H_exact⁻¹∂g/∂ε，亦不能普遍直接用 H_exact⁻¹当协方差。PR108/109 的均值、随机传播与曲率逆区别在此保持。

## 两车提取与假设集合

F_{t,i} 选取第 t 时刻第 i 车 XY，则 δp_{t,i}=F_{t,i}Tδc。指定单位方向 a、假设中心欧氏球 ||δc||₂≤ρ，有 |aᵀδp|≤ρ||TᵀFᵀa||₂；二维范数≤ρ||FT||₂。将六时刻块叠为 F_i，则 RMS 位移≤ρ||F_iT||₂/√6。本轮ρ=.05m仅是指定四维集合下的局部一阶敏感性；坐标逐分量5cm盒不是同一集合。单方向+.05m实验不能验证整个球的非线性上界。

没有实测半径依据、全局非线性余项控制或风险分配，不称 HCPL、保护级或安全界。锚点坐标误差与安装外参误差需各自额外扰动 Jacobian；不能把它们替换成同一个 c 误差，测距常偏也不能直接当作位置先验中心偏移。
