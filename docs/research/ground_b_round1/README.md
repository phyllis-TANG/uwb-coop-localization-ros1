**原协议复算。** 在固定故障窗内，从注入开始到首次显示报警是 7.15 s，从首次可观察越限到首次显示报警是 4.30 s。若以归档的连续就绪时刻为终点，则分别为 7.104746670 s 和 4.254746670 s。两组值来自同一决定，差别是车辆 50 ms 采样。实际车载通信、调度时延尚待实测。旧 episodes.csv 按连续可观察片段计数，首片段为 [26.85,27.05)，其间未收到报警；旧 WINDOW_DELAY.csv 按整个 [24,38) 故障窗读取到 31.15 s 的报警。

**本轮事件规则。** 从任意可见位置首次满足误差 > AL 的使用时刻开始，包括有启动预测但没有声明可用的时刻，单列起点声明。下一次观测到误差 ≤ AL 时结束，恢复行属于事件外。中途缺位置保留事件编号，误差记未知，单列过期和后续重新可用；未知时长不计入已观察越限时长。跨缺口仅是会计规则，不能证明期间真实误差始终越限。到记录截止尚无恢复观测时标记 CENSORED。首次实际收到报警、决定就绪时刻、首次撤销可用与首次过期各有独立字段；事件内无告警时 alarm_received=False，时刻留空。故障事件合并到 [26.85,46.10)，其中 34 个无位置采样（1.70 s）、168 个越限且可用采样（8.40 s）。2 s 是带状态戳结果的有效期，实验没有设定允许告警时间 TTA。

## 复现

从本 PR 根目录运行。读数据与事件评价只需 Python 3 标准库。临时结果可与提交内容逐字节比较。

```sh
out=$(mktemp -d)
python3 tools/ground_b_round1/review.py --out "$out"
diff -qr "$out" docs/research/ground_b_round1/evaluation
(cd docs/research/ground_b_round1 && sha256sum -c SHA256SUMS)
```

重新从生成器提取传感器时使用 #143 的 Python 3.10、numpy 2.2.6、scipy 1.15.3 环境，在独立工作树执行 `python tools/ground_b_round1/export.py`。该命令只写本轮 runtime 下的两个数据文件。旧数据路径相对仓库根目录为 docs/research/ground_continuous_b。本轮运行的真实路径是 /home/ubuntu22/ground-b-round1，旧工作树 /home/ubuntu22/ground-cont-b 只读。
