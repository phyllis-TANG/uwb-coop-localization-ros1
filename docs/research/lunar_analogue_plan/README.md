# 月面类比协同定位研究方案

版本：v1.0（2026-11-17）

正文：[PLAN_ZH.md](PLAN_ZH.md)

本目录提供实施方案，尚未执行其中新增实验。目标是将自有双车实测与定位、不确定性分析接入可追溯的月面类比场景，并明确开源资产、实测依据和研究假设的分工。

## 推进顺序

1. 从现有资产重建来源链，检查高差量级及几何敏感性。
2. 整理实测角色与车辆参数，验收定位接口及真值隔离。
3. 冻结协议后开展小规模配对定位与经验覆盖对照。
4. 运行条件具备后加入基础接触动力学，逐步检查驱动、碰撞和实际滑移。

正文包含输入、阶段出口、方法对照、开发与确认批次、统计口径及中期报告交付范围。准确高度和已知故障候选须作为理想参照单列；经验覆盖不等同于完好性风险保证。月壤陷沉及土壤剪切模型属于后续研究。
