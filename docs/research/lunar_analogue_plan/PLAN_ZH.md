# 月面类比场景下双车协同定位研究实施方案

研究题目：Safety Quantification for Multi-Agent Cooperative Localization in Lunar Exploration

版本：v1.0　日期：2026年11月17日　状态：实施方案，尚未执行新增实验

本方案将已有双车实测、定位与不确定性分析接入月面类比场景。我们复用开源地形和物理引擎，保留自有测距数据、校准与摆位分析，先完成可追溯的受控定位案例，再加入接近实验车辆的基础接触动力学。中期目标是说明方法的适用条件及失效边界；真实月面性能和完好性风险保证仍需后续证据。

文档开发基准为 db45d94d03061e6828afb25d841c2b1777d0af48；此前已审查研究与月面代码基准为 e28fda7361e79c7970bbd34fb680448c6a131617。新基准增加了C端技术初稿。本次只提交方案，不修改求解器、原始数据或已有结论，不启动下述实验。

## 一 研究问题与预期贡献

核心问题是：当地形高差、运动观测误差和测距偏差共同存在时，协同定位何时改善每辆车的位置估计，何时低估不确定性，以及这种失准与哪类模型假设有关。

本方案提出三个待检验问题。Q1关注忽略或固定高差是否产生有意义的测距均值失配，以及单一常偏差能否解释随几何变化的误差。Q2关注运动信息退化时，车间测距是否帮助退化车辆，是否将误差传给另一辆车。Q3关注误差下降是否同时伴随合理覆盖，或仍存在区间过窄、先验偏移和弱几何问题。

已有实测中的per-robot cooperative benefit、校准及摆位效应构成问题依据。新增贡献候选是地形与运动退化下的失效机制、先验和噪声依据可追溯的评估设计，以及经独立验证的不确定性改进。场景搭建、开源模型移植和增加试验次数本身不作为算法创新。具体新方法需等待A/B诊断审查，并完成近邻文献比较后再确定。

| 定位和不确定性代码 | 基线、偏差增广、配对评估及后续改进 | 冻结来源；保留失败与全部计划分母 |

自有数据首先保留为独立实测证据。只有具备足够参考信息的记录，才能用于估计相应误差。例如静态可靠参考可支持测距偏移与波动分析；动态残差可能混合运动、同步、坐标和定位误差，不能直接全部归为传感器噪声。

参数选择、校准和验证按完整采集记录划分。建立每份记录的角色清单，并检查既有论文或方法开发是否已使用该记录。已经看过的数据不能再次称为完全盲测；不足以独立留出时，采用明确标注的跨记录分析或只做探索性诊断。

地面实测启发的噪声条件与纯假设条件分别报告。地面人体遮挡偏差不等同于月面岩石传播，室内里程计误差也不能直接作为月壤打滑参数。不把同一段实测误差复制到多个seed后计作独立实测重复。

## 四 车辆模型与参数依据

近期采用与自有底盘驱动形式相符的简化车辆。核实轮型与转向方式后再选模型，不预设为差速、阿克曼或全向底盘。优先复用关节及碰撞结构，按可确认记录设置轮径、轮距、轴距、尺寸、质量与天线位置。JPL等公开rover只作为候选参考，本方案不指定六轮构型，也不承诺其参数适用于本车。

| 参数组 | 必查内容 | 依据和缺项处理 |
| --- | --- | --- |
| 本体几何 | 驱动形式、轮径、轮距、轴距、车体尺寸 | 实车规格或已有记录；缺失则待确认 |
| 质量与惯性 | 总质量、各刚体质量、质心、惯量 | 测量或公开模型；几何计算明确密度和质量分配假设 |
| 天线外参 | 车体到天线的平移和姿态约定 | 统一显示、测距及评价点；不能重复叠加杆臂 |
| 接触材料 | 静摩擦、动摩擦、恢复系数、组合规则 | 文献或模型来源；未标定值作为敏感性参数 |
| 关节与驱动 | 轴向、限位、阻尼、控制增益、速度与力矩限幅 | 公开配置或硬件规格；防止无限驱动力掩盖滑移 |
| 数值设置 | 时间步、子步、接触容差、求解迭代 | 属于数值设置；需检查稳定性和时间步敏感性 |

建立参数登记表，字段为参数名、数值、单位、坐标系、来源URL或文件、版本、适用对象、修改理由、状态及敏感性范围。状态分为已有测量或规格支持、公开模型值、计算假设、待确认。表中未知值保持待确认，不填无依据的月面摩擦系数。

质量、轮径和驱动力矩应来自一致车辆配置。改尺寸后需复核惯量与碰撞形状；直接缩放外观不能视为完成动力学缩放。基础接触只用于模拟刚性地面上的接触和滑移，月壤沉陷、颗粒运动与土壤剪切暂列后续研究。

## 五 数据接口与真值隔离

采用三类逻辑隔离的数据：reference保存生成与评价真值、故障标签；measurements保存算法可见观测及其时间、坐标和假设；estimates保存定位结果、协方差或候选区间、数值分类和代价。评价程序才允许同时读取三者。初始化、权重选择和候选选择不得读取评价误差。

天线位置统一定义为 p_a = p_b + R_b l_ba。若暂时只保留世界z方向加高，就明确为简化约定，不宣称已建完整姿态杆臂模型。每条测距记录两端天线身份、模拟采样时间和收发方向。双向测距是否共享噪声、偏差或通信过程必须写明；不默认它们完全独立。

运动观测与参考位置分开。早期可由参考轨迹生成带规定误差的增量，但必须称合成运动观测。全局XY增量不能称轮编码器或IMU。动力学阶段再由轮转角与明确的运动学模型生成里程计，并与仿真真实位姿比较。仿真状态作为评价真值，不经/odom直接供给待测方法。

月面桥接先选择一个后端，保持旧代码只读。优先评估能输出状态、雅可比和既有不确定性统计的中期后端；若仍用六时刻模型，则从场景提取预先规定的短窗口，并声明其全局增量和先验假设。不得将17.59秒回放称为已完成长时在线估计。

早期绝对位置案例使用配置中明确指定的固定信标与起始先验；这些信标属于研究设计，不是LuSNAR已有设施。原纯车间测距场景若保留，则只评价在给定先验下可确定的量，明确共同平移和旋转等自由度。不能靠随意强先验掩盖不可观测性。

## 六 分阶段工作与验收

### 阶段一 资产复建与高差量级

从已有PLY和GT在新目录生成NPZ与新版CSV，保存源哈希、代码SHA、参数和生成回执。逐数组比较新旧场景，保留差异说明和旧文件。没有历史回执时只记录本次生成关系，不补造旧资产来源。

对原轨迹计算水平距离r_xy、三维距离r_3D和高差Δz。忽略高差的距离误差为 δr = r_3D − r_xy = Δz² / (r_3D + r_xy)；两端重合且分母为零时单独处理。固定高度模型还需比较 r_fixed = sqrt(r_xy² + Δz_fixed²)，固定值来源预先规定，不从全段真值反向拟合最优常数。

报告差值分布、RMS、极值和时序，并按车辆插值所依赖的网格节点、离观测距离和边界裁剪分层。0.03 m和0.04 m只作为历史代码中的假设噪声尺度参照。原轨迹和重采样序列分别说明，时间点不当独立重复。小测距失配不自动意味着小位置影响，还需结合所选参考几何的灵敏度判断，不能只按噪声比例排除弱几何效应。

验收包括合成平地零差、斜坡解析关系、CSV与天线坐标一致，以及旧CSV不被静默接受。若自然高差效应小，保留小效应结论；若主要来自填补区，暂不据此扩大定位结论。可另设解析斜坡用例，但不得称其为原Moon_1。

### 阶段二 实测依据与定位接口

完成数据角色清单、车辆参数登记和一个短窗口无噪声一致性检查。仿真信标、先验、运动坐标系、尺度、时间对齐、双向测距相关性以及高度信息来源写入协议。数值尺度和几何改变后重新检查雅可比、秩与单位，不直接套用原室内协方差。

准确高度参照可使用参考高度，但需显式标为oracle。将来使用高度图时，若高度随估计XY取值，应处理高度图梯度及不确定性；若使用独立高度观测，应定义其误差与相关性。仅把真值z加入距离而忽略高度误差，不可称为可部署地形补偿。

验收要求普通方法不读truth或故障标签；导出的零噪声观测与声明模型一致；独立程序复算测距与至少一个雅可比检查；不可观测、失败和缺失都有显式分类。通过后才冻结定位试验矩阵。

### 阶段三 小规模定位与可信度对照

先采用运动学参考与合成观测，隔离定位模型影响。建议开发上限为2种地形条件（同XY平地对照与原Moon_1）×2种运动观测条件（正常与一种规定退化）×2种测距条件（LOS噪声与指定链路常偏差），共8条件。原Moon_1不适用时缩减，不为填满矩阵改造数据。

| 方法标记 | 定位配置 | 用途 |
| --- | --- | --- |
| M0 | 各车独立，二维距离模型 | 逐车协同收益参照 |
| M1 | 双车协同，二维距离模型 | 无偏差增广基线 |
| M2 | 双车协同，二维模型加指定链路单一常偏差 | 检查偏差吸收与几何失配混淆 |
| M3 | 双车协同，准确高度距离模型 | 与M1配对隔离高度建模作用 |
| M4 | 准确高度模型加同样的常偏差增广 | 与M2配对，避免同时改变高度与偏差处理 |

窗口位置、采样间隔、信标布局、先验、噪声与退化幅度必须在协议中列出具体数值和依据，不能依据定位误差挑选窗口。首轮可使用假设的四信标局部参考，以便与既有模型衔接；这只是受控参考几何，不宣称实际月面已有该布设。上述配置未冻结时不得启动正式矩阵。

所有方法使用相同配对观测、信标、先验和运动信息，除指定模型差异外不调权。准确高度是额外理想信息，单独标注。M0用于给定建模条件下的独立参照；若要评价准确高度下的协同收益，应另增对应独立高度基线，不能只与M0混比。

最多30个开发seed形成1200个条件方法组合；冻结方法与指标后，使用50个新seed确认，最多2000个组合。两批分开，不作为必跑配额。每个组合可含预先规定的多个短窗口，必须另报窗口数、优化阶段数和实际调用数，不把组合数等同优化器调用数。

开发结果用于确定问题与实现，不用于挑选有利确认条件。确认后若改模型，另立版本和新确认批，不继续把已暴露seed称为盲测。50个seed用于初步经验比较，不足以支撑罕见风险保证。

### 阶段四 基础接触动力学

阶段二可并行进行车辆资料整理；GPU可用后再建立最小平地动态车辆。保留原运动学回放作为独立基线。轮关节驱动决定实际位姿，禁止逐帧设置车体位置后声称由动力学产生。

依次验证静止支撑、直行、转弯、简单坡面、障碍接触和普通/低摩擦区。同一载荷、控制指令和数值设置下比较，输出轮角速度、车体位姿、接触事件及编码器里程计误差。低摩擦并不保证一定滑移，应报告实际测得的轮地运动差异；低速滑移比需规定分母阈值和不可用标记。

以物理合理性和数值稳定性作为进入地形场景的条件：检查单位、惯量正定、轮轴方向、碰撞初始重叠、驱动饱和以及不同时间步下结果变化。不可避免的数值接触容差应记录，不承诺绝对零穿透。出现明显不稳定则暂停动力学批次，保留CPU定位研究继续执行。

动力学路线与运动学路线分开汇总。实际轨迹改变后不能将不同路线差异全部归为定位器改进。可固定同一组动力学输出供全部定位方法回放；评价真值与编码器观测仍隔离。新增月壤模型需要单独方案和参数依据。

## 七 指标与统计口径

主要指标为逐车水平误差、相对位置误差、per-robot cooperative benefit、均值偏移与随机波动分解，以及95%和99%候选区间的经验覆盖和尺寸。协同收益严格沿用已有定义，比较时保证同一输入、时段和误差量纲。水平估计只评价水平误差；只有方法确实估计或提供可解释的z时才报告三维结果。

点覆盖与整条轨迹全部时刻覆盖分别报告。短窗口全覆盖不等于完整任务连续性。对数值失败、缺失区间和奇异矩阵报告计划数、可用数及其原因；全计划成功覆盖比例和有效子集条件覆盖分别列出，不将未产生区间解释为成功。

以独立随机运行为主要聚类单位，保留两车、方法、时间和窗口的配对关系。重叠窗口不增加独立样本，相关实测残差也不按采样点独立重采样。固定一条场景轨迹上增加seed只能评价该轨迹条件下的随机性，不能证明跨场景泛化。

所有置信区间和阈值说明统计单位与适用事件。不得用少量seed零失败宣称极低HMI风险，不把经验覆盖称为PL或HCPL保证。真实协方差、准确高度和已知故障候选作为离线理想参照。

## 八 中期交付与任务协调

中期最小交付为可追溯场景与数据接口、一组受控定位对照、逐车误差和覆盖图以及明确局限。Moon_1不适合高差结论时，交付量级分析、接口验收和单独标记的解析案例即可。基础动力学为增强项，不成为技术报告完成的前置条件。
