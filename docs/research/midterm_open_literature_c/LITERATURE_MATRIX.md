## 4. 搜索域和失败输出的迁移要求

Calafiore可从有限上界距离球得到有界外近似；差分域单独可能因秩不足无界。Safe/CORA优化没有因此给出全噪声可行集搜索域；IMM/Connectivity输出局部belief，也无全域反演合同；GMP只给误差过程的界。任何一个模块都不能替代本项目Ω的独立依据。

未来接入时必须沿用B端完整状态：空集经证书确认、无界/域依据不足、未决、预算中止、数值异常和可用输出分别统计。有限粒子、多初值、密集网格及少量真点被包含只能用于诊断，不能证明全部分支被保留。详见 [验证方案](NEXT_EXPERIMENT_SPEC.md)。
