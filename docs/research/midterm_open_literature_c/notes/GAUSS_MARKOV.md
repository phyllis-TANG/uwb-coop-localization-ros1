# 时间相关误差：保留平稳谱界，暂不移植2020稿初始方差折减

访问日期：2026-11-17。实际精读 [García Crespillo、Joerger、Langel，arXiv:2009.09495v1](https://arxiv.org/abs/2009.09495v1)，2020-09-20，8页。以下页/式均指这一作者稿。[2023后继期刊元数据](https://elib.dlr.de/193615/)已核，但该机构全文限内部访问；本笔记不评价其正文、勘误或作者实现。实际PDF哈希与限制见 [GAUSS_MARKOV_ACCESS.json](GAUSS_MARKOV_ACCESS.json)。

## 1. 模型与保证对象

**原文定义/证明，p2–4式(1)–(22)。** 真实误差是零均值、平稳、一阶Gauss–Markov过程（GMP）。其稳态方差已知为 $\sigma^2$，或有独立上界；相关时间常数仅知 $0<\tau_{\min}\le\tau\le\tau_{\max}<\infty$。等间隔离散化后 $\alpha=\exp(-\Delta/\tau)\in(0,1)$，协方差为

$$R_{ij}=\sigma^2\alpha^{|i-j|}.$$

目标是在全部允许 $\tau$ 和频率上，用另一个GMP的功率谱上包真实谱，从而给线性估计响应的误差方差上界。这里的“tight”是给定一阶平稳GMP候选族内的最小稳态方差膨胀，不是任意形状定位区域的最紧界，也不包含任意非线性估计器。

连续时间 p3式(12)–(14)给

$$\widehat\tau=\sqrt{\tau_{\min}\tau_{\max}},\quad
k=\sqrt{\tau_{\max}/\tau_{\min}},\quad \widehat\sigma^2=k\sigma^2.$$

不能只把 $\tau$ 取最大、保持方差不变就声称所有频率保守。离散时间需考虑采样间隔；连续时间界可离散使用，但不是离散候选族内最紧者。

## 2. 离散平稳界：从原文端点条件独立重推

**原文条件：** p7式(51)/(53)。**以下参数形式及充分性说明为我们推导**，避免直接照录p8式(54)：

$$g(a)=\frac{1+a}{1-a},\quad
g_- =g(\alpha_{\min}),\quad g_+=g(\alpha_{\max}),$$
$$k=\sqrt{\frac{g_+}{g_-}},\qquad
\widehat g=\sqrt{g_-g_+},\qquad
\widehat\alpha=\frac{\widehat g-1}{\widehat g+1}.$$

原文约束正好为 $k\widehat g\ge g_+$ 和 $k/\widehat g\ge1/g_-$。两边同时取等号，使两者最大值最小，且保证 $k\ge1$、$\alpha_{\min}\le\widehat\alpha\le\alpha_{\max}$。对固定 $\alpha$，离散谱

$$S_\alpha(\omega)=
\frac{\sigma^2\Delta(1-\alpha^2)}
{1+\alpha^2-2\alpha\cos(\omega\Delta)}$$

有严格正分母。将 $\widehat S-S_\alpha$ 乘以两个正分母，得到关于 $z=\cos(\omega\Delta)$ 的仿射函数。其在 $z=\pm1$ 的非负性即覆盖全部频率；端点最坏 $\alpha$ 分别为 $\alpha_{\max}$、$\alpha_{\min}$。这补足了“只看两频率”的充分性说明，未靠密集频率网格替代证明。

对任意有限向量v，谱积分给 $v^\top(\overline R-R)v\ge0$，其中

$$\overline R_{ij}=k\sigma^2\widehat\alpha^{|i-j|}.$$

因而固定线性响应G满足 $G R G^\top\preceq G\overline R G^\top$。这可直接用于集中式批量估计，不要求改为分布式Kalman滤波。若G取决于本次噪声或非线性端点，只对固定G的证明不能直接条件化后复用。

**版本疑点：** v1 p8式(54)所印分母是
$\alpha_{\max}-\alpha_{\min}+\alpha_{\min}\alpha_{\max}-1
=(\alpha_{\max}-1)(\alpha_{\min}+1)<0$，
而根号分子为正；按字面会给负膨胀因子。已用PDF像素复核，非仅OCR结果。上面的正值来自式(51)/(53)独立推导；不宣称作者程序或2023版使用这一印刷表达。

## 3. 初始方差折减的三时刻反例

**原文主张，p4–5式(24)–(33)：** 在平稳外包的同一 $\widehat\alpha,k$ 下，将初始方差改为 $k_0\sigma^2$，随后趋向平稳方差。其多时刻协方差按式(24)是

$$\widehat R_{ij}=\sigma^2\left[
k\widehat\alpha^{|i-j|}+(k_0-k)\widehat\alpha^{i+j}\right].$$

稿件以两时刻块的半正定条件求初始方差，并借数值敏感性判断最坏时刻和参数；式(33)取 $n=0,p=1,\alpha=\alpha_{\min}$。两时刻块条件本身不能证明任意多时刻联合矩阵的半正定。

**我们推导＋本轮精确代数观察E3：** 预先登记 $\alpha\in[1/3,7/9]$、$\Delta=1$、$\sigma^2=1$，平稳解 $\widehat\alpha=3/5,k=2$。取真实 $\alpha=1/3$、时刻0/1/2。式(32)/(33)给 $k_0=11/9$，分母为 $8/25>0$，没有负方差或非法参数。完整差矩阵为

$$D=\widehat R-R=
\begin{pmatrix}
2/9&2/5&74/225\\
2/5&18/25&262/375\\
74/225&262/375&562/625
\end{pmatrix}.$$

首两时刻块半正定且行列式为0，但预定 $v=(-9/5,1,-1/10)^\top$ 给

$$v^\top Dv=-1157/93750<0.$$

另一个无需浮点特征值的核对是：$w=(-9/5,1,0)^\top$ 满足 $w^\top Dw=0$，但 $w^\top De_3=8/75\ne0$，与PSD矩阵的零二次型方向必须在核空间矛盾。

因此，**该2020版本式(32)/(33)这样折减初始方差，不能作为任意多时刻线性响应的普遍协方差上界直接移植。** 这是单个合法参数反例对普遍主张的否证，不是用三点去验证概率尾部。对照 $k_0=k$ 的有限矩阵全部主子式非负；一般平稳保证仍来自上一节谱证明，不来自这一对照样本。

## 4. 相关性与固定偏差不能混为一谈

|对象|可用结论|边界|
|---|---|---|
|一个通道的时间相关随机噪声|上述谱界上包任意有限时间联合协方差|真实过程必须属于声明的平稳一阶族，方差与时间常数范围有依据|
|多个通道/车辆共模随机噪声|若整个联合交叉谱矩阵有PSD上界，可同样传播|各标量通道分别上包并不能自动上包未知跨通道相关；没有依据不能简单拼独立块|
|确定但未知常偏移|另用同一固定参数集合，或明确具有依据的随机先验|协方差上界不消除均值偏移，固定survey不因写成二次罚项而随机化|
|确定性step/ramp|可建立变化包络或显式趋势模型，但本轮未建立|不属于零均值平稳GMP；不能把moon1残差趋势拟成一个大τ就宣称已涵盖|
|集中式联合状态估计|已有共享位置、bias与运动因子的联合耦合可以保留|已有状态互协方差不证明原始输入噪声模型包含未知有色/共模误差|

协方差序上界本身不是分布尾界。只有额外满足零均值Gaussian、固定线性映射、正确支撑/秩及已定义事件等条件时，才可转成相应Gaussian区域的保守概率陈述；任意非Gaussian分布或非线性多分支估计不能直接继承。状态区域若通过完整噪声事件反演，还需单独证明外包和有限域包含。
