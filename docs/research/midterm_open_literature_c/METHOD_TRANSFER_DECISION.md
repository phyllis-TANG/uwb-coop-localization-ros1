# 方法迁移决策：最多两项，先做区域预收缩

**先实现Calafiore平方测距差凸外集的可核验预收缩。** 当前B端已有全盒外包，增加一个bias后盒数约增12–13倍；这一模块直接回应已观察到的成本瓶颈，且可保持原始测距、联合噪声球、多支及偏差域不变。第二项只准备平稳GMP联合协方差外包的低维验证，独立开展，不同第一项合并调参。

证据定位和既有数字见 [CURRENT_EVIDENCE.md](CURRENT_EVIDENCE.md)，书目与不利结果见 [LITERATURE_MATRIX.md](LITERATURE_MATRIX.md)。优先级按现有缺口与可否否证排序，不按刊物或年份。

## 1. 第一候选：可核验的凸外预收缩

**解决问题：** 保留非线性全部噪声相容分支的同时，尝试减少区间依赖导致的未决盒/计算成本。它不负责诊断故障、选择真分支、校准bias范围或设定风险。

**借鉴模块：** Calafiore §3的平方差凸外集及§5.1固定方向外盒。先以联合噪声球的分量外界、合法bias域构造更松距离界；只用可靠对偶方向界缩位置域；继续调用原SIVIA和原独立证书检查。内接椭球、穿中心截线、自动界膨胀不进入此验证。

**尚不满足：** 可靠数值SOCP外界/对偶残差修正未实现；作者代码未取得；实际域、锚点和bias范围缺平台依据；未知第二车位置尚不属于原低维模型。对共同b外投影可能太松，凸外集也不能分开镜像支。

**成本与否证：** 单次根域预收缩需2n个方向求解，额外认证成本可能大于节省的分支搜索。若任何合法分支/边界点被删、需要放宽原q/域/容差才能通过，方法迁移失败；若全部证书保守但总成本无收益，则否定其在当前预算中的优先实用性，保留负面结果。不能把求解器精度小数当包含证明。

## 2. 第二候选：仅平稳GMP的联合协方差上界

**解决问题：** 当未来平台证据支持有限正τ范围和方差上界时，为时间相关随机输入提供明示的联合误差矩阵，避免按独立噪声或只取最大τ误估线性响应。不声称解释当前独立噪声仿真的非线性覆盖缺口。

**借鉴模块：** 2020稿的平稳谱外包；从两端谱约束重推正值离散参数，保持初始方差等于平稳 $k\sigma^2$。对固定集中式线性参照用 $G\overline R G^\top$；不改成分布式，不引入IMM，不同步更改bias模型。

**尚不满足：** 当前没有平台τ/方差范围与平稳性验证；跨车共模需联合交叉谱依据；固定survey偏移和确定性step/ramp要另列；非线性数据依赖G的区域包含未证明。2020稿的初始方差折减被E3否证为一般多时刻上界，故明确排除。

**成本与否证：** 先限6时刻单通道矩阵与固定G，代数证明优先，计算成本远低于整套定位器。任何合法τ下完整矩阵序/固定响应上界被严格反例否定，即否证实现或推导；仅少量检查通过不证明全部参数。若模型辨识只能用当前同批残差、无法给独立参数范围，保持理论储备，不接入保护区域。

两候选的具体条件、对照、预算和输出列于 [NEXT_EXPERIMENT_SPEC.md](NEXT_EXPERIMENT_SPEC.md)。第二项不是第一项的前置条件，也不是本轮已经授权启动的新实验。

## 3. 暂缓的方法及原因
