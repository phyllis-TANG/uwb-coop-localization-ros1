# 同目标误差恒等分解与退化Gaussian集合

以下推导针对固定设计；PR119/B2与PR121为25维，PR119/B3为24维。位置状态顺序为(t,car,xy)，b仅B2存在，单位m。B3目标先扣除已知真实注入，是oracle参照，不能将其套用B2的自由b列。所有残差按实际sigma白化；先验中心固定，不是新的随机观测。真状态只用于本轮离线诊断。

## 1. 恒等式与稳定计算

记r0=r(x*)、J0=J(x*)、ΔN=xN−x*、rN=r(xN)、JN=J(xN)，真值仿射直接解ΔL使J0ᵀ(r0+J0ΔL)=0。定义η=rN−r0−J0ΔN，ΔJ=JN−J0，gN=JNᵀrN。于是

    gN = J0ᵀ(r0+J0ΔN+η) + ΔJᵀrN
       = H0(ΔN−ΔL) + J0ᵀη + ΔJᵀrN，H0=J0ᵀJ0。

当J0满列秩时，

    ΔN−ΔL = v_g + v_η + v_J，
    H0 v_g=gN，H0 v_η=−J0ᵀη，H0 v_J=−ΔJᵀrN。

这在任意保存端点都成立，不需要驻点或局部极小。接受标签不允许令gN=0。η和ΔJ含路径之外未知的非线性行为，分解是恒等归因而非独立干预的因果贡献：同一变化会影响多个项。符号抵消须保留，不能把三项范数归一化冒称误差来源的可加百分比。

计算使用J0D=U S Vᵀ，位置尺度1m、偏差尺度.1m。ΔL=−D V S⁻¹ Uᵀr0；H0 v=b通过v=D V S⁻² VᵀD b求得，不显式构造H0逆。独立验收使用未缩放QR的Rᵀ与R两次三角系统。报告κ(J0D)及其平方，不隐瞒正规方程条件性；主秩相对阈值1e−8及1e−6/1e−10/1e−12敏感性均保存。无满列秩时不提供该唯一向量分解。

位置大小为||v_position||/sqrt(12)，逐车为六时刻RMS，不是单一坐标范数。先逐候选、再在seed内平均、再跨seed；它与sqrt(总体MSE)不同。偏差保留有符号标量。弱方向用D坐标的GN特征子空间W，对v使用||WᵀD⁻¹v||；真值和终点两个W分别标记。近重根取完整子空间，避免不稳定单向量。抵消标量1−||Σv_position||/Σ||v_position||只描述三角不等式余量，余弦进一步给方向关系。

## 2. 唯一状态与退化随机分布

固定仿射目标为||AΔ−ε||²+||LΔ−δ/σp||²，J=[A;L]，ε∼N(0,I74)，δ=c−Ex*是固定4维中心偏移。满列秩时K=J⁺，G=K[:,0:74]，T=K[:,74:78]/σp，

    ΔL=Gε+Tδ；EΔL=Tδ，Cov(ΔL)=GGᵀ。

这里K作为唯一满列秩最小二乘响应计算，不是在欠秩状态上用伪逆制造唯一性。位置块F的P=FGGᵀFᵀ仍可奇异。曲率逆K Kᵀ不同于固定先验噪声传播GGᵀ，不默认等同于Bayesian后验协方差。

weak静态共线真值下，所有测距对y的一阶导数严格为0。每车横向仿射目标只含运动差分和首时刻先验。令白化运动噪声为ε_y,t，则精确直接解

    Δy0=δ_y，Δyt=δ_y+σmotion Σ(k=0…t−1) ε_y,k。

因此首时刻随机y恒为0，随机x非退化：二维边缘结构秩1。以后y为随机累计位移，边缘秩2。位置先验消除了状态平移不唯一性，却没有将固定中心变成随机量。代码先核验锚点/真位置共线和零横向导数，再核验解析G/T行与SVD、独立QR相符，才用解析零行；不是依覆盖好坏或谱阈值删小特征值。缺少结构证明且数值奇异值不能可靠区分时标记RANK_UNCERTAIN。实际PR121没有秩0位置块，但确定性测试覆盖秩0通用情形。

## 3. 秩r的Gaussian置信集合

写P=Q Λ Qᵀ，Q的r列是随机支持的正交基，Λ为r×r正定矩阵。对r>0，噪声集合

    Nα={z: z∈range(Q)，(Qᵀz)ᵀΛ⁻¹(Qᵀz)≤χ²_r(1−α)}。

Z∼N(0,P)几乎必然在range(Q)，二次型服从χ²_r，因此P(Z∈Nα)=1−α。可写zᵀP⁺z，但必须同时附加支持条件；否则所有零方差方向的任意误差都被漏掉。r=1为线段而非二维椭圆；r=0为{0}，包含概率1，没有χ²_0分位数计算。r<2的二维Lebesgue面积为0；最大半径仍有意义。

实现使用噪声因子FG的SVD检查数值条件；有数学结构支持时使用明确Q。支持容差1e−10m仅用于浮点验收，记录真实支持距离，单位转为mm时同步乘1000，不把容差当物理裕度。边界使用100eps尺度的舍入容差。理论集合没有这些人为厚度；部署若依赖该判定须再单列数值界。

## 4. 固定偏移Minkowski和及外包圆

令Dρ={δ∈R⁴:||δ||≤ρ}，B=FT，实际同一个固定δ属于Dρ。误差FΔL=FGε+Bδ。集合

    Cα,ρ=Nα ⊕ B Dρ

对每一个集合内固定δ提供至少1−α覆盖，不是为δ指定均匀分布。对任意方向a，

    h_C(a)=sqrt(q_r aᵀPa)+ρ||Bᵀa||，r>0；
    h_C(a)=ρ||Bᵀa||，r=0。

这是全方向的支持函数，适用于线段/单点与偏移椭球的和。对单位a，aᵀPa≤λmax(P)，||Bᵀa||≤||B||₂，故

    Cα,ρ ⊂ {e:||e||≤R}，
    R=sqrt(q_r λmax(P))+ρ||B||₂，r>0；R=ρ||B||₂，r=0。

本轮实际覆盖表计算噪声支持集（rho0）和三种rho的外包圆；不声称实现一般Minkowski和的精确成员判定。圆可能包含原支持之外的误差，这本身是正确外包保守性，不是支持检查遗漏。只有噪声支持集成员测试强制支持条件。偏移方向不与噪声支持平行时，Minkowski和可能变成二维；不能拿“原噪声秩1”否定组合集合面积。

各块使用同一个四维Dρ，不能在评估时替换每块的真实δ。各块外包允许不同的最坏偏移方向，仅增加保守性。由于集合中心对称，把误差包含转成以估计为中心的真位置区域不改变符号。离线扣除Tδ仅用于检查噪声恒等式，从未用于改变交付估计中心。

## 5. 点态与双车六时刻联合

点态：每块α=.05，仅保证固定某车某时刻。12块全覆盖的经验频率另列，不是点态保证的同义词。

联合：预先固定每块αj=.05/12。令Ej为第j块Gaussian噪声在其支持集合中，则P(Ejᶜ)≤αj（秩0为0）。对任意同一个固定δ∈Dρ，全部Ej成立蕴含全部12块误差进入各自组合集合及外包圆。因此

    P(所有12块同时覆盖) ≥ 1−Σj P(Ejᶜ) ≥ .95。

不要求车间、时间或不同块独立。固定仿射设计、正确联合Gaussian噪声及固定偏移集合包含是必需前提；rho不足时理论不适用。rank0可使界更保守，本轮不重新分配其预算。联合外包圆通常更大，高经验覆盖不是错误，也不能当作罕见风险证据。

## 6. 非线性研究能继承与不能继承的部分

恒等分解解释已有端点为何偏离仿射解；并没有给未观察噪声/偏移域内的v_η+v_J统一外包，也没有控制分支遗漏、离域或关联误差。即使v_g很小，另两项仍可很大。精确Hessian逆不是随机协方差；改用精确H灵敏度也不自动补齐有限扰动余项界。

本轮将同一仿射区域套到非线性端点仅作NL_COMPARE经验反例，不继承上述点态或联合保证。尤其秩1支持的微小非线性横向位移即可能违反支持，不能为提高覆盖而给零方向加ridge或事后厚度。下一阶段若要证明非线性区域，须给出有依据的扰动域、余项与分支控制，或另作噪声事件的全域外包反演。当前结果不构成保护级/HMI/实车或罕见风险保证。
