# 下一阶段决策

本轮成功标准是数学边界清楚，不是非线性覆盖变好。来源与全部数值见REPORT；以下三项按优先级建议，未新增实验或优化。

1. **先构造明确扰动域内的非线性余项外包问题。** 本轮weak/.5位置差约.125m，梯度响应约2e−7m，且Jacobian变化项占代数主导；偏差误差则主要表现为残差余项。不能以数值驻点接受替代区域有效性。最小下一步是固定一个可论证的状态/噪声/中心偏移域，给η、ΔJ及信息逆响应的统一界，明确距离零点、秩变化、离域与候选分支条件。验收必须是域内包含论证及边界反例，不能把本批最大值当确定上界。若界不可得或区域无界，应诚实报告不可用，不追加ridge。
2. **保留支持几何，避免将退化仿射区域直接迁移。** 首时刻缺口在仿射模型内已解决；非线性小的横向变化也会离开秩1支持。未来若增加非线性余项集，它必须能够描述横向厚度且有独立界，不能为了经验覆盖加任意厚度。验收需包含秩0/1/2、支持外反例、单位/旋转不变性和固定偏移的同一集合语义。
3. **任务事件与联合区域必须一起定义。** 本轮12块Bonferroni风险分配提供固定仿射模型的联合语义，代价是更大区域；weak/.5非线性仅7/30完整覆盖，直接移植已被反例否定。下一轮方法设计应保留共同噪声事件/同一偏移集合，若改为全域噪声事件反演，必须证明计算外包及包含所有候选区域。不能以有限多初值结果冒充全局覆盖，也不能用30/30替代罕见风险论证。

已有解释与未决问题分开：恒等式是端点的代数解释，不是因果贡献分解。它不能分离未发现分支、路径非线性、几何引起的选择变化的全部作用。PR119轻扰动未同步改善覆盖的反例继续保留。最终安全量化目标仍需有依据的噪声/故障/中心集合和数值误差界，本轮不声称保护级/HMI或实车保证。
