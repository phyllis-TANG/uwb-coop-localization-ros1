# 建议的数值状态与后续协议

本文件是本轮事后建议，不改变PR98/99的旧标签或预登记标准。建议正式新批次之前另冻结统一协议；本轮没有开发新定位方法。

## 分层记录，不用一个成功位覆盖所有含义

|---|---|---|
|execution|EXCEPTION / NONFINITE / FINITE|估计、残差、J、代价和梯度分别检查finite；有限只是必要条件|

`GTOL`本身也不能证明全局极小；在非线性/退化问题上需保留分支敏感性和局部解限定。秩亏不是统一执行失败，且不得加ridge来伪造有限协方差。

## 梯度量纲、白化和状态尺度

目标 `F(x)=1/2 ||r(x)||²`；r已经按range .04m、motion .02m和实际prior sigma白化。`g=Jᵀr`是对物理米坐标的梯度。设`x=D z`，则`g_z=Dᵀg`。D的位置尺度1m、偏差尺度.1m；应同时存完整向量和无穷范数，不能只看bias方向或只看总norm。

已检查当前SciPy1.15.3本地源码 `scipy.optimize._lsq.trf.trf_no_bounds`：此无边界TRF返回的optimality为原始 `norm(g,inf)`，x_scale影响步长/信赖域，不自动将返回optimality变成 `||Dᵀg||∞`。本面板两范数数值相同是最大分量落在位置维，不是两个定义一般等价。未来更换参数单位、尺度、噪声权重或残差数量时，不能机械沿用裸1e-5。

补充保存列归一化梯度 `max_i |(JD)_iᵀr|/(||(JD)_i|| ||r||)`，它衡量残差与列的夹角；零分母需显式处理。该指标也不能单独判断状态误差，近奇异方向的小梯度仍可能伴随大状态变化。本轮原面板最大6.63e-7、继续后1.43e-8，仅为描述性读数。

## 为什么ftol可以先满足

已检查本地SciPy `check_termination`：ftol要求实际代价下降小于`ftol*F`且模型比率>0.25；它不要求梯度低于B的1e-5。非零噪声/冲突prior使F非零，下降可非常小但梯度仍非零。xtol检测物理步长相对状态范数，不等于梯度标准。126次继续迭代由xtol停下，不能宣称128次均达到1e-10。

仅改max_nfev通常不能解决ftol提前停止；本轮诊断关闭ftol并收紧xtol，未改变目标、增广状态或权重。保留原终点与继续终点，不静默替换。全局分支问题也不能靠增加迭代预算自动解决。

## 阈值建议及依据

先继续保留旧raw-gradient≤1e-5为独立可比较标志，不靠事后放宽它“消除失败”。对于**本固定模型与尺度**，可在下一轮开发冻结下列候选诊断标准，而非直接成为实车在线政策：

- 有限性、独立残差/J验证通过；完整记录停止原因和预算。
- 同时报告raw和scaled梯度，候选scaled≤1e-5；重新标定量纲或权重后重新论证。
- 以固定继续方案为稳定性探针，候选最大位置坐标变化≤1e-4m、偏差变化≤1e-4m，且相对代价变化≤1e-8。本轮位置最大约9.8e-6m、偏差3.2e-8m，但这些候选阈值是在看过本面板后提出，只是远小于.04m测距噪声的工程诊断尺度，不是精度保证或预注册验证成功。
- 将截断SVD预测步、奇异谱、条件数和可辨识性一起阅读。若方向落入零空间，不以截断步小断言稳定；显式标注unidentified并保留null协方差。总J条件好也可能只是prior补充，不能代替data信息。
- 使用跨初值或分支检查时，预先规定起点与比较规则，保留各分支；不按真值近远选。当前同初值面板没有分支差异，不能保证其他起点同解。

这里`1e-4m`/`1e-8`等是后续待验证候选，不用于重新分类旧成功标签。本轮CSV保留连续变化值，未强制给stability通过率。继续后未达1e-5或仍有显著变化应保持未解决；不要求所有退化场景通过。

双精度epsilon约2.22e-16。本轮记录的 `eps*m*||JD||₂*max(1,||r||)` 约1.0e-11–3.6e-11，仅是梯度求和舍入尺度的粗略代理，不是含函数求值/消减误差的严格上界。原梯度最大6.12e-4远高于它，故不能简单归咎舍入。反过来，在代价下降接近可分辨精度时，盲目追逐极小梯度也可能只得到xtol停滞。

## 尚未解决

本面板只有一个暴露seed、两种运动、两种几何、强位置prior；不覆盖A near、无prior或peer-only不适定案例，也没有正式新seed。未为旧全矩阵继续迭代，不能保证其误差/分支不变。后续若需诊断具体near多分支，应按固定案例和目标选取，不按真值结果筛选。

未建立适合实车噪声相关性、未知航向、边缘化、更多状态和浮点平台的统一阈值；未验证协方差覆盖率或完好性。接受一个数值稳定的局部解与认定观测模型可信、定位误差可接受是不同判断。
