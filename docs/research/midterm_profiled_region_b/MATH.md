# 区间偏差的解析消元

沿PR124，p=(x,y)∈X=[−6,6]²m；d_j(p)=||p−a_j||。前三条无偏差，第四条预测d₄(p)+b，b∈B=[β₋,β₊]。已知b₀对应B=[b₀,b₀]，不是另一噪声模型。独立四条测距sigma=.04m；q=9.488仍是完整χ²₄事件的向上阈值。不把参数消元当成噪声维数减少。

## 精确实数关系

若观测是精确y，令t=y₄−d₄(p)。第四残差最优b为clip(t,B)：t在B内部时取t、低于β₋取β₋、高于β₊取β₊。于是

    Φ(p)=Σ(j=1..3) [(y_j−d_j(p))/σ_j]² + dist(y₄−d₄(p),B)²/σ₄²。

对固定p，这是紧区间上的连续目标最小值，极小值必达到，故

    πXY { (p,b)∈X×B : Q(p,b)≤q } = {p∈X : Φ(p)≤q}。

这是真实数集合的等价，不只是保守近似；无唯一性假设，也不选镜像支。

## 区间观测的存在量词

PR124保存I_j=[ℓ_j,u_j]，定义C_I={ (p,b):∃v∈∏I_j, Σ[(v_j−h_j(p,b))/σ_j]²≤q }。因为I为笛卡尔积、权重对角，且b仅在第四行，各项可独立最小化：

    S(p)=Σ(j=1..3) dist(d_j(p),I_j)²/σ_j²，
    J₄=I₄−B=[ℓ₄−β₊, u₄−β₋]，
    Φ_I(p)=S(p)+dist(d₄(p),J₄)²/σ₄²。

闭区间相交、端点接触都允许残差0；第四项最小距离等于两个区间I₄和d₄+B之间的距离。独立最小值可同时达到，因此πXY C_I={p∈X:Φ_I(p)≤q}严格等价。若采用一般相关R，上述逐行分离不再直接成立，本轮不作此扩展。PR124旧盒检查的内部条件更强（对盒中所有b/观测都满足），不等于新二维内部盒中每个p存在合适b；内盒数量不可当同一状态体积比较。

## 从固定位置恢复全部可行偏差

令余量L(p)=q−S(p)。L<0时偏差集合为空；L≥0时

    B_feas(p)=B ∩ [ℓ₄−d₄(p)−σ₄√L, u₄−d₄(p)+σ₄√L]。

这是对同一个固定p的全部可行b，不是位置盒内所有p共用的b。零余量给B∩(I₄−d₄)，相切时允许单点；区间左端大于右端才是空集。已知b退化区间也按相同闭集规则处理，不能因宽度为0而删除。

有限算术恢复使用S、d₄、√L的区间：L上界和距离外向界产生可行b的外包；若L下界非负，反向收紧产生可认证内区间。外区间空才证明无解，内区间非空才证明可行；中间状态UNDECIDED保留。保存精确字符串，不用浮点相等容差扩展物理集合。

## 新二维盒的可靠证书

对位置盒得到d_j∈[d₋,d₊]。令目标区间两个端点分别由[l₋,l₊]和[u₋,u₊]包围，则

    gap_lower=max(0,l₋−d₊,d₋−u₊)，
    gap_upper=max(0,l₊−d₋,d₊−u₋)。

用定向舍入分别平方、除σ²、求和即可包围Φ_I在整个盒上的值。端点减B时不能只扩大J后拿距离上界当内盒证书：扩大目标区间会降低距离；本实现保留端点各自的上下界。第四距离平方只需此分段函数，不对b再二分。

运算复用PR124的40位Decimal向负/正无穷舍入及10³⁵整数平方根上下界。独立checker使用Fraction与10⁴⁵整数平方根，并通过距离到区间的凸函数端点值重新计算上下界；不直接相信求解器保存的lower/upper。只有下界>q剔除；等于q、相切、预算队列和数值未知均保留。二叉树检查保证完整域覆盖。

数学等价不要求有限分辨率外包相同：新旧区间依赖、分割轴、内部判据和队列不同。X分辨率均.025m，旧b分辨率.025m；新法是对整个B解析存在消元，不是把b分辨率偷偷放粗。实际面积界、圆半径、未知盒及全部成本共同比较，不只比较盒数。

## 继承的概率语义

四维完整Gaussian噪声事件εᵀR⁻¹ε≤q，在真(p*,b*)属于固定X×B、模型/R及观测表示包含正确时，蕴含真位置属于精确投影，继而属于新旧认证外包。q和域均保持PR124，不引入位置先验、不赋予b随机分布、不把b混同δc。随机实验为100seed/条件的有限样本描述；即使全部包含，也不能证明罕见HMI风险或完整双车/25维可行性。
