# 冻结后的只读描述补充

冻结的求解、输入、阈值、预算、主统计未变。发现面积上界不同而圆完全相同后，新增union_audit.py：以精确有理数扫线构造闭矩形并集的规范分条表示，比较完整XY输出；它不生成观测、不调用搜索、不改变输出。全部626对并集相同；不能把主表面积上界下降解释为真实区域缩小。

随后describe_regions.py只读已保存偏差恢复和盒状态，分开真位置在精确C_I内与在有限外包内、负Y候选与有内部盒证明的负Y分支。这些是冻结后描述，不冒充预登记主比较；没有新选择阈值或新统计实验。audit_delivery.py补核计数和全耗时，pack/unpack只处理便携归档。它们在交付SHA/SHA256SUMS中登记，不改变冻结执行依赖清单。

扫线每个x条带合并所有闭Y区间，并合并相邻相同条带；保留矩形均有正宽度，有限并集为其内部的闭包，因此规范条带一致意味着完整闭集一致，而非只在网格采样点一致。不同条带时另算对称差面积；本批对称差均严格为有理数0。
