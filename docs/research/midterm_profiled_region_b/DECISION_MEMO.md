# 决策备忘录

**消元保持声明的包含关系。** 对独立对角权重、第四行单个常偏差和固定闭区间B，MATH给出真实数层面的精确位置投影等价；实现的定向区间和独立证书保持保守外包。没有把4维完整噪声事件改成拟合自由度，也不把b当作PR121的δc。

**本批计算节省明确，但只限当前合同。** 六个随机条件含认证与IO的均值加速约4.36–9.20倍，b内部节省较大，边界较小。全部1200运行完成，未丢失败案例；原八例不重搜，也不把历史搜索时间拿来替代缺失的历史总成本。

**输出信息没有变多。** 精确并集核对显示全部626对XY外包相同，圆也相同。旧面积上界更大是三维投影重叠表示造成的，不是旧法的真实位置集合一定更大。新法的主要价值是更少的盒与更低的认证/归档成本。

**真实歧义与保守性须分层。** 严格共线几何有反射歧义，单圆必须包住远隔两支；消元不能消除此几何事实。near每b有23个负Y候选，只有1个含已认证内部盒，其余尚无法区分窄分支和区间未决。真位置精确C_I包含97/98次，而有限外包包含100次，直接证明有限分辨率有额外保守性。100/100不意味着罕见风险已验证。

**是否进入真正单时刻双车？** 理论上单条加性偏差消元可作为下一步基础，但当前代码和实验证据尚不具备直接迁移的条件：它只处理一个未知位置、另一个参考位置完全已知。下一轮可以另行冻结少量单时刻双车机制案例，先建立四位置坐标加一个b的观测合同、锚定/镜像分析、正确完整噪声维数和联合位置投影证书；再比较四维profile与五维原集合的预算可行性。不要直接启动大样本或六时刻25维验证。

如优先追求当前模型更紧的区域，应先研究可认证约束传播或自适应精度预算，保持未决队列和失败分母；不能删负支或按真值缩域。本轮按冻结计划结束，不追加搜索。
