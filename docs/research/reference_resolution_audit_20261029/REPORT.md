# 独立参考与重复性快核：当前无法冻结实测XY数值容差

**决定：证据核对完成；数值冻结条件未满足。** 已检查12组既有参考/重复记录，不是重新解码12包。没有新采集、定位运行、视频重建、seed或留出误差读取。结果按源SHA绑定。不能从现有材料认定真实双车XY能稳定分辨1mm、5mm、1cm或2cm级的方法差异；这表示证据未建立，不表示设备客观上一定达不到。

本轮新增核实了两项具体事实：

| 既有记录 | 核实到的数值 | 可以用来做什么 | 不能升级为什么 |
|---|---|---|---|
| 9月27日双车1.85m静态卷尺及PA0/PB3单链距离 | 原notes/报告明确“约0.01m不确定度” | 当时标量车间距离的人工参考与误差量级描述 | 未给覆盖概率/因子或确定界；不等于两车各自XY精度，不能跨安装/日期套用 |
| 10月11日P1 R1/R2，同名义(2,2,1)m | N10/N2/N3/N8中位数差为5/7/0/14mm；原统计保留到1mm | 一对重复下的原始墙测距变化 | 不是定位误差标准差，也不是参考读数不确定度或均值置信区间 |

原notes仅重复相同XYZ，没有逐次尺量读数、不确定度及是否重新摆位的完整记录。每包约1,500帧不能代替1,500次独立重复。9月27日1.50m首录与repeat可用率为13.60%/99.90%，NLOS两次又分别包含进入过渡/预先站位，不应池化为同条件重复性。上述早期数据未运行当前双车模型，本轮没有把它们变为新的方法实验。

其他核对：P1/P4是不同位置，P1还参与拟合；10月18日A/B/Brepeat/C包含不同操作；T01/T03/T04的直接间距、朝向和回位不同；T02多窗来自一次相关记录。它们支持量测变化诊断，不能提供当前方法配对XY效果的独立重复性。旧前进检查中“修正后距离与卷尺只差−1mm”同样不能证明1mm评价精度。

**视频与停点未解决参考能力。** T10几何报告的1,164条候选读回在数值上可复现，但verification明确accepted metric reference rows=0；P/Q实际量测不确定度、Car2安装姿态、正式空间变换未验收。候选事件拟合残差约0.1803秒不是独立同步误差界。人工终点(1.48,2.97)m及1.52m间距仍缺量测误差与同次未挪动停车窗绑定。独立静态停点无需强行要求毫秒级同步，但这两项仍必须有来源。这里只引用已存在的验收记录，没有重新审查视频。

**冻结结果见FROZEN_TOLERANCES.json：**

- 冻结同状态/同参考配对、误差来源和覆盖说明、重复的可比条件、unknown/null语义；不把MAD、拟合残差或样本数变成参考精度。
- 实测XY/yaw分辨能力、最小有意义改善、同伴/正常/yaw允许退化、恢复时限均为null。现有0.04m只保留为开发预算；不会变成允许损害。9月27日约0.01m保留其标量/历史限定范围，不批准为本轮XY容差。
- **即使参考能力已知，也只能回答“能分辨多小”；允许损害多少仍需用途或明确的研究取舍。** 两者不能合并成同一个阈值。

为避免只留下泛化缺项，本轮给出可执行的条件规则：若将来有同一时刻天线参考误差的独立确定界ε_t，记R=√mean(ε_t²)，则两方法的配对RMSE差受参考误差影响不超过2R。当前“约1cm”既非XY界也非已证确定界，不能代入；95%扩展不确定度也不能当成必然界。证明及使用条件见BOUND_RULE.md。

**最小下一项仅为办公室恢复旧记录：** 同次实际天线XYZ/停点的重复读数、量具与误差类型、对应未挪动停车窗。若没有，保留合成条件下的算术比较和实测量测变化，不宣布真实精度小幅提升，不自动新增采集。当前检查没有遇到原件访问阻碍：本轮需要的紧凑记录均可读；缺的是可审计参考信息，不是bag丢失。
