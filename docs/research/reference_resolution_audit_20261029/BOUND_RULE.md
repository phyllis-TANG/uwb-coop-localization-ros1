# 已知参考误差界时的配对规则：本轮推导，尚未赋数值

设固定同一n个时刻，方法A的天线XY为a_t，真实位置为x_t，独立参考为r_t。假设已经由独立证据保证||r_t−x_t||≤ε_t；不能用待评价方法拟合参考，也不做轨迹对齐使差异变小。

令E_A(r)=sqrt(mean(||a_t−r_t||²))、E_A(x)=sqrt(mean(||a_t−x_t||²))，R=sqrt(mean(ε_t²))。把n个二维误差堆叠后应用欧氏范数反三角不等式，得到

    |E_A(r) − E_A(x)| ≤ R
    |[E_A(r) − E_B(r)] − [E_A(x) − E_B(x)]| ≤ 2R

所以同参考下观察到A优于B的RMSE差超过2R，足以在这些时刻保证该差的符号不因满足上述界的参考误差而翻转。这是保守充分条件，**不是必要分辨门槛**：共享误差可能部分抵消，更紧的界需要具体几何与误差相关证据，不能预设完全抵消。时间、安装等影响必须先包含在对应天线XY的ε_t中。这个界不负责跨实验随机变化、统计泛化、未观察时刻或实时延迟。

若将来预先批准最小有意义改善δ_help，可检查观察到的帮助差−2R>δ_help；若预先批准退化δ_harm，可检查观察到的代价差+2R≤δ_harm。这仍须逐车和各规定阶段检查，不将一车帮助抵消另一车损害。当前R、δ_help、δ_harm都未建立，故不做通过判定。

记录为“约0.01m不确定度”而未定义标准/扩展不确定度、覆盖或硬界的标量卷尺数据，不满足前提。概率覆盖区间也不能直接当确定性界；若采用概率口径，需要另列联合覆盖与跨时刻相关性，不能凭样本多估计极低失效风险。

两个边界例：

1. 一维真值x=0、共同参考r=e，A=0、B=2e。真实RMSE差为−2e，按参考的差为0，差值误差2e，说明2R最坏情形可达到。
2. 若两方法误差相对真值和参考始终处于同一方向，某些共同参考偏移会在差值中抵消。因此不能反过来说“差小于2R一定不可分辨”。

以上为代数推导，不是新定位算法、测量认证或论文创新结论。已有NIST指南支持先定义被报告量、明确不确定分量及传播关系，但不提供本项目的具体ε或允许损害值：[不确定度分析步骤](https://www.itl.nist.gov/div898/handbook/mpc/section5/mpc521.htm)。该网页此前已完整核对；本轮没有将它的统计不确定度方法等同上述确定性界。
