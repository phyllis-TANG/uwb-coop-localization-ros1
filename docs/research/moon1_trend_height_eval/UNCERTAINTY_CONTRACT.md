# Moon_1观测不确定性说明

本契约区分公开合成来源、可核验历史字节和研究假设。没有把本轮任何sigma、高度误差幅度或设计偏差曲线称为真实月面标定。
未知故障发生概率仍未知，条件扫描不提供概率。坐标统一moon_map，长度m、时间s；公开来源不是实测校准的同义词。

本轮核对固定提交中的PR120 reference归档哈希、同窗记录及三个窗口；不宣称重新验证原始PLY→NPZ→USD全链路或重跑Isaac GUI。
地形“观测支持”分层、平滑/填补、自然小高差沿用PR114历史报告，只作为本轮场景限制，不把新增e当作那些处理误差的已知分布。

M0也依赖供给高度：非零e改变其锚距几何，不能要求它跨高度不变。其对未使用的peer注入曲线必须保持不变。
实际距离由原true天线位置生成；e只改变估计端几何。估计权重不随σ_h改变，本轮属于模型失配敏感性，不是高度不确定性融合。
条件GN协方差仅反映声明残差模型下的局部曲率，未包含未知高度误差、设施误差或真实相关性，不作保护区域、PL/HCPL/HMI或安全概率解释。
