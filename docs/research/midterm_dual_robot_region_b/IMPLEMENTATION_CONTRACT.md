# 实现合同与阶段边界

仅新增本B端两个目录；基线PR124/127/129及PR126文献文件只读。core.py通过common.py按明确路径加载PR124的40位定向Decimal和10^35整数平方根界；新certificate.py独立使用Fraction与10^45整数平方根。普通float仅用于时间、资源统计和展示，不用于剪枝。

内部状态严格为[px,py,sx,sy,b]，9个唯一原始测距ID，4锚点，9×9正定对角R；拒绝缺行、相关/非正R、重复ID、错误完整噪声维数及阈值、额外truth字段。评价真值只在搜索结束后进入geometry.evaluate，未传给搜索或中心选择。

J5的peer包含盒内b，P4消元整个固定B，N4忽略第9行但使用单独q8。J5/P4/N4共享位置分辨率与分割规则，按归一化最长轴二分，同宽取最小轴号；不按真值或观测结果选分支。

源码独立实现完整树、队列、两车投影、独立证书与归档检查。所有阈值、正式观测和A检查器从锁定A来源读入；开发夹具里的q9=18/q8=16仅作软件测试常量，不是共同正式合同，不运行正式矩阵。

每方法独立子进程，设置1GiB虚拟地址空间限额与全流程截止。搜索每盒检查墙钟/盒数，峰值RSS达到650MiB时提前保守返回全部队列，为证书与写盘留内存。意外MemoryError、超时或硬中断保留attempt和已原子保存的结果，不冒充已认证结果，不自动重跑。正式预算、所有attempt和完整分母必须可读回。

完整流程分开记录搜索、独立B认证、A认证、投影、压缩IO、总墙钟；总墙钟含attempt/receipt等写盘。零搜索复核另计，不替换原计时。已有完成记录必须核对身份及哈希后复用，保留原成本；未知attempt触发明确阻塞。

阶段协议、来源、输入、实现及预算必须先提交冻结。冻结后发现错误：停止受影响正式运行，单独记录修复和影响范围，不重跑已暴露案例冒充冻结验证。
