# Calafiore凸预收缩接口（本轮不启用剪枝）

来源为共同起点中PR126的METHOD_TRANSFER_DECISION、NEXT_EXPERIMENT_SPEC及notes/CALAFIORE.md。其核查对象为Calafiore《Set-Membership Localization via Range Measurements》的arXiv:2603.04867v1（§3、§5.1）；本轮继承已有核查，不声称重新取得或重读正式付费版。下面双车接口是本项目推导，不是声称原文已实现未知双车联合模型。

## 从原联合事件到每车锚点距离界

对于原9维事件εᵀR⁻¹ε≤q9，每个分量满足|ε_i|≤sqrt(q9 Rii)。这由椭球支持函数成立；对角R时也可直接由各非负项得到。存在观测v_i∈[li,ui]时，前8条无偏差锚点距离必满足

    di∈[max(0,li−sqrt(q9 Rii)), ui+sqrt(q9 Rii)]。

若上端严格小于0则原相容集为空；区间跨0时先与非负距离相交，再可靠平方。用联合事件的分量外界会丢失剩余预算的共享结构，是松弛，不重新给每行分配独立概率。N4应使用其自身q8重新构造同类界，不能偷换q9以获得比较优势。

对每车各4个已知锚点，记平方距离界ξ−≤ξ≤ξ+，A列为锚点、w_i=‖a_i‖²、Q=I−11ᵀ/4。构造

    Xc={x: 存在α，ξ−≤Qw−2QAᵀx+α1≤ξ+，且‖x−ai‖²≤ξ_i+}。

原每车锚点球壳交包含于Xc。联合原集合的位置投影包含于Xp×Xs；peer始终保留在原联合反演中，不用另一车均值作已知锚点，不把b设成估计点值。共线情形凸集会填入镜像两支之间空白，所以只可作为预收缩，不能用凸集内部连通性否认真实分支。

## 数值证书、接口与回退

候选接口 `contract_anchor_outer(model, method, original_domain, direction_budget)` 返回两车各四个轴向端点、端点证书、成本和回退标志。共8个方向；只在根域执行一次，原q/分辨率/队列规则保持不变。

上端点必须是max方向目标的可靠上界，下端点必须是min方向目标的可靠下界。普通原始可行点、solver success、小KKT残差及经验epsilon均不能作为外界证书。需独立验证对偶可行性、锥条件、已知原域上的残差修正和外向舍入，保存可审计证书。

某方向未认证、超时或数值失败：该方向回退原域端点，并记录新增耗时；不能使用未经认证的较窄端点。只有可证明的新盒与原域相交才进入后续SIVIA。原域外被剔除的部分须由预收缩证书覆盖，原树证书覆盖剩余域，两者共同构成全域包含依据。本轮没有实现SOCP方向求解或将其投入正式剪枝。

## 下一轮最小对照与否证

若正式结果显示时间主要耗在宽域/区间依赖，可另冻结：本轮全部16确定性输入，每输入P4原版与“根域预收缩＋P4”各一次。每车四方向共8次，每方向最多0.5秒，总预收缩最多4秒，包含在每方法120秒总预算内，1GiB内存；原搜索50000盒/30秒不变。此为下一轮提案，不在本轮执行。

报告完整分母、方向失败/回退、总成本、B/A独立证书、两车可靠面积界和全部分支。主要否证：合法分支/边界被删；需要改变q/域/精度才通过；证书失败却仍缩域。若包含全部合格但新增成本超过节省，保留“无效率收益”，不追加方向或选成功案例。不承诺凸化必然缩小最终外包。
