# 决策

维持原随机门槛。44项复核及24个主例实际分辨率均通过，但P4全流程中位数2.319769s>2s；N4为1.618432s。因此随机完成0、失败0、未执行240。不能把N4通过替代双方通过，不能将确定性命中当随机覆盖。

下一优先项：提出7个几何/边界代表输入×原P4/认证预收缩P4，共14项对照，先冻结独立可验的复合包含证书接口。依据是P4成本仍与树节点数高度关联，且A/B界与树核验占主导；函数归因不支持把写盘或投影当首要瓶颈。实验应允许“认证正确但总时间无收益”的结论，不能忽略预处理成本。

本轮不增加随机、预收缩或两时刻搜索；保留全部旧结果、原门槛和失败/未执行分母。具体预算与否证条件见NEXT_PERFORMANCE_EXPERIMENT。
