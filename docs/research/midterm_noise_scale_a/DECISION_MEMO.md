# 下一轮优先区分什么

本轮没有观察到降噪让weak/B2多接受终点组消失：60%→62.5%→65%；主要配对区间不支持明确变化。组内点覆盖没有共同改善，RMSE却下降。整体Hessian相对差下降与弱方向修正增大同时发生，因此不建议用整体矩阵范数作为“非线性已足够小”的单一判据，也不建议将多初值或降噪直接包装为可靠区间修复方法。

## 1. 优先：共线几何的局部阶数是否关键

现有证据：真位置的测距横向一阶导数为零；估计点弱方向二阶项相对GN可很大；good无多组且覆盖稳定。缺少的是只改变共线程度的配对对照。

最小后续设计建议：固定噪声水平与正确先验，先冻结两个非零横向几何扰动对照及同一小组新seed，保留精确共线组、相同五初始化预算。观察最弱方向的导数阶数/谱隙、接受组率、组内覆盖。不得依据结果选择几何偏移。若离开共线后弱方向修正与覆盖没有改善，应削弱“共线非正则性是主要原因”的解释；不将任何单一改善自动推断为因果证明。

## 2. 随后：分离噪声幅度与相对先验权重

现有实验中数据权重随α^-2增强、先验sigma固定，且I0观测位移积分随α改变。这些都是明确混杂因素。

建议冻结一个最小伴随对照：当前固定sigma=.5与sigma=.5α两种先验权重路径，在相同标准噪声、几何、初始化规则下配对；后者保持名义数据/先验尺度比例。先规定所需样本与否证条件，不重复本轮全部矩阵凑显著。若两路径的组率/覆盖变化一致而区间足以排除实际重要差异，则“相对权重变化主导”的解释受到限制。该实验改变先验权重，必须明确为新设计，不能倒写成当前协议。

## 3. 数值接受的尺度诊断应独立处理

α=.25有117/800个初始化未驻点，但全部输入方法单元均有接受候选。尚不能由这一标签断言位置失败，也不能默认这些状态都收敛可靠。

优先利用保存r/J/gradient和Hessian做尺度化停止敏感性描述，保持旧标签。若未来要继续迭代，只能先冻结少量案例、预算和接受说明，再比较端点变化；不能按真值挑“更好”答案、放宽门槛或把重跑称未暴露样本。若标签差异不伴随可测端点变化，应修正对数值标签的解释；若变化显著，则应降低本轮对该候选的局部曲率解释力度。

以上均未执行。方法开发应等待机制与数值因素得到更清晰区分；不承诺某种协方差修正、保护级或全局求解方法一定有效。
