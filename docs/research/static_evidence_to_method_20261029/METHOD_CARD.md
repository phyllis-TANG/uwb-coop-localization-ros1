# STATIC-TO-METHOD-02｜一页方法问题卡

**问题：何时限制一车向同伴传递影响，同时保留它接受帮助的机会，何时允许恢复？当前为候选问题，非已确定的新算法。判定G3。** 本轮只读10包静态资料；没有执行协同控制方法，也不能据此宣布简单门控已经足够。

**候选想多解决的具体问题**：对外传播与接受帮助不必同时关闭，例如一车局部墙冲突时减少其牵动同伴，却仍允许其受正常peer帮助。但这需要可信角色或可操作的额外发布合同；同线索的逐车门控限幅也可以表达这类策略，目前没有只有图内候选才能解决的已验证差异。增加分数、迟滞、方向开关本身不构成创新。

**最小实测反例**：T04未安排人体操作，双向peer相对本包卷尺仍为−10.2/−5.6cm，MAD约1.6/1.6cm；T02人工peer操作段相对初始中位数仅+0.2/+0.5cm。B_repeat的peer较clear_A仅−0.7/−0.6cm，但Car2—N8仍变+37cm。故“操作即故障”“小MAD即可信”“peer恢复即四墙恢复”均不成立。这里是已有实测的量测差，不是位置真误差，更没有认证哪辆车健康。

**公平、可检验差异（仅讨论，不启动下一轮）**：若未来给出可信角色或独立发布需求，I、原J、固定缩权、输出限幅及获得相同四墙线索的门控限幅，必须共享输入、截止、几何假设、参照、预算、unknown/恢复政策。只有候选在同信息下逐车保留更多帮助、减少新增损害且不增加正常代价/误退出，才有继续依据；不能以更小拟合残差代替。若简单逐车门控限幅已达成，则停止扩张图内硬约束贡献。

**恢复及历史**：本轮T02尾段Car1—N2仍较初始多47.8cm，是量测未恢复的证据，不是运行过joint prior的证据。PR70/72/75的旧仿真/读回才支持“关闭当前peer和经过20秒不清除完整joint prior”；这些结论仅引用，未重跑。恢复必须区分当前线索、发布模式和旧先验影响；不清prior冒充peer-free，不把回退计作联合成功。

将来评价需逐车分别报告帮助、新增损害、正常代价、误退出、恢复；并列XY预算、yaw、unknown/回退/失败分母与耗时。帮助/损害需要合适独立参考；本轮静态统计不能给这些方法性能评分，也不以50Hz帧数当重复实验。新一轮若成立再冻结指标和输入，本轮无阈值/预算搜索。
