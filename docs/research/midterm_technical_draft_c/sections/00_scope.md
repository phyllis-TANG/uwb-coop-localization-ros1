# 技术摘要与阅读说明

本研究以多机器人协同定位中的安全量化为长期目标，现阶段围绕一个可检验的问题展开：引入车间测距和偏差状态后，定位误差是否逐车改善，局部不确定性是否与实际误差相符，以及这种判断在何种假设下失效。室内实测用于发现校准、摆位及误差传播的现象；固定的双车短轨迹仿真用于分离偏差建模、几何、先验与噪声机制。两类证据各有作用，均不直接代表月面环境验证。

技术正文从状态与观测模型出发，保留 per-robot cooperative benefit 的原始定义，说明指定单链路常偏差增广如何改变信息结构，再比较点覆盖、轨迹全覆盖和误差二阶矩。已有证据支持“性能改善与不确定性一致性必须分别评估”，也显示错误先验、候选链路失配和噪声相关性都可能破坏名义覆盖。当前尚未完成保护级、HCPL或危险误导信息（HMI）保证；完好性（integrity）在本报告中是研究目标，不是已获得的系统能力。

本文依据已审查固定提交整理，不生成新定位数据、不运行新的定位仿真。PR108对43200次既有方法结果作覆盖分析，不计新增定位运行；PR109历史批次完成14400次非线性方法运行和14400次对应真值处线性诊断，后者不增加独立随机样本。正文保留必要代表表图，完整矩阵与来源行号另置证据附件，避免用附录规模的数据表取代技术论证。

**来源约定。** MODEL、FIELD及R0/R106/R107F/R107N/R108/R109均为本仓库内部证据标签，不是外部文献编号。完整提交、代码行与表格筛选键在 `CLAIM_EVIDENCE.csv` 和 `FIGURE_TABLE_INDEX.md` 中展开；`notes/methods_sources.md`、`notes/results_sources.md` 提供按章节的核查记录。本文不补写完整月球背景或文献综述，不引用未核实的作者、DOI与外部研究结论。
