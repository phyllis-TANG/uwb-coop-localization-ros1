# 参考车不确定性：包含证明与适用边界

本次推导建立在固定来源30f9379249a4e695acf75910c40862a770e6f4ce之上。PR124的集合反演证书、PR123的非线性/仿射区别、PR121固定中心模型及仓库文献审计提供背景；本节扩展不是声称原论文或PR124已证明实际双车安全。

## 1. 符号及A0准确条件

p为目标车二维天线位置，s为参考车二维天线位置（避免与阈值q混名），b为指定peer测距的固定加性偏差；δs=s−s0是参考位置相对名义位置误差；δc=c−Eθ是固定先验中心偏移。b是标量测距量，δs是几何向量，δc是先验约束误差，三者不同，不能合并为同一种随机噪声。位置、距离、b均以m计，R以m²计；全部观测必须同时间、同参考系、同天线参考点。

A0沿PR124：三个已知固定锚点a1…a3和第四个已知参考位置s0，

    h(p,b;s0)=(||p−a1||,||p−a2||,||p−a3||,||p−s0||+b)。

阶段1 b=.3已知，阶段2 b∈[−.6,.6]未知固定；p∈[−6,6]²。无位置先验、无运动观测、没有第二个未知位置。ε∼N(0,.04² I4)，完整随机维数m=4，τ=9.488，其χ²4尾概率有精确有理数上界<.05。阶段2参数维数3不将自由度改为1。域和偏差范围只是仿真假设。

理想读数Y=h(θ*)+ε，定义C0={θ∈X: (Y−h(θ))ᵀR⁻¹(Y−h(θ))≤τ}。当真实θ*∈X且模型正确时，噪声事件Eε蕴含θ*∈C0。若输入以区间I表示，必须包含真实Y；反演存在v∈I的更大集合，再经包含函数/完整分割树外包。保留多支、边界未决和预算队列，不以局部极小或只搜索真值附近替代。这只是声明域内的概率下界，非任务级或HMI保证。

## 2. A1：确定集合的精确联合模型

给定预先声明的非空集合S，假设固定s*∈S；给定目标域P、偏差域B，真实p*∈P、b*∈B。定义

    C1(Y)={(p,s,b)∈P×S×B: Y−h(p,s,b)∈E_R}，
    E_R={ε: εᵀR⁻¹ε≤τ}。

输出目标投影πp C1，或者能证明包含它的外包。对每个满足域条件的固定(p*,s*,b*)，Eε直接蕴含真联合参数在C1，故目标投影覆盖至少1−αε。无须给s赋概率，也不要求唯一解或Jacobian满秩。S增大使C1及其投影单调不减；可能不连通、无界或在预算下太宽。空S是输入模型无效，不能将其当作有效定位空集。

多条观测/多时刻使用同一参考状态或声明的参考轨迹集合S_T；必须保留共享关系。若同一参考车移动，不能默认每个时刻同一s，亦不能默认各时刻独立。固定先验若被采用，只增加确定约束c−Eθ∈D_c（要有包含依据），不增加Gaussian维数；PR124原模型没有此项，新增后必须另验收。

## 3. 距离范围及保守松弛的证明

逆三角不等式给出

    | ||p−s||−||p−s0|| | ≤ ||s−s0||。

证明：||p−s||≤||p−s0||+||s−s0||；交换s和s0再取两边。无需非零距离、可导性或小误差，p=s0时也成立。若S为闭球B(s0,ρ)，令d0=||p−s0||，则固定p下的**精确标量距离像**为

    [max(0,d0−ρ), d0+ρ]。

上下端分别沿连线朝向p/背向p达到；球包含p时下端由s=p达到，d0=0时任选方向达到上端。连续像给出中间值。一般紧集S可定义d_min(p,S)、d_max(p,S)；其界必须由认证算法提供，不能用有限采样的极值声称全局范围。对一个方向的定值误差，平行误差可达到ρ，垂直误差在d0>0时变化sqrt(d0²+ρ²)−d0，通常更小，但近零距离不允许使用统一一阶线性近似。

设e(p,s)=||p−s||−d0，精确单行范围为[−min(ρ,d0),ρ]；对一个peer行和独立B，b+e的区间为[b_min−min(ρ,d0),b_max+ρ]。进一步用与p无关的对称区间[b_min−ρ,b_max+ρ]是一层额外松弛。未知物理b的解释不变，β=b+e只是有效nuisance，不能把β的估计解释成实际偏差。

多行时定义联合像V(p)={ (e_j(p,s))_j : s∈S }。精确模型保留b·c+V(p)，逐行放宽为b·c+∏j[−ρ_j,ρ_j]（可进一步将每行b也独立区间化）。由于V⊆该笛卡尔积，放宽后集合是外包；它允许彼此矛盾的误差方向、打破共享参考状态及可能的共享b一致性，通常增加保守性。区间下界即使较弱，只要严格包含仍安全；把依赖错误当成不依赖可能造成不必要的大区域。

重要反例：参考s=(u,0),u∈[−1,1]，两个已知评价位置p1=(−2,0),p2=(2,0)。距离为(2+u,2−u)，变化(e1,e2)=(u,−u)。独立区间允许(1,1)，但联合模型不允许；把所有误差强行吸收为同一个扩宽标量β也不保守，因为它只能产生(β,β)，会排除真实(u,−u)=(1,−1)。故“扩大偏差区间”仅在明确单行或有相同误差结构的特殊情形成立，不能不加条件推广到时间共享b。

## 4. 噪声事件、R与白化

对一般**已知正定**R∈R^(m×m)，令R=LLᵀ，W=L⁻¹。原始完整随机噪声ε∼N(0,R)，于是Wε∼N(0,I_m)，||Wε||²∼χ²_m；τ应满足P(χ²_m>τ)≤αε。m是去重后的原始随机数据维数，不是m−dimθ，不包含确定域、固定b、固定先验约束或确定参考误差。对固定nuisance，始终评估真参数处ε事件；拟合后的最小残差分布不是这里的阈值依据。

参考位置有界误差作为nuisance显式保留时，原ε的R可保持原定义，因为条件生成模型中没有把δs并入随机ε。这并不声称“将未知参考点代入名义点后，总残差仍具有原R”。消去s后，名义残差ε+e(p,s)通常有固定均值偏移或更复杂分布，不能套用原零均值Gaussian协方差。

若额外假设δs随机，并作明确的一阶近似e≈H_s δs，令Σs=Cov(δs)、C=Cov(ε,δs)，则

    Cov(ε+H_sδs)=R+H_sΣsH_sᵀ+C H_sᵀ+H_s Cᵀ，
    E(ε+H_sδs)=Eε+H_s Eδs。

这是局部表达；只有真实仿射且联合Gaussian等额外条件下才有精确Gaussian语义。相同UWB数据会产生C，不能任意删交叉项；固定δs只改变均值，不产生额外重复抽样方差。固定共享b与时间相关零均值ε也不同：b留在参数/域内，AR或其他时间相关进入R的非对角项。给b²加到R不是本模型的等价改写。

R非对角时，白化会混合残差行。PR124的“每行除sigma后平方相加”实现不能直接承接；新的包含函数必须包围W(Y−h)的所有线性组合（包含W本身的数值表示误差），或对二次型给可靠上下界。不能忽略交叉项后沿用旧剪枝证书。重复原观测形成奇异R，不满足本节正定前提，应去重或另推支持空间事件；不得ridge增加虚假独立信息。本轮只实现有理数2×2代数验证，没有实现一般相关R的可信区域计算。

## 5. A2：有概率覆盖的参考集合

令参考集合为可测随机集S(Z,Y)，可来自独立数据Z，也可复用Y。对固定真实联合状态，必须有同一采样总体上的覆盖前提

    E_s={s*∈S(Z,Y)}，P(E_s^c)≤α_s。

目标/偏差/固定中心域条件仍先按确定成立处理。对每次实现，将S作为约束构造C2(Y,Z)。无需E_s和Eε独立，

    E_s∩Eε ⊆ {p*∈πp C2}，
    P(p*∈πp C2)≥max(0,1−α_s−αε)。

这是联合界，不是(1−α_s)(1−αε)。两个各95%集合在无独立性时只保证至少90%，不能仍标95%。若目标总失包含≤.05，可示例预分配α_s=.02、αε=.03；不是本项目真实风险目标。PR124原q=9.488约给.05噪声风险，原样加.02参考风险仅给约.93下界。一般域、偏差、表示、故障类若也只有概率包含保证，须列明对应事件及有效上界后再作并集界，不能凭空赋零风险。

同数据不自动使上述交集包含失效：只要各**无条件**边缘事件确有有效保证，联合界仍可用；它可能保守。但不能将S的Gaussian密度当作与原Y独立的新似然，不能重复把同一UWB因子计入完整噪声向量，也不能宣称给定已观测S后，ε仍服从原无条件Gaussian。对数据驱动选子集、拒绝输出、只在接受结果校准的集合，须重新证明相关事件的无条件覆盖；P(覆盖|输出)和P(输出且失包含)不是同一量。

随机椭圆只有均值/协方差或历史经验覆盖并不足以提供E_s的界。PR123说明：非线性端点不是仿射Gaussian变量；一个样本协方差、最大经验误差或30/30结果不能变成确定球或真实α_s。若参考集合构造也用了“目标车位置已知”的假设，再用于未知目标，须有同时联合有效性证明，不能循环引用两个条件性保证。

## 6. 单时刻双车与不可辨识

下一阶段固定θ=(p_x,p_y,s_x,s_y,b)，每车对四已知锚点测距，加一条peer，共m=9：h=(||p−a_k||_{k=1..4},||s−a_k||_{k=1..4},||p−s||+b)。b只对应声明的peer候选；其他链路故障不由此自动覆盖。没有足够锚点时，共同平移/旋转、共线反射或距离-b混淆都可能保留；不能由m>5就认定全局唯一。无锚点时共同刚体变换不改peer，且单peer对距离和b不可分离。锚点共线时同时反射两车仍保持所有距离；近零peer距离处一阶导数未定义，但距离包含函数本身仍有效。

联合反演时参考车不再被当成已知量；域X=P×S_domain×B及可能的固定中心集合独立声明，完整9维噪声事件一次使用。联合可行集及其两个位置投影共享同一事件，不需要为两车重复独立计数。若再加A2集合，须说明其信息来源及相应风险/重复数据关系。两时刻只在DUAL_ROBOT_NEXT_SPEC定义，不执行高维搜索。
