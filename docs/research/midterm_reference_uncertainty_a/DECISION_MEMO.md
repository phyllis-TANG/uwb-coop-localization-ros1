# 下一阶段决策

优先做**保留共享参考位置的单时刻联合模型**，不要默认把参考误差塞进同一个测距b。T08已经给出遗漏真值的精确反例；T07显示独立逐行放宽虽可保守，但会允许不可能的联合方向。第一版应明确采用联合s状态，或在资源限制下使用带包含证明的独立距离包络并承认额外保守性。

参考位置是概率集合时，用E_s∩Eε和并集界组合；不要求独立，但必须有两项真实有效的覆盖前提。同一UWB数据可以出现在集合构造中，但不能把派生参考估计当成新的独立似然重复融合。原q=9.488加2%参考失包含风险并非95%总保证；风险预算必须在设计时统一说明。经验椭圆不足以提供αs。

下一阶段最小交付是5维[p_x,p_y,s_x,s_y,b]、9个唯一随机测距的明确输入合同、认证外包及独立全树读回；在固定预算下区域太宽也算诚实完成。首版若只支持对角R，非对角R应明确拒绝，不能静默忽略相关性。当前数学已给一般正定R表达，但一般R的可信区间计算尚未实现。

在实车解释前，先解决参考集合、坐标/时间/杆臂、R/尾部和偏差域的来源资格。已有静态或视频记录是线索，不是确定界。两时刻规格已写但不自动执行；完成单时刻包含/分支/预算门槛后再另行评估扩维可行性。未设最终AL、PL、HMI或罕见风险指标。
