# 下一阶段真正双车模型：最小实现规格与结束标准

本文件只定义下一阶段合同，不授权本轮高维搜索。先做单时刻5维；两时刻9维仅保留规格，不能据低维PR124的耗时承诺可行性。

## 单时刻最小模型

状态θ=[p_x,p_y,s_x,s_y,b]（m），两车各一个二维天线位置、一个已知候选peer链路的固定加性b。四个已知锚点a1…a4的具体地图必须显式传入并带标定/仿真假设来源，不能把PR124第四个“已知参考车”悄悄改成额外固定锚点。

观测顺序：

    y=[r_p,a1,…,r_p,a4, r_s,a1,…,r_s,a4, r_peer] ∈ R9。
    h=[||p−ak||_k, ||s−ak||_k, ||p−s||+b]。

每个原始测距ID只出现一次；双向测距只有在确为不同采样且联合噪声模型明确时才是额外行。若无已测锚点位置，应显式增加其不确定性或声明模型不适用，不能吸收到一个peer b。

声明域X=P×S_domain×B，P/S_domain为位置集合，B为固定偏差集合。可用PR124的[−6,6]²和[−.6,.6]作为**新合成验收假设**，不作为实车安全域。可选固定中心约束c−[p;s]∈D_c需要另外的来源；默认无先验。R9已知正定时完整噪声事件为(Y−h)ᵀR9⁻¹(Y−h)≤τ9，P(χ²9>τ9)≤αε；不能复用m=4的9.488阈值，也不能用9−5=4。第一版建议只实现明确对角R的认证计算，非对角输入返回UNSUPPORTED_CORRELATED_CERTIFICATE，直到有独立认证的白化/二次型界。

输出联合外包及两个XY投影，所有分支共享一个原始9维噪声事件，所以不因投影两车额外假定独立或重复扣预算。单一包围圆仅为各投影的附加外包，需要包含全部保留分支。空集、域接触、未决/预算、数值失败与区域太宽分别记录。

|投影/半径|投影包含保持，矩形顶点界|完整5维叶向两车XY投影，重叠不当精确面积，全部分支覆盖|

## 对称性与不可辨识验收

1. 无锚点且仅peer：共同平移/旋转自由度；距离与b也可混淆。有限域可以截断自由度，但不证明数据可辨识。
2. 所有锚点共线：同时反射两车保持全部距离；独立反射某一车未必保持peer，不能随意倍增或删除分支。
3. 单车只连接单锚点或锚点观测缺失：存在圆/弧等连续集合；增加peer+b未必消除。需按实际行和域判断，不能用m≥dimθ作为全局保证。
4. p=s或车到锚点距离为0：距离函数有效但Jacobian方向不唯一；认证距离界不能依赖除以零的局部导数。
5. b超域、错链、多链路、参考/锚点真位置域外：条件性保证不适用；以明确反例验收拒绝错误主张，不能重新裁域隐藏。

## 两时刻仅模型与验收规范

θ2=[p0x,p0y,s0x,s0y,p1x,p1y,s1x,s1y,b] ∈ R9。两个时刻分别8条anchor＋1条peer，18个标量测距，共享一个固定b。若另有两车已知全局坐标系的位移观测u_p,u_s，各2维，总随机观测维数为22，h_motion=[p1−p0,s1−s0]；没有位移输入时m=18，不能保留空的运动行。R18或R22显式包含同链路时间相关、时车交叉相关及位移-测距相关（若存在）。固定首时刻中心约束不加到m。

若实际平台只有body-frame里程计/IMU而没有全局位移，以上运动模型不适用；必须增加航向/外参/时间同步模型并重新数维数，不能将其直接等同PR121的全局位移观测。参考轨迹集合S01应保留时间共享约束；若使用两个边缘概率集合，须另外给联合包含界，不能默认各自95%即整轨迹95%。

验收必须包括：时间共享b的两个peer残差；共同刚体变换/镜像；相关R的正确维数及拒绝未认证情形；运动噪声与确定性先验分开；全部位置投影的共同事件；域边界、真值域外、空集、预算未决；原始ID去重。当前不生成两时刻输入、不搜索9维空间。

## 最小接口与结束标准

下一阶段最小接口为：`invert_joint(model, domains, observation_intervals, noise_event_certificate, arithmetic_policy, budget)`；model显式包含state_order/measurement_ids/bias_incidence/data_provenance。输出`joint_outer, projections[p,s], certificates, queue, statuses, assumption_qualification`。它不应接收评价真值作为剪枝/选支参数。

结束标准在下一阶段运行前冻结：

- 先证明并独立验收5维包含扩张和完整树不变量，零参考误差退回A0、A1投影包含关系成立；一般R未实现时必须拒绝，不能静默对角化。
- 对预定有限合成例，保存完整输入、所有叶/队列与证书；独立读回证明未遗漏镜像、边界或预算队列。发现任何域内、噪声事件内真状态被排除即停止受影响实现。
- 新参数下的噪声维数和阈值有证书，所有数据身份去重；A2要求有效参考集合覆盖依据，无依据时只交付条件性A1结果。
- 统计报告全部计划案例和不可用类别，不以区域够小或所有案例成功作为结束条件。达到固定预算仍宽/未决也应完成交付，并判定当前可用性不足，不扩预算追求满意结果。
- 只有上述5维关通过后，另行决定是否实现两时刻；本轮没有自动升级，也未给出实车AL/PL/HMI数值。
