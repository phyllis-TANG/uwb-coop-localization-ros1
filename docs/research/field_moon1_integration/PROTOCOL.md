# 实测接入固定协议

恢复来源：2026-11-17月球重建会话最后指令要求合并PR128并接入可用实测包。PR128已合并，基线为7f02c403f513be70e64e90951bfe5633af356796；中断留下四个零字节文件，没有新运行。

本轮为最小接口与数值冒烟：固定015334、033248、050447三个包，各取bag接收时间1至20秒的整数时刻，独立与协同各一次，总共6次优化器调用；不看结果换窗，不追加批次。该窗口可能包含静止准备段，不声称涵盖完整动态过程。013206只通过已冻结静态校正参与来源链；045116继续保留PR128挑战证据，本次不新增求解。

复用two_car_updated_comparison.py的SE(2)模型、天线杆臂、伪Huber测距残差及解析Jacobian。每车20个(x,y,yaw)，总120维；本轮不移植Moon_1的M2/M3偏差状态。独立与协同共享全部输入、起始先验和初始化，只有协同增加peer因子。方法名称不与Moon_1 M0—M3混同。

CONFIG.json显式摘出历史协议的设施、外参、权重、先验、静态校正和初始朝向，不将动态终点传给求解器。固定校正源为two_car_updated_comparison_20261022/results/calibration.json，不重新标定。观测统一从PR128便携归档读取，先与原bag独立路径生成的输入逐字段比对。reference文件不进入估计接口。

时间采用共同bag接收轴，odom插值要求括点且不外推；每时刻±0.4秒各方向至少5条测距，墙测距取中位数，peer先分方向取中位数，再将可用方向平均成一个因子。保留方向计数，不把两个方向当独立信息。这是离线工程关联假设，不是时钟校准；完整窗口批量优化不是在线估计。

天线高度Car1=.17m、Car2=.20m，杆臂(.08,-.06)/(.12,-.08)m；四墙锚与校正来源于历史安装假设。odom消息child_frame_id为base_footprint，但本仓库没有充分证据确认它与人工近似底盘中心一致；初始朝向同样是历史摆放假设。所有结论均以这些假设成立为条件。

求解沿用历史trf/exact，max_nfev=100，ftol/xtol/gtol=1e-7，每方法仅一次。记录SciPy状态与物理梯度，另列1e-5梯度诊断；不为提高通过率调整容差。调用前持久化attempt，目录独占锁，任何已有RUN不自动重跑，孤立attempt保留待审计。

评价为残差、代价、数值状态、两方法天线位置变化及实际窗口运动量。没有连续真值，不计算全程RMSE、覆盖率、定位改善或保护级。全体六项（含失败）保留，formal_runs=0，不能视为六次独立实地实验。

验收：原bag与便携输入一致、时间/单位/标签身份校验、Jacobian中心差分、带先验秩、异常字段拒绝、独立方法对peer值不变。冻结后零优化器读回全部端点、残差、Jacobian、梯度、调用数及来源哈希。冻结代码和历史文件不得改写。
