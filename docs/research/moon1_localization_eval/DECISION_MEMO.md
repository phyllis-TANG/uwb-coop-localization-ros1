# 决策：接口可复用，暂不直接冻结正式性能矩阵

已完成原Moon_1的三个固定短窗口接入，具备下一轮受控定位研究的代码基础。保留PR114小高差结论，未改变轨迹放大效果。
本轮仅5个seed，人工信标、理想已知高度、已知运动噪声及预定候选偏差链路；180次中11次未达到冻结梯度标准。
因此不能直接宣称正式性能/95%覆盖已确认，也不应把11次改标为成功。

下一步优先级：

1. **独立数值稳定性验收**：保留本轮11次失败，针对冻结目标函数另立协议诊断停止条件、尺度和二阶行为；不得回填本轮结果。之后才决定正式预算与接受规则。
2. **冻结可信的观测与不确定性协议**：明确高度误差、先验来源、增量相关性、测距系统偏差/时间相关性及候选选择机制；用新seed和预定样本量评价，不混用本轮探索结果。
3. **分阶段接入物理仿真**：先平地单车/双车运动与传感器接口，再坡面和Moon_1地形。复用measurement/estimate契约与读回，但新的观测生成器必须来自物理/传感器输出；不把Isaac画面回放当动力学或定位验收。

此次Car2运动噪声增大和M1偏差传播都可在受控设置中观察；M2对常偏差有效主要受益于正确的模型族与预定链路。
不应据此承诺未知故障、多径、轮滑、姿态杆臂或真实月面条件下同样有效。
