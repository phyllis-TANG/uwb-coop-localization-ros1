# 参数与证据来源

| 参数 | 本轮值/定义 | 来源类别与限制 |
|---|---|---|
| NPZ、原双车轨迹 | PR114新资产，哈希见FREEZE | 已核验合成场景资产；LuSNAR并非真实月面实测 |
| 双车关系 | 同一原GT，Car1=t+5s、Car2=t | PR114生产代码；非两次独立采集 |
| 坐标变换 | 原GT (x,−y,−z)，m；时间s | PR114来源链；本轮不重复转换NPZ |
| 地形与GT | NPZ地形贴地body，原GT z另存 | 保留填补/平滑及来源限制，不重新宣称原始观测支持全域 |
| 天线 | body+[0,0,1.16]m | 历史配置；世界竖直简化，不是完整姿态杆臂 |
| 高度 | 每车每时刻参考高度给定 | height-oracle理想信息，不是可部署测量 |
| 信标天线 | (-5,±12,1.16)、(55,±12,1.16)m | 用户建议的人工几何；z研究冻结，无标定/安装误差 |
| 窗口 | 0/8/16s各6点，dt=.2s | 预先固定；全部处于NPZ 0…17.590822656s；不外推 |
| 测距sigma | .04m，单条单向peer | 用户给定研究假设；非月面实测，非旧CSV的.03m |
| 合成全局XY增量sigma | 正常.02m；Car2退化.10m | 研究假设，已知权重；不是轮速、IMU或历史/odom |
| prior | 正确中心+独立N(0,.5²I) | 假设存在独立无偏起点参考；不是将真值轨迹传给求解器 |
| 偏差 | 指定peer链路，0或+.3m | 受控常偏差；M2不读注入标签，无通用检测能力 |
| 初始化 | prior+观测增量累加+固定XY偏移 | 所有方法相同，不使用整段truth |
| 状态/因子 | 六时刻XY24；M2额外自由常b | 复用冻结movement和information，不修改A/B/C |
| 随机数 | CONFIG的5个seed、3条独立PCG64流 | 新研究配置；跨条件共用标准噪声，seed而非窗/车/时刻为重复单位 |
| 接受阈值 | 梯度∞≤1e−5、满秩、有限、成功退出 | 冻结数值标准；不是定位误差或安全标准 |

信标几何在查看带噪结果前冻结，没有按定位误差选布局。
矩形覆盖轨迹XY区域，但不意味着现实能在这些点安装设施；物理接入需确认地形、杆高、视距与设施位置误差。
