4. **实测完成固定窗B1响应**，尚不能做B2定位级验证或位置HMI；缺项具体见FIELD_PLAN/INPUT。T10恢复了旧尺量记录，但没有新的停车绑定或误差证据，accepted未变。
5. **工程SS可作为当前比较方案**；弱偏差、短故障、本车残余和可用性代价构成明确适用边界。当前不能据此断言必须新算法，也不能把基线叫作完整风险方案。

## 解释与边界

以seed为配对单位；PER_SEED含所有时段/共同可计算分母及XY/yaw/相对误差，PAIRED_NOMINAL按每种条件实际故障结束后10秒恢复窗及late进行相同索引正常配对。各单元episodes保留预先报警、延迟与删失；trajectory保留虚拟可获得时间和开销。混合bin与长故障后的2秒late均未删除。

尺度1在未用于本次调参的seed上进行确认；各故障、车辆和AL效果须按上表比较，不以“检测到了”代替所有HMI清零。增加偏差/持续时间可能同时增加越限与报警，可用率代价必须与HMI并读。AR(.7)仅改变两车墙raw噪声时序、边际sigma=.04保持；它是模型失配压力而非PR77实测估计。原peer/Odom/初始化随机流不变。

当前结果支持将含独立历史和共享噪声相关的工程SS作为当前比较方案；没有证据仅凭残余小AL HMI就必须新算法。剩余可研究机制是初始化可信性、时序相关下协方差有效性、持续故障与恢复历史的报警/可用性折中；本轮未新增门控、回滚、约束或学习模型。8个seed是小型模型条件验证，零事件不是零风险，不认证罕见风险/PL或实车闭环实时性。
