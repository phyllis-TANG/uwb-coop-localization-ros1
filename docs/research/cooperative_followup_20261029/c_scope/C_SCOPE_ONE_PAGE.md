# 10月29日会议范围建议（任务C）

**结论：贡献尚未成立。** PR72在一个已暴露seed的两个条件下，验证了双车实际天线XY相对全历史peer-free参照的图内预算与完整联合prior；这证明可实现的输出合同，不证明新颖算法、绝对精度或完整性风险。4cm只是解释性开发预算。[PR72报告](../../../field_tests/20261024_25/cooperative_influence_probe_20261028/REPORT.md)中，故障窗K004相对同预算裁剪C004的Car1/Car2 RMSE仅改善0.579/0.105mm，恢复窗Car2反而恶化1.001mm；SLSQP关闭预算路径本身已耗时约34秒/63帧。当前应停止扩性能矩阵。

已发表工作的覆盖很近：Hafez等[RA-L 2020](https://doi.org/10.1109/LRA.2020.2975769)的§II-B Eq.(5)、§III–V已覆盖fixed-lag解分离、先前故障进入prior及风险/可用性区分；Olawoye–Gross的[2026全文](https://doi.org/10.3390/app16105137)§2.1/4/5覆盖坏移动参照、LOO/LTO、低冗余不归责和投票。Wang等[ASR 2026公开预览](https://www.sciencedirect.com/science/article/pii/S0273117726013074)已明确说到信息缩放、配置一致working prior、可信检查点和跨历元验收；**全文/公式仍未获得**，不能宣布“历史恢复”未被做过。PR71既有QA-DSE、DECLARE、DCS审阅也已覆盖质量权重、历史可信折减和鲁棒抑制的基本方向。详见[C_NEAREST_WORK.csv](C_NEAREST_WORK.csv)，各行把原文与推断分开。

若继续主张方法，必要性门槛是：先定义一个直接裁剪/固定缩权确实无法满足、且两车现有可用输入可判定的需求；给出因果决策与失败语义，并在同预算、同参考覆盖、同时间窗下证实逐车帮助/伤害、unknown/回退、历史残留与恢复、计算代价的**净收益**。不能把非线性轨迹不完全相同、预算满足或求解收敛本身称优势。若主张概率完整性，还须另建故障先验/风险分配、相关不确定度和独立验证；现有4cm三角不等式只约束相对参照的误差变化，不认证参照。

可讨论的窄问题是“有限冗余、参照可污染时，何时采用/拒用peer以及如何解释历史影响”。但两车仅一条peer距离对测距偏置、任一车沿视线位置偏差与共同偏差通常不可唯一归责；unknown是诚实输出，也已有文献先例。若拿不到ASR全文，或找不到超越简单裁剪的必要需求，就把本阶段写成**可复核的影响预算合同与失效边界/负结果**，停止新机制主张；现场工作仍可独立补参考。10月30日先按[预检清单](LAB_PRECHECK_20261030.md)验收参考，达A才谈连续RMSE，达B只谈稳定停点，C只作诊断。
