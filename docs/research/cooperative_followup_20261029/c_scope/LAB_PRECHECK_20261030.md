## 用途与数值容差草案，待10月29日讨论后在看算法误差前冻结

设目标待分辨的**实质性效应**为 `Δ_min`，两种方法差异的合成参考/重复性不确定度为 `u_Δ`；建议必要条件 `U95(Δ) ≤ Δ_min/3`，并在配对差值报告置信区间。对于绝对天线位置用途，逐轴/总位置参考的扩展不确定度 `U95,xy` 建议也不超过预定可报告改进的三分之一；这是设计门槛草案，不是现有设备已达标。参考预算须含点位量测、尺度/内参、逐片相机外参、板形变、marker→天线杆臂/转角、像素提取、时钟映射与运动项；动态时间项至少按 `v_max·u_t` 进入（转向时另计角速度×杆臂）。项目要先决定 `Δ_min` 与最大速度，才能把这些式子换成毫米阈值。

**讨论示例**：若只希望分辨2cm级逐车位置改善，可暂定 `U95,xy ≤ 5mm` 且独立Q最大误差≤10mm，随后用误差传播和重复量测检查是否实际可达；若不可达就调低主张或只评价更大效应，不能按结果放宽。若目标是PR72对裁剪的约0.1–1mm差异，5mm参考显然不够，现有视频材料没有支持这一级别评价的证据。4cm开发预算既不是绝对位置容差，也不是论文主预算。检测成功率、重投影/拟合残差或尺子最小刻度均不能代替 `U95,xy`。

A连续：空间独立Q、两车天线外参、同步界和全路段覆盖均满足冻结容差，才允许动态RMSE。B停点：量得实际天线位置且停车窗可靠，但动态时间/覆盖不达标，只对那些停点报误差，不插值全轨迹。C诊断：身份/原始话题/标记可读或空间时间任一关键链缺证，只报诊断。各级按独立参考验收，不按算法结果或录包数量决定。
