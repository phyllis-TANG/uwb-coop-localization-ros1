# B一页结论：必须先补可信信息

**决定：必须先补可信信息。** 当前不提出新候选机制，不进入B4静态二维或FGO性能试验。
这是针对“选择相信谁、定向保留帮助并限制损害”的条件性决定；若只需对等相对影响预算，现有廉价裁剪已可履约，不必把参照先认证准确才使用该有限合同。

| 证据类别 | 本轮结论 |
|---|---|
| **自己实际重算** | 计算前登记两个一维解释，精确有理数核验：局部位置/正确peer/同类运动增量相同，但A为Car2准确、B为Car1准确；等精度箱约束与同预算裁剪严格相同。4cm实际天线位移预算成立时，有偏方仍可有26cm绝对误差 |
| **仅核对汇总** | 从PR72原表重算K004−C004：故障窗Car1/Car2为−0.578934/−0.105053mm，恢复窗Car2为+1.001213mm；同分母14/10。成本U也昂贵，主要代价不能算成约束方法本身的收益或代价。未从原轨迹重算RMSE |
| **引用原报告** | PR72私有全历史peer-free参照、完整联合cross/affine prior、实际双方天线预算与失败合同已实现；单个已暴露seed101/两条件，不是独立性能验证。4cm为解释性开发值，非论文主预算或绝对安全保证 |
| **新建议** | 先拿到能区分可信角色的独立绝对信息及其有效界，或明确一个裁剪不能满足的实际额外合同；再给候选及简单基线完全相同的信息/预算/评价条件，讨论是否存在必要差异。当前没有这类证据或候选 |

**为什么先停：** 本误差类允许正负局部位置代理偏差；相同观测的两个解释要求保护不同车辆。只依赖这些输入，不能统一保证“准确车不被移动”又帮助有偏车。限制准确车最多b的统一要求退化为双方都限b，并同时限制帮助；对称一维恰与裁剪等价。这是代理模型的必要条件，不是原始四锚/任意几何的普遍不可能定理，更不是单seed证明所有约束方法无用。

**哪些真实信息能改变判断：** 同次、同状态可绑定的独立静态天线点或经检验绝对初值及有效误差界；若移动还要有可传播并会到期的运动误差界；peer的安装/时钟及测距适用界。小协方差、残差小、车未动、peer-free或求解收敛都不能替代。具体缺项和用途见B_ASSUMPTIONS.json；本轮未采集这些信息，当前界为null。
先核对现有原始锚点冗余、初始化和既有测量是否已能提供这些信息，不默认新增传感器或路线。经过校准的概率先验可改变期望损失决策，但不等于本例要求的统一确定保护；若改用概率主张须另定风险模型与验证。

**候选必要性尚未成立：** 固定正缩权不自动提供硬预算，γ=0又无协同帮助；同预算输出裁剪可以给现有位移合同，但不认证参照准确。仅加约束、保留历史或换SLSQP不是新贡献；若额外可信证据也让简单裁剪达到同一实际要求，就仍无候选继续依据。
