# B：先判断可辨识性，再讨论机制必要性

## B1　四个命题不等价

设同一时刻两车实际发布天线XY为a_i、从启动起无peer信息的参照为r_i，预算为b_i。

| 命题 | 真正需要证明的内容 | 本次证据地位 |
|---|---|---|
| 候选满足预算 | 每次已认证发布均有 `||a_i−r_i||≤b_i`，含旋转杆臂、两车、失败/unknown分母 | PR72原逐发布审计支持；本B仅引用，没有重验完整journal |
| 保持帮助 | 对同一真值、同状态集合，明确谁的误差相对独立参照变小、多少；不能只看peer残差 | PR72有限开发例保留部分帮助，同时限制帮助；不代表保留全部 |
| 优于同预算裁剪 | 相同信息/预算/损害定义下，有实际需要的稳定收益或裁剪不能满足的合同 | PR71对称一维严格等价；PR72二维有差异，但故障窗亚毫米收益与恢复窗退化并存，尚无必要优势 |
| 绝对安全保证 | 独立参照误差、时空安装、有效期及失效模型有可信界，再关联任务容许误差/风险 | 没有这类证据；4cm相对影响预算不是4cm绝对精度、保护级、概率完整性或yaw保证 |

预算的三角不等式只给同一真值的 `|e_joint−e_ref|≤b`。同一个固定样本集合进一步有
`|RMSE_joint−RMSE_ref|≤RMS(b)`，不需要假设两图独立；但也不使r准确。
若另有经独立认证的 `e_ref≤E`，才可推出该有效域内 `e_joint≤E+b`。
故障相对正常的差还涉及两种情况下参照自身的改变，不能仅由b推出；未约束yaw亦不能套用。

PR72保留完整cross/affine prior、私有peer-free参照，是合同的重要实现条件；当前peer权为0不清历史，
这些条件不自动增加外部可辨识信息。C保持J内部历史、只改发布，K改自身活动状态，二者确有不同；
若没有另行定义“必须保持何种内部/发布一致性”的实际用途，不能以内部不同证明方法必要。
两者61/61参照有效时刻都可发布；C的post_clip不能因名称不同被算成缺少可用性。

原墙/peer均已有pseudo-Huber，本B一维二次模型只是PR71代理模型，不声称是PR72原非线性鲁棒目标。
SLSQP关闭控制U已经昂贵；换数值路径不能计为方法收益。本B无求解器更换。

## B2　观测相同、可信角色相反的最小例

把每车局部绝对定位压缩为天线中心位置代理：

`m1=x1+β1, m2=x2+β2, r=x2−x1`。

明确允许：β可正或负，未知哪一车有偏、至多一个非零、幅度≤0.30m；peer在本例准确，车序已知，
时钟/安装理想。同一类运动输入只提供各车相对增量。初始绝对位置没有另一个经认证的硬界。
局部二次权是设计权，不是经过认证的无偏协方差。

| 完全相同的在线量 | 解释A（仅评价可见） | 解释B（仅评价可见） |
|---|---|---|
| m=(0.30,1.00)m；r=1.00m | x=(0,1)m | x=(0.30,1.30)m |
| 同一观测源/权/运动增量 | β=(+0.30,0)m，Car2准确 | β=(0,−0.30)m，Car1准确 |

B将两车同时平移0.30m；各车Odom增量和双方相对位移不变。对任意已观察运动函数x_i(t)，
替换 `x'_i(t)=x_i(t)+c`、`β'_i(t)=β_i(t)−c` 保持这些观测相同；本例两端都满足“仅一局部源有偏”。
固定车序使距离观测也相同，且我们已经额外给了定向和准确peer，歧义仍在。
若初始化/记忆也只由相同可用信息构成，它们不能生成新的区分证据；带独立可信初值则是不同假设。

**限定的不可辨识结论：** 在这个误差类/代理观测图上，映射不是一一对应。任意仅依赖这些信息的
确定性策略对A/B输出相同；随机策略的条件输出分布也相同，不能以随机化获得两世界统一确定保证。
若要求对任一可能准确的车零损害，A强制δ2=0，B强制δ1=0，因此只能δ1=δ2=0，无法同时定向帮助。
若允许准确方最多改变b，则统一保证迫使两车都受b约束，有偏方能得到的误差改善也至多b。

本例观测间距比正确r小0.30m。若两车都只可动b，仍有peer残差至少 `max(0,0.30−2b)`；
解释性b=.04m时为.22m。更小拟合残差不是准确方的证明。

**不能推广的范围：** 这不是所有四锚原始UWB、所有几何、所有时变故障或完整PR72轨迹的不可能定理。
压缩位置代理可能丢失原始锚点的冗余结构；若给已认证健康绝对观测子集、可靠初值和运动误差界，
或可信偏差支持/方向假设，观测模型已改变。raw NLOS常见正测距偏差也不能直接升级为全局XY代理误差同号。
本B没有检查原始四锚可辨识性、没有给PR72某个实际时刻贴“不可辨识”标签。

可以打破这两个解释的额外信息例子：同次独立证书限制 `|x2−1.00|≤ε` 且ε<0.30m，则B被排除；
理想准确初值及准确运动也能作此证书。这个0.30仅来自二例之间的分离，不是新验收容差，亦未提供给本次任何对照。
有测量噪声时须检查两种解释的可行集合是否真正分离，证书失效/过期后不能沿用可信角色；
若证书或其他可靠先验已存在，必须承认问题已可辨识，不能继续套用这里的无证书结论。

也有必须承认的理想可辨识边界：若“准确peer、无随机噪声、至多一个局部偏差”均为可信假设，
且观测间距恰好等于r，则β1=β2并由至多一非零推出二者都为0。不能将本例有冲突时的歧义泛化到该情况。
实际还要求考虑共同源故障，不能未经证据排除它；在这个更宽误差类中β1=β2=c可令相对量完全一致、
协同改变为0而绝对误差仍为|c|。这是符号边界分析，不是第三个数值配置，也不属于B2的单偏差子类。

## 自己实际重算：两个解释、同一输出

预登记权a=b=1、gamma=25；b=.04m沿用解释值，不调参。以下为实际一维天线位置及各解释绝对误差，单位m：

| 方法 | 输出位置 | A误差Car1/Car2 | B误差Car1/Car2 |
|---|---|---|---|
| I | (.300000,1.000000) | .300000 / 0 | 0 / .300000 |
| J解析联合 | (.152941,1.147059) | .152941 / .147059 | .147059 / .152941 |
| C输出裁剪 | (.260000,1.040000) | .260000 / .040000 | .040000 / .260000 |
| K对称箱约束闭式 | 与C严格相同 | 与C严格相同 | 与C严格相同 |

在线输出只算一次，再用两个解释评价，真值/健康标签不进入输出函数。C/K均在实际天线位置上满足预算；
但A的Car1或B的Car2仍有.26m绝对误差。算法不能由同一数据知道哪一项.04m是帮助、哪一项是伤害。

等精度的一般闭式也说明必要性边界。设δ_i=a_i−m_i、k=r−(m2−m1)，令s=(δ1+δ2)/2、
t=(δ2−δ1)/2，则目标为 `w(s²+t²)+gamma/2(2t−k)²`，约束为 `|s|+|t|≤b`。
对任何可行t，s=0既可行又最优；故 `t=clip(gamma*k/(w+2gamma),−b,b)`，与逐车裁剪无约束解完全相同。
本次用有理数检查J梯度为0、H正定、箱约束KKT、C=K、实际位移预算及误差变化界。
没有SciPy/SLSQP、数值路径优势、2D试验、种子或FGO运行；详见results/exact_worlds.json。
