# A/B下一轮结果的条件式决策表

本表不预设结果，更不是执行授权。所有“验证”均为下一轮建议；本轮定位调用为0。固定起点PR115/116见README，不读取其他窗口未完成结果。文献标号见LITERATURE_MATRIX，优先路线仅METHOD_OPTIONS中的两条。

## 先通过比较身份检查

所谓“线性参照”必须是同一输入、同一信息范围、同一固定/随机先验机制下**直接求解的真值仿射模型**，并将它自己的估计误差与对应解析传播比较。PR116的`oracle_truth_GN`是非线性误差配真值处宽度，不能代替它。真值参照仅作理想诊断，不可部署，也不增加独立seed。

所谓“改善/异常”应同时写出误差、区域尺寸、覆盖、不可用和数值接受分母，以及seed配对不确定性。点估计变化、区间跨零或区间包含名义水平都不是等效性/因果证明。多终点组数量按同样阈值与接受规则比较，不能事后重定分组。

## 每一条结果都必须保留的三种分母

令N为计划独立seed数，A表示算法输出了满足合同的有限区域，C表示该区域覆盖真位置。分别列：可用率$n(A)/N$，可用输出中的经验覆盖$n(A\cap C)/n(A)$，以及全计划成功覆盖比例$n(A\cap C)/N$。后者不是把不可用的误差强填零，而是明确的事件计数。无输出与输出危险位置属于不同结果。

若有告警阈值AL，再单列$A\cap\{\text{error}>AL,\text{no alarm}\}$；这和覆盖事件不是自动相同。拒绝输出不能从计划分母消失，也不能用“拒绝所有输出”制造完好性成功。六时刻若有任一不可用，必须按预定联合事件规则处理，不删时刻后仍叫完整轨迹覆盖。

## 升级和停止准则

- 先修复身份/代数合同，再讨论非线性机制；每次只推进METHOD_OPTIONS的一条最小验证，不混合多个修正追求更高覆盖。
- 出现模型外故障、未知真实噪声、无依据D或无界状态域时，先补定义与外部证据，不用增加Monte Carlo次数绕过缺口。
- 若关键删边假设失秩或关注方向不受约束，SS在该条件上应不可用；未来可提出补测量或限制适用范围，但本轮不修改其他窗口协议。
- 若完整外包在可接受资源内始终过宽，应保留这一技术结论；不承诺改善、实时部署或发表结果。研究目标仍是可解释、可验证的安全量化。
