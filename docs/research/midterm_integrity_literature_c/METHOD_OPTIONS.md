# 条件式方法建议：保留安全量化目标，最多推进两条路线

本轮只推荐两条优先候选，**现在均不实现**。排序依据是当前缺环与方法假设是否匹配，不是预设覆盖一定提高或论文一定可发表。L1–L5的原文页码、公式号和访问版本见LITERATURE_MATRIX；本项目代数扩展见THEORY_AUDIT。

## 1. 第一优先：完整非线性测量模型的置信集合反演与有证据外包

**研究问题。** 当真值共线、多个终点组和局部覆盖失准并存时，是否能用生成噪声事件定义一个保留全部可行分支的状态区域，从而避开“估计误差Gaussian”和“单个Hessian逆就是区域”的假设？依据是L1的Gaussian噪声事件反演、L2的区间包含计算。排序第一因为它直接面对PR115/116尚缺的非线性/分支包含问题，不需要先宣称已找到唯一正确终点。

**范围。** 初期作为离线可信参照或区域计算模块，保留原定位中心；不立即写新定位器，不同时引入未知故障检测、鲁棒核和先验学习。B2已知候选常b可以作为待估参数，固定survey误差必须作为外部有依据的约束D。若没有可辩护D，应明确不使用该硬约束或只给条件于D的机制结论；不能用覆盖反推一个合适半径。

**原理和可迁移部分。** 使用完整随机观测噪声的联合置信集合，对原非线性测量关系作反演，再投影到目标车辆位置。D和固定状态域不是随机噪声行。外包保留未决盒与所有可能分支，区域可以不连通；不依赖某终点H可逆。不确定性区域与原估计中心分离，有助于判断是区域遗漏分支，还是定位器输出选错了位置。

**迁移成本及可能失败。** 当前模型是74个随机数据分量、25维状态；全文中的低维示例不说明这一规模可高效处理。区间包络可能极宽、域不有界、边界很多或预算耗尽。只有声明域内的外包不能声称域外保证。完整非线性函数与严格包含计算可以避免Taylor截断；若改走局部Taylor余项，只能作为另外单独冻结的替代构造，不能把未证明余项默认为零。

**最小验证分两关，禁止一起调参。**

1. **概率与实现关：** 一个固定满秩仿射模型，独立QR解/解析噪声事件对照，明确完整噪声维数m、先验不随机化、固定偏移在集合内/外的身份。检查对每个满足噪声事件的输入是否包含真状态；这里的包含可作解析/确定性检验，未来随机试验只辅助检查。
2. **非线性/分支关：** 一个有可穷尽镜像双解的低维测距模型，固定域、偏移集合、计算精度和预算，检查两支/域边界/未知盒均保留。再在同一合同下加入小的非共线扰动；不能用真值挑选搜索盒或优先分支。

通过上述两关后，才决定是否扩到六时刻24/25维。若A/B新结果显示异常主要来自数值未接受而非区域近似，应先完成数值合同，暂缓该扩展。若全域集合确实很宽，应报告信息不足或算力下不可用，不把它解释为定位器“坏”或用裁剪恢复好看的PL。

**否证条件。** 在已声明搜索域、真实噪声事件和D内存在被认证外包排除的真状态，否定当前实现/包含证明；存在未搜索但合法的分支，否定全局主张；预算内无法得到有限且有意义的目标投影，否定当前条件下的可用性，不否定集合理论本身。

**从区域到保护级的出口。** 必须再给任务误差、告警限、输出事件、故障覆盖和尾部/计算误差合同，才可对外包求半径并定义PL。当前只提出模块路径，没有完成这些环节，也没有设定最终风险数值。

## 2. 第二优先：带逐假设可辨识性门槛的solution separation

**研究问题。** 当已知候选常偏差的机制清楚后，能否把未知故障位置写成有限预先声明的假设族，通过全解/排除子解的分离事件量化未检测危险误差？依据是L3的机器人固定窗完好性结构和L4对估计—检验选择分布的警示。它更直接连接HMI事件，但当前的未知故障、真实先验及非线性条件缺口更大，故排第二。

**只借一个模块。** 首阶段仅审查有限故障族的可监控性与线性SS事件关系，不把“状态增广＋任意候选检测＋多峰概率＋集合包络＋鲁棒核”一次拼接。B2增广解决的是模型表示，SS解决的是故障假设与报警关系，两者不是互相替代的同名算法。B3依赖真注入，不能作为实际SS检测正确的证据。

**准入条件。**

- 明确故障发生的观测集合、是否跨六时刻共享、是否多链路、是否包括先验/运动故障；幅度可未知，但真实类别须在监控族或单列未监控项。
- 全解及每个排除子问题在关注方向上有可解释信息；若采用原文完整逆信息公式则必须满列秩。参数b在删除其全部支撑观测后须重新定义模型，不得保留无信息列再加ridge。
- 固定survey与原文随机历史先验不同。协方差、全解—子解相关性、残差分布和阈值都要按真实随机块推导；不能把4行固定先验当作多出4个独立随机观测。
- 相对变换、候选选择、拒判均纳入最终输出映射；不能在“选择正确”样本中校准后将结果作为全计划风险。
- 公共原文CS式(36)/(39)的尾概率不一致尚未核实勘误，不能据该表达写风险代码；SS主事件可从三角不等式独立重推。

**最小验证。** 先固定一个仿射模型和一个有限故障族，不添加新噪声学习。逐假设核查删行后的秩/弱方向、全解与子解协方差、分离统计，以及告警/无告警且超限/无告警未超限/不可用四类事件。故障幅度范围及数据选择规则先登记；必须包含会导致低冗余或失秩的负例。只有线性合同通过且真实先验机制明确，才讨论非线性固定窗。

**否证条件。** 若存在允许故障使所有可用子解都仍受污染、失秩或关键方向不可辨识，该假设族下SS不能给可用保护级；若解析线性分布不吻合，不能用更复杂非线性解释掩盖；若不同子解停于不同未控制分支，局部Gaussian SS界不能直接迁移。解决这些问题可能需要改变传感信息或限制适用场景，不能仅调检测阈值。

**为何不是第一条。** 当前toy虽有不少观测行，共线有效方向仍薄弱；实际机器人网络删一条关键边可能破坏锚定。L3并没有证明“低冗余下必可保护”。没有故障率资料时，可先做每假设条件界或全允许故障最坏界，不填任意P(H)，也不先宣称总体罕见风险。

## 3. 不列为新增优先路线的模块

- **仅把GN换为精确H：** PR116已正确用GGᵀ，当前缺的是有限扰动、分支和真实误差集合；精确导数不等于精确覆盖。仍可作诊断，不是独立安全路线。
- **仅多初值/有限混合Gaussian或NBP：** L5适合展示多峰与设计小问题参照，但有限粒子和端点分组没有全模式遗漏/尾部质量保证；不作为第三条优先实现建议。
- **仅膨胀rho/协方差或增加Monte Carlo次数：** 可以改变经验指标，不能补充独立偏移依据、故障覆盖或计算包含证明。

两条路线可长期互补，但本次不推荐同时实现。下一步先由DECISION_TREE选一个失败机制和一个最小验证，固定证据后再决定是否升级研究范围。
