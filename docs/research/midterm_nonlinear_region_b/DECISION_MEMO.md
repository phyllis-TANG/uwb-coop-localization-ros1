# 下一步：先改进约束传播，再谈短窗口

本轮数学包含关系闭合，八例的具体外包证书通过。可接受的是低维、已知噪声、预定候选偏差及有限域条件下的原型；不是最终保护级算法。

优先改进约束传播。理由是加入一个b后good/mirror盒数已增加约12–13倍，大量保留盒仍为边界未决；当前自然区间扩张对重复变量和单链路b有依赖膨胀。短窗口会同时增加变量、运动约束及分支，现有秒级低维例不能证明扩维可行。

建议下一轮仅选择一个改进并另行冻结：利用测距平方差或保守承包算子收紧盒，必须维持包含性并用本轮原证书体系复核；比较同域、同阈值、同输入、同盒数预算下的未决体积和认证成本。不能用局部最优解或真值先缩域。若约束传播改善后再做两时刻极小窗口，应先明确完整噪声维数及相关R，不跳到25维批次。

同时推进实际域/偏差范围和噪声协方差的独立依据。当前Ω、b范围及已知参考车位置均为降维仿真假设；若最终任务允许域外、错链或多链路故障，必须扩充模型与失包含事件，不能把本轮条件性保证直接搬到平台。

镜像例提示区域接口应保留多分支盒并集，必要时另报包含全部分支的圆；圆很宽是可用性信息，不应通过选支隐藏。预算中止须保留队列；空集、边界接触、数值异常与宽区域分别处理。任务级风险、长期轨迹及告警接口仍待定义，本轮不自设风险分配，不自动追加实验。
