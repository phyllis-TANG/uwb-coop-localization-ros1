# 会议：围绕一项可检验贡献候选

**候选题目：排除目标仍可能误归责：固定窗口UWB融合中参照污染与历史残留的证据审计。**

只选这一项候选贡献：以量测配对、真实入图倍率与有界干预区分“量测变坏”和“用于判定的参照变坏”，说明排除目标链并不足以保证独立健康参照。它是待文献查重/导师判断的机制分析贡献，不是已认定新算法、全域理论保证或泛化性能改进。本轮没有查新，不宣称首创。

可检验中心命题：在冻结的单车固定窗口质量控制设计中，其他链故障可以污染某健康目标的排除图；即使该目标量测与正常完全相同，仍可能连续越阈并真实削弱其主图信息，且当前倍率恢复不保证历史影响消失。明确适用条件与不触发反例，不能写成“所有排除图都会失效”。

| 章节 | 核心内容 | 已有/待补边界 |
|---|---|---|
| 1 问题与贡献陈述 | 区分实现、入图动作、真值性能；参照不是独立真值 | 用PR61正常/共同原因负结果引出，不以月球标题替代创新 |
| 2 冻结系统与假设 | Q0=F0、Q1=F3；Q2/Q3加逐链排除图判定；原pseudo-Huber、20s窗口、因果截止及相关先验 | 先给配置/数据/代码SHA；工程分数非NIS/PL，无概率完好性 |
| 3 可核查的归责证据链 | measurement−prediction=(measurement−truth)−(prediction−truth)；配对输入、分数、FSM、sqrt(g)、原因子/先验来源 | 对目标排除成立不意味着其余链干净；来源计数不是贡献比例 |
| 4 主实验：单链误归责 | PR63全部8健康链事件与counterexamples、晚发ramp事件；修订后的null-bias图 | 分析复用原96组，不把事件当新增独立运行，不按触发点再调阈值 |
| 5 历史与共同原因边界 | 3个共同原因seed、yaw/bias错误自洽；既有D1倍率干预、D2 prior-only条件干预和变差反例 | 干预是已保存机制诊断，非可在线取得的修复；未分解全部因果份额 |
| 6 真实开发包的适用边界 | PR65两包Q0–Q3动作/入图独立核验、冻结停点混合结果与真实flush成本 | 实包无完整故障标签，不能证明上述健康链误归责在实包已被独立定位；不报全程RMSE |
| 7 讨论与限制 | 独立性/可辨识性、unknown、历史重建作为后续问题，月面仅应用动机 | PR62只作不同系统的相关线索，不纳入本文单车机制因果链；不加入新主动恢复方案 |

建议主图为FIGURE_GUIDE F3/F4，附PR65完整双包停点表、正常代价和反例表；PR62 F5放项目背景或补充材料，不将两套数据/seed/时钟拼成一个双车实验。

当前可写：“在给定设计与受控合成条件下确认了误归责及历史先验条件效应；真实开发包证明动作确实入图，位置收益混合且参考有限。”不能写：“提出并验证可靠双车质量准入”“完全无鲁棒基线被改进”“已证明真实多径检测率/定位提升”“已完成在线安全恢复”。

最小还缺：导师是否认可机制/审计类贡献及目标会议；针对相关排除/冗余参照和固定窗口历史管理研究的文献查重；若要求总体实测位置收益，按MINIMUM_COLLECTION另批参考与验证规模。若会议必须有新算法，本包不满足该项，需另立预登记任务而非把现有FSM重新命名。
