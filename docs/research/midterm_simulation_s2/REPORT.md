# P-S2 B端：单常值偏差增广开发结果

完成6时刻双车XY的B0/B1/B2/B3、数学检查与小规模开发。没有启动正式验证；本轮结果仅支持原型及诊断，不支持“已验证增广方法稳健优于基线”。基准PR97固定df323eccdffd375a2fb255ebbfd734b6c2be4aac，执行版本见PROVENANCE；数据全部为本任务合成，原始实测与历史结果不变。

## 实现与假设
直接复用PR97 design/model/movement，24维位置或25维位置+单偏差。B0不含peer，B1协同不估偏差，B2协同估单常值，B3准确扣除注入量。没有生产M2/M3命名或8维后端移植。全局XY位移因子比实际未知航向轮速模型更强。

B2预知候选受影响链路；零偏差时也拟合该候选链。B3另外知道真实注入量。两者均不能代表完成了故障识别。B2不加偏差prior，不限制偏差正负。位置prior为第一时刻两车XY的模拟观测，正常含噪sigma=.05m；有偏prior在同一随机误差上加[.15,-.10,-.10,.15]m。求解只读取观测、先验和初值；truth仅由生成器/评价器使用，B3专用接口单独接收oracle补偿。

对于已知链路且没有bias prior的常值增广，观测增加常数、bias状态同步增加同一常数会保持目标函数不变。这是本模型的代数性质，因此B2在0和+.3条件下位置结果近乎一致本身不能当作未知故障泛化证据。

## 数学与复核
12种几何/运动/链路解析雅可比差分最大9.244216503390135e-10，低于预登记1e-8。独立欧氏距离公式核对、正确真值处残差为零、良好几何B2/B3无噪声恢复检查通过。192单元共享输入复核通过；96个peer条件的B0有效输入SHA和输出严格相同。B3在全部条件中与同噪声无注入B1的最大坐标差4.440892098500626e-16m。独立MSE/D重算最大差2.168404344971009e-19，残差重算差0。来源锁未变。

无先验、共线静止B2真值点数据+运动秩23/25；精确退化点的独立求解检查保留CONVERGED_RANK_DEFICIENT和null协方差。人为max_nfev=1的检查保留NOT_CONVERGED及最后估计。两个诊断检查在CHECKS.json中，不混入768主开发运行。

主运行的256个方法案例在参考真值处数据信息秩不足，但最后迭代点均按固定1e-8阈值算满秩。弱共线情况下离开退化流形的微小横向数值偏移即可改变局部秩，因此**不能用最后迭代点满秩推翻退化分析**。两类秩均保存，参考真值仅用于离线数学评价。

## 开发范围与失败

## 不确定度与开销
局部Gauss–Newton协方差由已知观测sigma白化后的J经SVD计算，包含实际启用的位置prior，不根据残差再缩放；不加ridge或伪有限正则。秩亏则null。尺度XY1m、bias.1m，阈值相对1e-8。最终迭代不收敛时保存的矩阵只是该点局部信息逆，不是经验证的不确定度；弱几何近奇异、非线性、有偏prior均使其解释受限。不计算或宣称保护级/完好性/实车精度，也不报告经验覆盖率保证。

768次求解累计约3.17s，中位约3.62ms，最大约20.17ms，仅本机求解调用耗时，包含局部矩阵计算，不含文件/绘图全流程，不代表实车实时性。逐次耗时已保存。
