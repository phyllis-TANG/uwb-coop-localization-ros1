# 判定标准如何固定：先来源，再数值

本页是研究决策规则草案，不批准部署损害容差、不定义新算法。机器可读清单见TOLERANCE_SOURCES.json（未知为null），CSV为空值；不能将未知填0。

## 已固定的评价合同

1. 同一状态、坐标、观测前缀和参考；同信息简单基线也能使用四墙线索。I始终全历史peer-free，但不是绝对真值。
2. 主结果逐车列XY误差、相对I的有符号ΔRMSE、正新增损害的峰值/均值/固定窗离散累计。相对位置/间距沿用PR78完整METRICS，不用更小peer拟合残差代替。航向必报副指标，不能藏在XY均值里，也不因本次结果而临时定义为新算法硬约束。
3. 正常、故障、恢复、晚段、当前窗口干净段均保留；故障条件边界仅用于离线评价。恢复“何时完成”需要另外冻结在线触发、误差容差、持续判据；目前没有这个时间指标，不用20秒当恢复保证。
4. unknown、预测、回退、失败、未发布与成功分开。共同accepted和全部有限发布并列；派生裁剪不是联合优化成功，不拼后验协方差。
5. 不压成一个团队加权总分，不默认“帮助1cm可以补偿同伴损害1cm”。计算成本单独看；现有主图/参考/裁剪计时和不同执行来源分开，不制造跨时机器加速比。成本源表为 ../history_recovery_minimal_20261029/COSTS.csv，本轮不新增计时实验。

## 三个不同层次的判断

**算术关系（本轮完成）。** 对相同样本集合，A各指定指标都不大于B且至少一项较小，是该集合/该指标向量的算术支配。1e-12是浮点比较epsilon，不代表实践等价；主方法在全阶段没有算术支配。图只画已有离散配置，不连出不存在的参数前沿。跨不同预算的点可描述但不能归因于同预算算法收益。

**实际研究优势（当前未确认）。** 需要预先说明值得分辨的帮助增量δ_help、允许的逐车退化δ_harm/δ_normal及必报副指标处理规则。若无用途支持的损害容差，不能用“无显著差异”代替非劣；可以只报告取舍。未来若具备合格独立重复与配对参考，可要求帮助差的不确定区间下界超过δ_help、代价差上界不超过已批准δ_harm；具体覆盖/统计设计必须另登记。当前一个已暴露seed不能生成这种通过结论，也不能将63个相关发布当63次独立试验。

**部署允许代价（当前不适用）。** 需要实际任务的总位置/yaw/时延预算，再分配给协同造成的新增影响。没有闭环任务指标，不宣布任意1cm/4cm安全，不为证明图内方法必要而人为增加一致后验、动态连续性或内部历史清理要求。简单基线获得同样预算及状态处理权利。

## 数值从哪里来

- **用途/研究尺度：** 先写清要辨别的效应为什么值得；不得从当前K004对C004约亚毫米差倒推。论文愿意报告多小效果是研究选择，不等于硬件安全标准。
- **评价分辨能力：** 独立参考的空间、安装、时钟及重复性合成，传播到真正比较的配对差值。共享参考相关误差可能抵消也可能不抵消，不能直接令U_delta=U_single，也不能以相同参考自动认定误差相消。采样密集不等于独立重复。若能力不足，降低主张或缩小适用范围；不据此放宽允许损害。
- **成熟文献/标准：** 用于指标、测试组织、来源深度和合理比较方式。ISO/IEC18305公开说明/目录覆盖定位评价及延迟、可用性等；本轮只核对公开摘要与目录，未阅读全文，不声称认证符合该标准。它们未给本项目一个可直接采用的厘米损害线。[ISO说明](https://www.iso.org/standard/62090.html)、[NIST目录](https://www.nist.gov/ctl/pscr/isoiec-18305-2016-table-contents)。
- **不确定度方法：** NIST建议先定义所报告量，再考虑重复、随机误差、偏差与其他分量，通过测量模型合成。本项目据此要求对配对方法差定义测量模型；不把既有建议U95≤δ/3当作NIST强制值。[NIST步骤](https://www.itl.nist.gov/div898/handbook/mpc/section5/mpc521.htm)。

## 当前去留决定

保留成熟基线和历史机制证据；暂不扩张图内硬约束贡献。此决定不是G2“所有简单方法已足够”，而是“必要优势及实质容差尚未成立”。不选新主预算、不用旧条件拟合新的通过标准、不消费留出。若继续，下一项独立工作是整理原有实际XYZ/安装/同步与重复性记录的来源和不确定度；PR77所述历史C组实际点位缺项仍存在。没有记录就保留量测变化/相对影响合同，不追加采集。
