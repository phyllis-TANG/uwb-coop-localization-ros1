# 方法方向建议：先修清先验机制，再独立研究弱几何局部近似

建议不在本批上调整sigma、阈值或求解器追求覆盖。需要两条有先后关系的研究线，而不是将欠覆盖全部归为一个原因。

1. **优先建立可审计的survey误差模型。** 同观测、初值、权重下，weak+.3的B2强survey Car1 MSE=.04894，换成理想正确中心后=.00127，配对差CI完全为正；错误中心的严重偏移在线性诊断中也存在。应先区分校准误差的固定偏移、跨实验随机波动与数据相关性，再决定prior权重如何获得。仍缺：独立survey校准记录、重复标定、真实中心误差的跨时间稳定性。这里的真值中心不可部署，不能宣布已经实现改进算法。

2. **对weak/near单独设计非线性不确定性诊断。** 正确固定中心sigma=.5后，weak B2两车非线性覆盖仍90.67%/89.50%，接受子集也欠覆盖；真值处线性模型则有可解释的约98.56%曲率候选覆盖。下一批应预先定义精确Hessian/隐式传播、二阶项、分支和初值敏感性的独立消融，保留全分母。仍缺：曲率余项量化、分支枚举、全局最优证据；本批不能将差异唯一归因于某一个非线性机制。

3. **另行冻结现实可取得先验下的确认实验。** 以新的观测和校准样本，在正确声明的固定/随机先验条件下检查误差、覆盖和成本；把random组改变sigma导致生成精度与权重同时改变的事实写清。保持与本批独立，不在本批选最有利sigma后重新称为新验证。仍缺：长期动态、未知候选链路、实际非Gaussian/相关噪声、部署资源证据；不能跳到HMI或保护级承诺。

继续依据：原数学目标和数值规则已通过回归与完整读回，差异有同seed受控证据，适合进一步机制研究。暂缓依据：尚无可部署的正确先验来源，也未分清非线性曲率/分支/数值残留贡献；因此暂缓“覆盖已校准”“保护级已验证”或实车安全结论。
