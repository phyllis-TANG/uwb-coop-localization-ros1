# 中期报告机制分析章节初稿

针对既有冻结结果中的欠覆盖，本文新增先验机制与非线性近似的受控仿真。实验在阅读既有结果后设计，并在新观测生成前独立冻结。保留六时刻、双车XY、原测距与全局位移模型，测距与运动噪声标准差分别为0.04m和0.02m。矩阵包含三种几何、peer无偏差/恒定0.3m、位置先验标准差0.5m/0.05m及三种中心机制，共36条件，每条件100个新种子。fixed_correct将中心固定在真实首时刻位置，fixed_survey使用原survey，random_correct在真实中心上叠加与数据独立的正确尺度Gaussian扰动。所有条件始终采用相同规则的survey积分初值。两个correct机制依赖仿真真值，仅作理想诊断，不代表可部署方案。

四方法共完成14400次非线性运行，并为每个输入构造对应的真值处一阶仿射模型，另完成14400条SVD直接线性诊断。线性模型保留每种方法的信息范围：独立B0不使用peer，普通协同B1保留未建模peer偏差，增广B2估计一个自由常偏差，oracle B3校正真实注入。线性诊断不使用P0/P1，也不增加独立随机样本量。非线性14335次满足冻结接受标准，65次未驻点，全部最终估计有限并进入主统计。

在线性模型中，令白化数据Jacobian为A、先验Jacobian为L，H=AᵀA+LᵀL。H⁻¹是总曲率逆；固定中心重复数据噪声的传播为H⁻¹AᵀAH⁻¹；独立正确随机中心的传播还需加上H⁻¹LᵀLH⁻¹。固定中心错误或B1漏建模偏差产生的均值mu须单列，误差二阶矩为随机协方差加mu muᵀ。实验逐记录验证了直接线性解与该解析关系。正确随机中心下，正确指定线性组的曲率椭圆理论点态覆盖为95%，本批条件—车辆点平均经验范围为92.83%至97.17%；固定正确中心的相应传播椭圆在可用二维块上为94.50%至97.33%。固定中心采用曲率逆时可能保守，不能把它与随机中心传播混为一谈。

在weak、peer恒偏差0.3m、B2条件中，强survey先验的非线性Car1/Car2 MSE为0.04894/0.03218m²，曲率逆名义95%点平均覆盖仅1.83%/10.00%。该组全部数值接受，且约97.5%/96.6%的MSE来自跨种子均值误差平方。相同权重和初值下改用理想正确中心，MSE降至0.00127/0.00123m²，覆盖为98.83%/98.83%。对应强survey线性诊断也严重欠覆盖，说明固定偏移无需非线性求解失败即可解释这部分现象。

然而，正确中心不能解决全部问题。weak、fixed_correct、sigma=0.5m下，B2非线性两车覆盖为90.67%和89.50%，按100个seed整簇重采样的95%逐项区间分别为[86.00%,94.67%]与[83.67%,94.67%]；对应线性诊断为99.00%/99.17%，其曲率候选理论覆盖约98.56%。非线性接受子集仍欠覆盖。另一方面，random_correct、sigma=0.5m时非线性MSE远小于真值处线性参照，却具有更低覆盖，说明精度改善与不确定性一致性并不等价。

先验强度的影响依赖中心机制：weak、B2的Car1在正确固定中心下加强先验降低MSE，在错误survey中心下反而增加MSE；随机中心组还同时改变先验生成精度和估计权重，不能解释为纯粹的算法优劣。真值处的一阶模型在weak横向方向遗漏距离的高阶变化，非线性与线性差异还可能包含分支、初值及数值因素。本批尚未逐项分离这些贡献，因此建议首先明确现实survey误差机制，同时另行设计弱几何非线性传播与分支诊断。

全部输入和状态经过不调用优化器的独立读回及压缩证据复核。点态覆盖与六时刻全覆盖分开报告，奇异传播矩阵保留不可用标记，不用伪逆制造有限区间。独立单位始终是100个seed，方法、车辆、时刻和两种模型对照均不增加样本量，逐项区间不具有家族保证。本研究不构成长期动态、实车、罕见风险、HMI或保护级验证。
