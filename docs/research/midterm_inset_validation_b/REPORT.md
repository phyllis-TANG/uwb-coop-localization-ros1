# 集合内固定偏移：正式结果

## 结论与边界

同输入仿射参照通过代数、独立直接解及读回验收，未发现均值传播、噪声协方差或集合外包公式的实现错误。good 几何下非线性与仿射结果接近；weak 几何、sigma=.05m 时也接近。weak 几何、sigma=.5m 时，即使中心正确且数值接受，非线性位置误差仍明显大于仿射参照。这支持继续研究局部近似和解分支的局限，尚不能单独归因于某一种机制。

本轮构造了有明确假设的候选区域，没有验证部署保护级、HMI或轨迹风险保证。全部预定中心偏移都在 rho=.05m 的四维欧氏球内，但只测试了 Car1Y 轴向扰动，不能据此声称非线性区域包络整个四维球。

## 线性验收与不可用

600个线性设计均满列秩25。直接解与独立未缩放最小二乘解最大状态差1.09e-15，噪声加固定偏移恒等式最大差2.02e-16，正规方程残差最大3.53e-12。500个坐标级均值/方差诊断均未触发预定宽松异常规则：最大均值标准化偏差2.997，中心方差比范围.613–1.723。这些坐标和条件彼此相关，不是500个独立检验，也不证明精确频率覆盖。

weak 的首时刻噪声边缘协方差奇异。解唯一不等于每个二维噪声椭圆非退化。全部129600条逐点候选记录中4800条按 NONPOSITIVE_OR_SINGULAR_MARGINAL 保留，124800条可用。未加ridge，未混入退化Gaussian定义。weak 的噪声及组合候选每车每条件仅150/180点可用，因此六时刻全覆盖及完整六时刻配对覆盖区间不可用；曲率椭圆另列，不能替代该缺口。

线性噪声椭圆在零偏移下解析覆盖为.95；good 零偏移经验覆盖约95.56%。外包圆更保守：good弱先验零偏移时两车解析噪声圆覆盖约97.18%、95.89%。rho=.05m 的所有可用线性组合圆解析覆盖均不低于.95；高于95%不属于实现错误。

weak/.5/零偏移的30个非线性结果全部数值接受，因此差异不能仅用4条未驻点结果解释。good 各中心条件的RMSE约.024–.025m，非线性和仿射相近。正负偏移全部报告；例如weak/.5的±.05m下仿射Car1 RMSE分别约.05219/.06868m，有限样本共享噪声均值造成不对称，不能据此事后选择方向。

rho=.05m下，weak/.5/零偏移的非线性GN圆覆盖两车95.56%/93.89%，平均半径.433/.445m；精确H灵敏度圆为93.89%/96.11%，半径.318/.311m。仿射可用点覆盖100%/100%，半径约.132m，但缺首时刻。30seed区间较宽，例如非线性精确H圆Car1覆盖区间约[84.44%,100%]，不能把点估计不足95%直接当作统计显著欠覆盖。全成功bootstrap区间也不能转化为罕见风险保证。

weak/.05下，增加rho从0到.05m，非线性GN Car1各偏移条件覆盖范围由60–97.78%变为98.89–100%；精确H圆由60–98.33%变为98.33–100%。低rho并不包含所有±.05m偏移，所以这一变化不能解释为有效集合内理论在rho=0时失败。good 下增加偏移项主要轻微扩大尺寸。完整三rho、两车、所有偏移、全部有限与accepted子集均见 SUMMARY.csv 与图，不能只展示最有利的rho。
