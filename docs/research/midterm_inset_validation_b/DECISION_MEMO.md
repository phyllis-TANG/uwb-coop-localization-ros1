# 下一步决策

本轮正向验证支持：在匹配的仿射高斯模型、固定中心偏移位于指定球内且二维协方差非退化时，噪声灵敏度协方差加偏移支持函数产生的外包圆符合推导。rho=.05m覆盖全部本轮指定中心偏移。它是候选区域，不是已验证保护级。

good及weak强先验的非线性结果接近仿射；weak弱先验即使正确中心、数值接受，仍有明显更大的位置RMSE。加入偏移集合并不能自动消除非线性误差。数值停止标签、Hessian与GN差异和分支影响尚不能完全分离；当前结果仅支持机制线索，不能断言单一原因。

本轮不追加实验。下一轮优先顺序：

1. 使用现有端点和输入分析weak/.5的曲率、残差、偏差状态和解分支，区分驻点接受与局部近似有效性。若确需新优化，另冻最小配对设计，不能从本批挑有利seed或改本批结论。
2. 单独推导并验收奇异Gaussian区域，或明确采用可观测子空间表达。不得把不可用首时刻删掉后声称完整六时刻验证。
3. 为安全量化目标补齐实际先验误差集合依据、非线性余项/分支控制及轨迹层面风险分配。当前四维球只是仿真假设，轴向实验不证明整个球的非线性包络；扩大rho不能代替这些证据。

30seed逐项区间不足以建立罕见风险保证。是否新增非线性实验应由以上只读诊断产生明确可证伪问题后决定，本轮交付本身不授权自动追加批次。
