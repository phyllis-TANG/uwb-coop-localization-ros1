# 中期报告新增段落

为检验局部不确定性在模型失配下的适用边界，本文对已保存的故障压力测试和独立噪声探索分别进行事后覆盖分析。故障批次为72条件、每条件100seed、四方法共28800结果；噪声批次为72条件、每条件50seed、四方法共14400结果。本轮不重新定位，不改变原权重、先验或估计中心；数值未驻点和预算耗尽输出全部保留。统计独立单位为seed，同seed的车辆、时刻、方法及条件相关；六时刻点平均覆盖采用seed整簇重采样。

在每个保存终点比较三种局部矩阵：总Gauss–Newton信息逆H⁻¹、独立白化噪声假设下的固定先验传播H⁻¹AᵀAH⁻¹，以及真实白化噪声协方差Ω已知时的传播H⁻¹AᵀΩAH⁻¹。先验中心固定，不加入随机先验项。第三种仅作为离线参照，描述局部随机波动，不包含未知故障均值偏移、固定错误先验偏移、非线性余项或错误解分支。

故障批次表明，误差改善与覆盖充分并不等价。B2在正确常值模型下的名义95%位置覆盖，跨12条件的描述性均值约为两车91.86%和92.24%；step时下降至59.99%和74.57%，ramp为74.18%和81.97%。错误候选与多链路条件中，车1在所有12条件均为0/600点覆盖。多链路下B2相对B1有20/24条件—车格MSE均值下降，但仅8格覆盖上升。上述条件相关，计数不能作为独立检验次数。时变及错误候选模型不存在统一真单常b，因此不对其注入均值计算真偏差覆盖。

噪声探索中，B2车1/车2采用独立噪声传播时，实际sigma=.08的名义95%覆盖描述均值为58.08%/63.42%；使用真实Ω的离线传播后为85.97%/92.92%。AR(1)、rho=.7、边缘sigma=.04时，相应为67.58%/77.67%提高到87.00%/93.50%。这些是每噪声24条件的等权描述，不扩大独立n。尽管局部噪声解释有明显改善，弱几何静止peer、AR零注入的B2车1修正后仍仅221/300=73.67%覆盖，seed聚类95%区间61.33%–84.67%，说明正确随机协方差不能单独保证位置区间校准。

一阶矩阵在所有保存终点可逆，但这不消除结构与非线性问题。错误候选示例中，预测随机方差迹与经验中心波动接近，而误差均值平方远大于两者，说明中心波动与真实误差二阶矩必须分开。残差较小也可伴随更大误差。剩余欠覆盖中固定先验、非线性与分支的贡献仍需独立实验隔离；本轮不能作因果分解。本结果为已暴露仿真的探索性分析，点态椭圆不等于轨迹保证，未构造保护级、HMI或实车/罕见风险保证。
