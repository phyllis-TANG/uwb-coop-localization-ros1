# 故障与噪声失配的联合覆盖分析

**故障均值失配与随机协方差失配不能用同一种修正解释。** 单常值正确模型的覆盖明显好于时变故障；错误候选/多链路甚至出现所有条件车1零覆盖。真实Ω的离线传播可解释噪声失配的一大部分欠覆盖，但仍留下显著反例。估计位置未改变，不能把覆盖提升称为定位性能改善。

## 三种矩阵与分母

A_total是总GN曲率逆H⁻¹；B_iid是假设白化数据独立的固定先验传播H⁻¹AᵀAH⁻¹；C_true_noise是H⁻¹AᵀΩAH⁻¹，**真实噪声协方差已知的离线参照**。A为测距+运动Jacobian，先验L只进入H=AᵀA+LᵀL。固定错误先验中心不重新抽样，Ω不含prior随机项。实际方差改变仅作用测距，不能整体乘4；AR只关联同链路不同时刻，B0按原行索引删peer。详细定义见MATRIX_DEFINITIONS.md。

故障每车每条件600点（100seed×6时刻），噪声300点（50×6）；逐时刻及六时刻全覆盖分母分别100/50。每个条件的独立n始终是seed数，同seed车辆/时刻/方法/条件相关。主表包含所有可计算最终状态；accepted、not_stationary、budget_exhausted各自列为补充。全部位置块三视图可计算：故障每视图345600，噪声每视图172800；不可用0，所以本次“覆盖/可用”等于“有效且覆盖/全计划”，两列仍分别保存。未驻点/预算结果不是缺失。

终点数据/总信息在主秩阈值和三项敏感性阈值下全部满秩。最大尺度化Jacobian条件数故障1022.65、噪声655.50；信息条件数为其平方。只说明这些保存点数值可逆，不证明结构退化消失、全局唯一或局部Gaussian可信；本轮未重做PR106的真值参考点秩分析。

## 1. 故障失配造成多少欠覆盖？

下表为B2、A_total、名义95%点态覆盖的**12条件等权描述性均值**，每条件100seed，括号为条件范围。不是把7200点当独立样本的总体覆盖估计，不给跨条件堆叠CI。

|注入|车1|车2|
|---|---:|---:|
|zero|91.86%（85.33–95.17）|92.24%（86.33–94.83）|
|constant|91.86%（85.33–95.17）|92.24%（86.33–94.83）|

|ramp|74.18%（51.83–88.83）|81.97%（51.67–93.33）|
|wrong_link|0%（全部条件0/600）|72.79%（0–94.50）|
|multi_link|0%（全部条件0/600）|72.79%（0–94.50）|

zero/constant位置目标在自由常b下等价，wrong_link/multi_link只差候选常数，可由b平移吸收，因此相近覆盖不是独立重复支持。真实故障在模型外的另一链时，单个候选b不能表达完整注入。step/ramp没有唯一真单常b，不计算它们的真b区间覆盖；表中适用性明确列出，而不是把候选均值当真值。

m32（weak/static/peer/step）车1只有178/600覆盖，seed聚类95%区间23.33–36.17%；C视图的六时刻全覆盖分别为车1 6/100、车2 4/100。wrong_link m28两车轨迹全覆盖均0/100。常值经验簇不报[0,0]式伪确定性区间，更不能推断真实覆盖概率严格为0。

故障批次真实Ω本就为I，故B_iid与C_true_noise逐点一致：知道正确随机噪声协方差不能修复这些故障均值漏项。m28（weak/static/wall/wrong_link）B2车1六时刻平均的经验中心波动迹为0.001423m²，C预测迹0.001455m²，二者接近；但均值误差平方0.75008m²，MSE0.75149m²。**随机波动尺度接近仍可几乎完全漏掉真实误差**。这个分解是样本事实；不把非线性均值偏移的所有来源都归因于某一个因素。

## 3. 噪声失配与真实Ω能解释多少？

以下是B2名义95%点平均覆盖的24条件等权描述均值；每条件50seed、每车300点，不跨条件扩大n。C只改变局部传播矩阵，误差中心完全不变。

|真实噪声|车1 B_iid → C|车2 B_iid → C|
|---|---:|---:|
|iid .04|88.81% → 88.81%|93.25% → 93.25%|
|iid .08|58.08% → 85.97%|63.42% → 92.92%|
|AR(1), rho=.7, sigma=.04|67.58% → 87.00%|77.67% → 93.50%|

对于iid .08，B2各24条件×2车的C−B覆盖差范围24.67–32.67个百分点，48个逐项95%配对CI均为正。AR同样48格均为正，范围12.33–29.67个百分点。区间相互相关且无多重比较保证，不能叫48次独立确认。其他三方法完整图表也保留，不能只据B2平均宣称普遍校准。

正确常值B2偏差95%区间：故障批次条件覆盖范围92–98%；噪声iid .08采用B时62–80%、C时90–98%，AR采用B时66–84%、C时92–98%。即使偏差区间较接近名义覆盖，位置覆盖仍可能不足。错误候选/多链路/时变故障的bias_q为空且NOT_APPLICABLE_MODEL，未参与上述范围。

## 4. 修正随机波动后仍剩什么？

AR下n32（weak/static/peer/zero）B2车1的C覆盖仅221/300=73.67%，seed聚类95%区间61.33–84.67%，仍低于名义95%；其轨迹六时刻全覆盖34/50，车2为43/50。C视图覆盖的条件范围：AR车1 73.67–94.00%、车2 89.33–96.67%；iid .08车1 72.33–94.00%、车2 87.33–97.67%。因此真实Ω只解释一部分失配。

n32车1平均MSE0.06190m²，其中样本均值误差平方0.03791m²、经验中心协方差迹0.02448m²，C预测迹0.05714m²。即使预测迹与MSE量级接近，方向、中心和误差分布仍可能不匹配，不能据平均trace宣称覆盖校准。固定survey偏移、弱几何非线性、分支与终点线性化都是待隔离解释，本轮没有重新拟合或做干预实验去认定各自贡献。

所有预定最大C归一化误差案例均数值接受，包括m28/m29的q约926.48，以及n32的q约38.89。局部驻点与正确不确定性不是同一命题。未驻点和预算耗尽单列，但不能用它们解释全部欠覆盖。

## 5. 残差关系与解释边界
