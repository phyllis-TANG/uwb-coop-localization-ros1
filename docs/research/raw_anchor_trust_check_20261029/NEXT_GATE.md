# 下一步判定

**三选一：现机制没有必要性应收缩主张。** 精确范围是“当前图内硬约束相对同信息、同预算直接裁剪的新增机制主张”，不是认定所有四锚方法无用，也不是否定PR71有限相对位移合同。

本轮没有找到候选独享、而同信息廉价基线无法利用的必要差异。原PR72/75在一个开发seed上的毫米级误差差别、yaw/发布状态差异和SLSQP成本，尚未对应一个有独立物理标准且裁剪不能满足的实际合同。本轮没有重算这些性能，也不把单seed负结果推广为普遍不可能。

原四锚确有比一维代理更多的冗余：在已知几何/高度假设下，XY＋共同偏差局部可辨识，未知单链身份也存在几何区分线索。但这些原始观测、偏差模型及其解释应同等开放给固定缩权和裁剪。**“能解释四墙冲突”与“必须新增协同影响控制机制”之间，还缺少可复查的比较理由。** 本轮不据此启动一个完整定位器。

允许继续的主线是：明确发布相对全历史peer-free参照的双方天线XY预算，以及帮助/损害/回退/unknown的合同与开发证据；不把它扩写成可信车认证、4cm绝对精度或完整性保障。无需先把所有几何/时间/相机链全面认证才讨论这一有限合同。

重新进入一个候选最小对照的门槛只需下列之一，而非无限补证：

1. 给出一个独立用途支持的额外发布合同，证明同信息同预算裁剪存在具体缺口，候选设计针对该缺口；物理阈值来自独立依据，不能看哪种方法好看再设线。
2. 若目标改为定向保护可信车，先通过FIELD_MINIMUM的旧记录恢复或必要静态补证，限定一个现实可用的信任假设；再先检查廉价基线用同一线索是否已满足目标。仅增加可靠线索、换求解器或模型满秩不是候选优势。

否则停止扩大图内硬约束实验，保留负结果和有限合同，转为清晰的基线/证据边界表述。10月30日不需要重录全套，当前新动态需求为0；11月15日投稿目标不改变证据门槛。

证据分层：本轮重算四个静态Jacobian/投影；元数据核对98行；约束/裁剪性能及历史尾部引用PR72/75；补证与重新进入门槛是新建议。详情见TRUST_BASIS、DATA_USE_MATRIX与HANDOFF。
