# 已暴露冻结结果的不确定性探索性分析协议

分析前固定于本提交。基准fba539052f3ce2ed7d2ed35e79ac03198200c680；只读仓库内midterm_simulation_confirmation/results/ESTIMATES.jsonl.gz，不使用另一机器绝对路径，不生成新的定位观测、不调用优化器。全部36条件、四方法、50已有seed，1800输入/7200最终P1状态，预期7175接受、25未驻点。此为探索性事后分析，不是新盲测，不调噪声、rank或接受阈值追求理想覆盖。

## 来源与矩阵

先核对confirmation交付清单、B冻结清单的文件SHA、RUN配置/计划和输入哈希，再核对身份唯一性、P1代价、梯度和误差。损坏/不匹配时终止依赖该证据的分析并保存诊断；可继续理论说明。保存源码与配置哈希、环境、执行日志。

状态顺序24位置（6时刻×两车XY），B2另有常b。重用只读独立readback.objective计算r/J，与原型problem交叉核对必要的代表性点。A为白化测距+运动Jacobian；L为白化t0位置prior；H_d=AᵀA，H=H_d+LᵀL。所有主分析在原P1终点，另在离线真值参考点报告data/total秩与完整奇异谱，不能用终点满秩推翻参考退化。

SVD对J D进行，D的位置1m、b .1m。主rank阈值s>smax×1e-8，附1e-6、1e-10、1e-12敏感性；记录矩阵维数、smin/smax、条件数、全部谱与零空间的bias分量。秩亏整状态协方差为null，不用伪逆提供有限原坐标椭圆，不加ridge。偏差在可辨识子空间可有局部信息，单独报告投影信息，不把保守的整状态区间不可用等同bias必不可辨识。

三种终点候选矩阵：

- total_curvature：C=H⁻¹（实际为Gauss–Newton局部信息逆，不自动是精确Hessian逆/校准后验）。
- fixed_prior_noise：C_noise=H⁻¹ H_d H⁻¹，假设固定prior、白化数据噪声独立单位协方差，仅局部线性随机波动；无偏性及非线性余项另议，不作偏差校正。
- data_only：C_d=H_d⁻¹，只在数据满秩时可用，评估仍用同一保存终点，不重新解无prior问题；不冒充去prior估计器的实际重复方差。

总信息不满秩时total/noise都不可用，data不满秩时data_only不可用。局部2×2块需有限且严格正定，未通过为NONPOSITIVE_MARGINAL；不增补正则。fixed_prior_noise可能奇异，按该规则保留不可用。数值矩阵检查容差用于核验，不用来改变原接受标签。

## 指标、分母与分组

对每条方法、每辆车、每时刻提取2×2边缘协方差（m²），误差e、q=eᵀC⁻¹e，尺度sqrt(trace C)、95/99%长短半轴（m）与面积（m²）。点态椭圆用chi²_2(.95/.99)；B2常b用chi²_1(.95/.99)阈值和对称区间，保存方差、误差、覆盖及半宽。B2另存全部24坐标与b相关系数、每个2D块的多重相关平方、有效bias信息。q可称局部归一化平方误差，不默认服从卡方。

每条件/方法/矩阵/车分别汇总六个时刻，各时刻计划50。另有“所有点的平均覆盖”（计划300点，CI仍按50 seed整簇）与“同一辆车六时刻全部覆盖”（计划50轨迹，所有六区间都可用才算可计算）。轨迹全覆盖不标称轨迹95/99保证。对全部组保留：计划数、可计算数、不可用原因计数、覆盖数、有效区间覆盖比例、全计划有效且覆盖比例。不可用不是成功；有效覆盖率分母0时为null，全计划联合比例保留0。

主表包括所有7200有限最后估计，另列accepted和not_accepted子集；不改变原分类，不悄悄丢弃25条。子集同时列全计划50和子集seed数，非入选数与区间不可用分开。不足30有效seed或区间缺失>10%不给有效覆盖率CI，给原因。全计划有效且覆盖的CI使用50个seed；子集CI只作补充。每组按seed排序，整簇重采样，PCG64 seed=91327061，10000次，95%逐项percentile。重采样同时保留同seed六时刻，ratio按覆盖数/可用数重算。不按时间点/车辆独立二项样本算CI。不跨条件把n扩大。若经验簇比例恒定，CI置null标CONSTANT_EMPIRICAL_CLUSTERS（避免[1,1]伪确定性），不声称真实覆盖恰100%。

补充经验矩：每条件/方法/车/时刻，50seed误差均值、ddof=1中心协方差、MSE=中心波动+(偏差均值)²，分别对比预测平均trace(C)与trace(C_noise)。bias同理。经验协方差仅50样本，不作高维全协方差精确估计。报告残差白化RMS、实际RMSE、sqrt(mean trace C)与Spearman关系，按seed为记录单位；描述性相关不作因果或校准证明。

固定prior的偏移项与漏建模range bias分别推导，不用truth修正估计或选择区间；不估计新的噪声系数。prior对比选择冻结core/no_prior/strong/shifted_strong的static/peer+.3组，用同seed差报告MSE、区间尺寸和覆盖变化。
