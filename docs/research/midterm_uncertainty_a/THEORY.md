# 不确定性：定义、推导与适用边界（核心交付）

本节为冻结测距模型的自行推导，尚未逐式对齐原文。对固定树 docs/、tools/ 中 Markdown、TeX、Python 搜索 HCPL、师兄、原始方案，未找到可识别的师兄原始方案；已有研究文档不是原论文原文。不能称为复现其 HCPL。

## 1. 状态、白化及局部信息

六时刻两车二维位置 $x=(x_{1,0},y_{1,0},x_{2,0},y_{2,0},\ldots,x_{2,5},y_{2,5})\in\mathbb R^{24}$；B2 增广常偏差 $b\in\mathbb R$，最后一维，所有状态单位 m。B0 不使用车间测距，B1 不增广，B2 已知受影响链路并估计幅度，B3 使用真实幅度修正；B3 是 oracle 对照，不能部署类比。数据含测距与相邻时刻位移，位置先验仅在首时刻四坐标。

设原观测 $y=h(\theta_*)+\epsilon+d$；$d$ 是模型漏项/系统误差，$W$ 为估计器使用的白化算子。取 $r_d(\theta)=W[h(\theta)-y]$，$r_p(\theta)=P^{1/2}[E\theta-c]$。令 $A=W\partial h/\partial\theta$，$L=P^{1/2}E$，均在明确给定的线性化点计算。目标为 $\tfrac12(\|r_d\|^2+\|r_p\|^2)$，$H_d=A^TA$，$H=H_d+L^TL$。冻结权重是测距标准差 .04 m、位移 .02 m；先验无/.5/.05 m，中心固定且可有误差。未使用残差重新估计噪声或乘约化卡方。

报告的“信息”是 Gauss–Newton 信息。真实目标 Hessian 还含 $\sum_i r_i\nabla^2r_i$，因此 $H^{-1}$ 严格说是局部 GN 曲率逆，不自动等于精确 Hessian 逆。未驻点终点更不能声称 Laplace 后验中心已找到。

## 2. 分块消元

对 B2，$A=[A_x,A_b]$，位置先验无偏差分量，

$$H=\begin{bmatrix}Q&T\\T^T&U\end{bmatrix},\quad Q=A_x^TA_x+L_x^TL_x,\ T=A_x^TA_b,\ U=A_b^TA_b.$$

若 $U\succ0$，消去 $b$ 得位置 Schur 信息 $S_x=Q-TU^{-1}T^T$。只有 $S_x\succ0$（等价此条件下 $H\succ0$）时，完整边缘协方差才存在：

$$C_{xx}=S_x^{-1},\quad C_{xb}=-S_x^{-1}TU^{-1},\quad C_{bb}=U^{-1}+U^{-1}T^TS_x^{-1}TU^{-1}.$$

若 $Q\succ0$，另可写 $C_{bb}=(U-T^TQ^{-1}T)^{-1}$。$Q^{-1}$ 是固定/已知 $b$ 的条件曲率逆，不是未知 $b$ 的位置边缘协方差；消去 nuisance 会减少信息。同一线性化点、同权重与模型比较时 $S_x\preceq Q$，不能把跨不同终点、不同模型的 B1/B2 数字直接当此定理的验证。

二维每车每时刻边缘由选择矩阵 $F$ 提取 $FCF^T$，不是先取对应的 $H$ 子块再求逆。位置—偏差相关系数为 $C_{ib}/\sqrt{C_{ii}C_{bb}}$；二维多重相关平方 $C_{bp}C_{pp}^{-1}C_{pb}/C_{bb}$。它只刻画此局部矩阵，不能证明真实误差的耦合因果关系。

## 3. 秩、先验及可辨识子空间

数据零空间满足 $Av=0$，添加先验后零空间为 $\ker A\cap\ker L$。先验可增加总信息秩，但不增加测距本身的独立信息。无先验若秩亏，不存在完整有限协方差。物理状态尺度 $D=\mathrm{diag}(1,\ldots,1,.1)$（非 B2 无最后项），以 $JD$ 的相对奇异值阈值 $10^{-8}$ 定数值秩，另列 $10^{-6},10^{-10},10^{-12}$；这是可审计数值约定，非物理可辨识性证明。信息条件数为 Jacobian 条件数平方；表内 condition 是后者。尺度影响数值秩阈值，不能省略。

若 $N$ 张成零空间，只有满足 $FN=0$ 的函数才可能在可辨识子空间给出有限局部方差。可在有明确约束的子空间选基 $V$，使用 $FV(V^THV)^{-1}V^TF^T$；不能把全空间伪逆的零特征值解释成不可辨识方向零方差。本轮完整状态秩亏时保守地不提供整状态各位置区间，不以 ridge 伪装满秩。偏差可单独在位置列空间正交补具有信息 $\|(I-\Pi_{A_x})A_b\|^2$；因此整状态区间不可用不必然等价偏差本身不可辨识。

终点数据秩与真值参考点秩分别报告。噪声导致终点离开精确退化流形，可能产生形式上的满秩；这不取消参考模型的一阶退化，也不能保证一阶近似在弱方向准确。

## 4. 三种不同的量

(1) $C=H^{-1}$ 是 GN 局部曲率逆，取决于当前线性化点和估计器权重。

(2) 若观测 Gaussian、权重等于真实逆协方差、先验是正确指定且与数据独立的概率分布，则在线性模型中 $H^{-1}$ 是精确 Bayesian 后验协方差；非线性时只是局部 Gaussian 近似，并要求适当的 mode、单峰/局部线性条件。Bayesian 可信区间对固定真值和固定错误先验中心的频率覆盖不自动标称。

(3) 固定真值、固定先验中心，反复抽取观测噪声产生的估计波动，即使权重正确，也通常是

$$C_{\epsilon}=H^{-1}A^TAH^{-1}=C-CL^TLC\preceq C.$$

它与 $C$ 不同，更不包括固定先验误差导致的偏移。令 $\delta=c-E\theta_*$，$\eta=W\epsilon$，则局部估计误差

$$e\simeq H^{-1}[A^T\eta+A^TWd+L^TP^{1/2}\delta]=G\eta+\mu,$$

其中 $\mu=H^{-1}(A^TWd+L^TP^{1/2}\delta)$。二阶矩为 $C_\epsilon+\mu\mu^T$，不是仅 $C_\epsilon$。非线性余项、分支变化和非驻点残差未被此表达式覆盖；在保存终点代入 Jacobian 是探索性 plug-in，不是重复抽样精确分布。经验 centered covariance 用 ddof=1；样本 MSE 等于 $(n-1)/n$ 倍该协方差的迹加均值误差平方。

若先验中心也按正确分布独立重抽，则加入 $H^{-1}L^TLH^{-1}$ 后才得到 $H^{-1}$。本冻结实验的先验中心不是这样抽样的，不应套用。

## 5. 椭圆、覆盖与局限

对正定二维边缘 $C_p$，$q=e_p^TC_p^{-1}e_p$，名义 $\alpha$ 椭圆 $q\le\chi^2_2(\alpha)$；长短半轴为 $\sqrt{\chi^2_2(\alpha)\lambda_i(C_p)}$，面积 $\pi\chi^2_2(\alpha)\sqrt{\det C_p}$。B2 常偏差区间 $\hat b\pm\sqrt{\chi^2_1(\alpha)C_{bb}}$。偏移非零会产生非中心分布；真实波动与候选矩阵不匹配时甚至不是标准非中心卡方。

每条件50 seed是独立随机单位。同seed的车辆/六时刻/方法相关，不能当独立 n。点态名义95%不是六时刻联合95%；本报告单独列六时刻全覆盖经验频率。覆盖区间按seed整簇重采样，不把不可用算成功，不用真值选解或调噪声。这里真值只用于离线误差及覆盖评价。覆盖率CI、误差椭圆和均值CI均非保护级、HMI或完好性保证。
