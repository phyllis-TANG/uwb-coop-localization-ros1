# 下一步决策

## 五个问题的回答

1. **11个旧失败主要原因**：4个ftol、7个xtol提前成功退出与外部物理梯度门槛不一致。独立目标/J/信息重算未发现基础错误；精确H正定，预测修正4.05–17.82nm。实际一次继续仅2例改标签，最大位置变化4.09nm，9例仍失败，说明浮点代价比较/步长停滞仍限制严格驻点判断。历史标签不改。
2. **常偏差匹配是否复现**：是，在10个新seed的三个窗口中，M2的normal/constant03端点仅约1.20nm差，bias平移误差≤7.05e−11m。仅是已知模型族与预定链路的一致性，不是故障识别。
3. **阶跃/斜坡保持与退化**：M2仍比M1平均误差小，但平均误差比M0大；残差不能被一个常数消除。step/ramp的后半段−前半段残差约−.218/−.127m，均保留明确时间结构。单个常bias收敛不代表模型匹配或完整性成立。
4. **下一步优先项**：针对安全量化主线，优先补观测不确定性契约及证据，再开展最小时变偏差建模对照；暂不直接开发检测器。设计的两条曲线能证伪“常bias足够”的一般性，却不能给出真实故障概率、时间相关性或虚警/漏检风险。没有这些依据，增加检测器或宣布保护级都缺少可校准对象。
5. **适用条件**：所有定位结论仍局限于height-oracle、已知无误差信标、合成全局XY增量、正确独立prior、独立Gaussian噪声以及事先选好的peer链路；不是非oracle高度、未知设施/故障、实车轮滑或月面实测结论。

## 建议的后续协议（本轮不实施）

先明确高度误差、设施位置误差、运动观测相关性、UWB时间相关偏差/幅度/持续时间的来源与可接受包络，并区分测量依据与研究假设。
若缺实测，可做明确标注的参数敏感性协议，但不能把参数扫描转成真实发生概率。

随后以新的固定seed与预算比较一个最小时变bias模型（例如线性趋势或带已声明过程约束的bias序列），继续保留M0/M1/常bias M2；
先检查可观测性、参数尺度及额外自由度的代价，不能用任意强先验掩盖不可观测性，也不能使用真实故障标签选切换时刻。
现有阶跃/斜坡结果仅作为机制线索，不用于调参后重写本轮结论。

故障检测需另有无故障/有故障分布、序贯相关性、检测延迟与虚警/漏检评价协议；本轮残差时间图不能替代这些校准。
正式安全量化还需独立测试集、样本量与风险事件定义、模型失配和数值失败处理；10seed不够作尾部/覆盖确认。

当前数值失败继续保留原1e−5标准；可以将严格梯度接受与精度停滞诊断分开报告，但不得把“预测修正小”升级为安全保证。
本轮不再追加调用，不运行任何下一阶段试验。
