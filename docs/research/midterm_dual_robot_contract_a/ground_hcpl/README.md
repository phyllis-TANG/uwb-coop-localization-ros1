**数据边界。** 原始依赖 #143 为 01e588021e7e3ddd918b1d1fc9561973373758c6。读取 ground_continuous_b 的 PROTOCOL、README、run_b.py。九条同戳测距取自 records.json.gz 的 obs，保留两原始帧 ID、peer 行、锚点顺序和实际接收时标。运动取 bins.carN.local_odom 的整数秒局部里程位姿：20 Hz 输入有同戳 odom，原生成器与前端独立核对代码见 tools/two_car_fixed_lag_fgo_v1/simulate.py 和 tools/cooperative_integrity_baselines_20261029/independent.py。整秒帧延迟小于一秒接收截止；bins 的最大依赖时刻还计入聚合测距，本例只取其中同戳里程，不用中位数。用调查航向旋转局部位移，并加旋转中的天线杆臂相对初始时刻的改变量，再从相邻两时刻作差。cfg 来自固定提交的 nominal_seed101.json。初始化只用带扰动的调查天线位置、调查航向及零偏差。滤波入口接收截至选定历元的观测包和公开配置；truth.json.gz 在全部估计与判定完成后才取同戳索引 200。

#143 的 augmented(obs) 单独拟合每历元的一个自由 peer 偏差，本历元结果为 0.138768 m；本例九链随机游走后 peer 偏差为 0.030400 m。二者使用不同状态与先验。#142 固定提交 94e70e9d50011802d867c849d21fe7935f78ebc9 的区域候选 PL 以发布点为圆心覆盖所有保留矩形，属于另一种算法；本轮表格按原稿增广协方差与剩余偏差项计算。

**可辨识性。** 单历元 13 维全链模型的九条观测不能定解，最小失败输入见 epoch10.json 的 packets[0] 和 first_epoch_failure（含精确到数值精度的零方向）。十历元的数据与运动对 130 列只提供 126 秩；随机游走信息和初始先验的作用见公式表。研究结论限于带这些先验的数值解。若要声称仅由轨迹辨识全部自由偏差，下一步应验证独立标定约束或多个有角度变化历元共用偏差的实际有效性。

**复现。** 仓库根目录运行，Python 3、NumPy 和 Git。epoch10.json 导出状态顺序对应的观测、运动增量、每步预测、创新、H、S、K、后验协方差、传递矩阵、各轴中间量和阈值；每辆车的发布、决策与事后评价分别保存。独立复算将十个归档线性化点重建为一个白化批量最小二乘系统，用 SVD 直接求位置、边缘协方差及各量测影响列，未调用滤波更新。

```sh
git fetch origin refs/pull/143/head
t=tools/midterm_dual_robot_contract_a/ground_hcpl
OPENBLAS_NUM_THREADS=1 python3 "$t/example.py" > /tmp/epoch10.json
OPENBLAS_NUM_THREADS=1 python3 "$t/recompute.py" /tmp/epoch10.json
```

Car1 批量复算减逐步计算的差：原式 −6.66×10⁻¹⁶ m，按轴预分配 −5.55×10⁻¹⁶ m，历史残余扩展 −1.11×10⁻¹⁵ m。复算程序同时检查发布 XY 并在差值超过 10⁻¹² m 时失败。完整输出见 [逐项算例](epoch10.json) 和 [独立结果](independent.json)。
