# 九维/八维完整噪声事件阈值

预先固定α=1/20，τ₉=26、τ₈=24；不依据定位结果调整。均用相同保守规则τ_m=2m+8，适用本合同m∈{8,9}。

若Z~χ²_m，取t=1/4：Markov与Gaussian平方的矩母函数给 P(Z>τ)≤exp(−τ/4)·2^(m/2)。平方后≤2^m exp(−τ/2)。
对x=τ/2>0，用正项Taylor和 S₇₉(x)=Σₖ₌₀⁷⁹ x^k/k!≤exp(x)，故尾概率平方≤2^m/S₇₉(x)。core.threshold_check用Fraction精确证明该上界<1/400，因此尾概率<1/20。
这是解析MGF证明与有理数尾证书，不依赖浮点逆CDF、蒙特卡洛或优化。完整有理数结果存THRESHOLD_CERTIFICATE.json。未使用普通浮点分位数作为认证依据。

相比紧分位数会更保守，本轮为透明可复核而冻结该选择，后续不能为了更小区域静默更改。五维/四维共用同一个九维阈值ID；无peer明确使用八维阈值ID。两个事件各自保证联合两车覆盖至少95%，不保证实现后的外包同样紧，也不代表精确尾概率相等。
