# 协同项什么时候真正提供约束

固定位置(p,s)，精确peer残差t=y₉−||p−s||。当且仅当t∈[β₋,β₊]，消元peer项为0。区间读数时，条件为(I₉−d)∩B≠∅，等价d∈[ℓ₉−β₊,u₉−β₋]∩[0,∞)。因此只要候选位置间距处于这个带内，peer不会消耗联合噪声预算；加入peer未必收缩这些候选。

偏差域增大使消元目标点态不增，固定τ的联合可行集合不减。窄B或退化已知bias会强化距离约束，但B必须有独立物理/研究依据，不能为追求收缩而事后缩窄。真实b=.6在声明边界，会令最优bias夹取在某些候选位置更早激活；这不保证整体区域单调改善。阈值由8维24变为9维26也会扩大可用的锚点残差预算，须单列这一作用。

近共线几何的横向信息弱，候选可能沿垂直方向宽而分支难分；额外一个距离壳主要约束两车相对位置，未必解决共同方向弱可观性。没有随机位置先验、运动或航向信息可以偷偷补足它。域有界带来的有限半径不是测距自身的全局可辨识性。

严格共线锚点位于x轴时，T(p_x,p_y,s_x,s_y,b)=(p_x,−p_y,s_x,−s_y,b)保持全部9个预测值和对称域。任何可行点的共同镜像都可行，这是真实集合对称性，不是区间数值误差。独立反射其中一车保持锚点读数，却一般改变peer距离；若改变仍能被B与噪声余量吸收，更多组合支仍可能保留。不能由peer存在就断言只剩一支，更不能按真值选支。

近共线的负侧保留盒可能是真实分支，也可能只是区间未决；有认证内部盒或可靠可行点可证明该处非空，仅有未决外盒不能。共同镜像严格成立的结构证明无需有限网格；数值未决必须保留标签，不得合并成“定位错误”。

同目标风险主比较应逐车报告区域/成本。固定阈值的嵌套关系是单独数学对照；不同τ导致的变化不能全部归于协同。五维与四维在实数层面等价，计算外包差异来自分割、区间依赖、预算与精度；精度变化也不能冒充新观测信息。
