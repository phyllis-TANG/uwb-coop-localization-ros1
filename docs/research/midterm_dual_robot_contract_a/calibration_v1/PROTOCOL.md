# 三步开发验证协议

实物轨迹和 #143 合成轨迹没有同一物理起点；本轮运行是合成重复调查的机制试验。场地模型和原始传感器生成器固定在 main c7d53da2。先冻结如下选择，再运行。

1. 对相同起点使用 32 个独立合成重复（随机种子 700001…700032），每次从原生成器取两车调查天线 XY、初始航向、t=1 的九条整数秒原始斜距。位置/航向扰动沿用原生成器 0.08 m / 2°。起点为坐标均值/圆均值，标准误取样本标准差/√32，并至少保留生成器名义标准误。按独立读数模型进行数值试验；未量化实物系统误差。测量的是天线，里程递推继续使用原杆臂。
2. 同一重复内用独立调查位置预测斜距，取九行“读数−调查斜距”残差均值。估计起点四轴和九链偏移的联合均值协方差（保留共享调查造成的交叉项）。验证只用独立种子 800001…800032 的 t=12、27、48 s。仿真参考仪器对各位置的天线 XY 独立加 0.08 m 高斯误差，不读取运行种子真值作标定。每链每个地点用均值之差的绝对值加 1.96 倍训练与验证均值合成标准误，小于等于 0.05 m 者通过筛查（三处均须满足）。这是开发筛查阈值，不构成 0.02 m 余差的独立证明。通过的链以校正均值及常数校准不确定度参加估计，失败链保留在线随机游走。不得按运行结果重新挑链。
3. 只用 101 nominal、wall。固定 AL=.10 m、主 history HCPL、原创新门限和车钟规则。比较原九链、仅更换调查、调查加逐链校正、原 B2。完整每车 1280 个 20 Hz tick。开发准入要求：两车正常场景均在第 2 秒及以后至少显示一次来自该阶段的可用位置，正常与墙场景两车越限且可用时长均为零，墙解除后两车均重新显示可用。任一失败则停止；全部通过才冻结后运行原八条配对复用留出。本试验不以准入作为任务风险证明。
