# 冻结方法、输入与评分

起点 f61c02e3aad26709a07940bd9900024ec9a93aa1，#147 e9167c294df252e26deac462920bba9477ad10a6，TTA 沿用 #148 的 excursions、classify。七项测试和十前缀 SVD 独立复算通过。正常首帧直接用 t=1 调查先验，零里程增量、零 Q。B 首个 101_wall 核验提交 5f016896d8d9443ec19eef0dab5f06a04aa073cb；四开发、八复用留出包锁定 85fbe8aca47f0b8d25b6b97107e91b8550737195。packages.json 锁定逐包 SHA256SUMS，运行时核对两文件。顺序 normal、wall、ramp、step；开发只用 101；留出种子 2026111901、2026111902。每轨迹 63 个状态、每车 1280 个显示采样。持出阶段只在开发验收并提交本协议后执行。

**估计与检验。** 状态是两车天线 XY 和九个链偏差，采用 #147 同一斜距、调查参考时刻、杆臂与航向。初始位置/偏差标准差 0.2/0.3 m，R=0.04² I，Q 每秒为 diag(0.03² ×4, 0.01² ×9)。计算更新前九维创新二次型，≤21.665994333461924 时才更新状态、Joseph 协方差与历史残余传播矩阵 T=[(I−KH)T,K]。原式与轴预分配使用本次 K，主版本 history 使用全部接受历史的 T，逐轴确定性项为 0.02 倍行绝对值之和，随后加高斯边际项再取两轴欧氏范数。每车单历元研究风险 0.01；原式每轴使用 0.01，另外两种每轴使用 0.005。逐车 PL>0.10 m 告警，等号可用。各版均使用同一位置与创新门限。

**拒绝与缺包。** 创新超限时两车报告检测告警，位置只随同戳里程预测，P=P旧+Q，b、T 原样传递；本次量测仅用于检验。拒绝期间缺少已验证的运动误差包络，三种 HCPL 都为空、不可用。收到同戳里程但缺测距时保留预测位置，状态 NO_DECISION；缺里程撤销位置并在下一次完整里程用累计差补齐，按跨过的秒数加 Q。首个调查参考里程缺失时不后移调查参考。t+1 的接收截止含等号。复收取下一次通过检验的测距；恢复可用取实际车钟上首次 AVAILABLE。

**时钟。** 独占 FIFO；逐历元模拟开始=max(输入到齐/缺包截止,上次完成)，加本机 perf_counter_ns 实测的帧载荷解析、里程/检验/滤波及三种声明所需数值量生成耗时即完成和就绪。批量解压、事件按接收顺序归组、日志序列化、事后评分与网络不计时。阈值比较和显示选择在车钟采样时执行。运行时先算完决定，再独立读取 #143 冻结的同场景真值。20 Hz 左端采样 0…63.95 s，首次显示需已就绪且当前时刻≤状态+2 s；期间保持该时刻的位置和判定，结果过期后无有效决定。显示时刻是离线服务时间驱动的模拟，实际车载交付时间未测。服务耗时随机器而变。

**评分。** 对每车每版本分别汇总 AVAILABLE / ALARM / 无有效决定，各占 tick/20 秒；越限且可用是 AVAILABLE 子集。回退有定位但无声明仍可观察误差。采用 #148 的按首个可见越限开启事件、恢复或记录结束关闭规则。无位置间隙维持事件身份；1/2/5 秒按首次显示报警、已恢复、截尾、无位置、越限且可用或停用分类。2 s 发布有效期独立计量。开发后保留所有种子场景，不因零可用、拒绝与否选轨迹。历史项与分布、初值、Q/R、0.02 m 界均为研究假设。
