# 写作窗口技术说明

本轮新增：真正双方二维天线位置未知的单时刻联合模型（4锚点×2车+1peer，9条唯一读数），五维原集合与四维偏差消元的等价关系、全部可行bias的内外恢复、完整噪声事件阈值证书、固定16个机制输入及独立全树证书检查器。120个条件性随机输入已经预生成，尚未作为A定位实验执行。

适用条件：固定声明域包含真状态、单条peer有界加性bias、已知正定对角R、零均值联合Gaussian原始噪声、读数区间包含理想输入；无运动、无随机位置先验。这些是合成研究假设，不是平台标定。

与PR127的关系：将参考位置作为共享未知状态s显式保留，避免把一般参考几何误差吸收到同一个测距bias。与PR129的关系：单条bias解析消元推广到两个未知位置，参数维数5→4，但完整噪声维数仍9；历史单未知位置模型的成本/覆盖数字不直接迁移。

可引用的结论：在上述条件下，完整噪声事件同时蕴含两车真位置进入各自联合集合投影；不必为两辆车重复分摊风险。固定τ下加入peer非负项只会收紧精确集合，但各自按95%目标校准时τ₈=24与τ₉=26不同，不能预设协同区域更小。共线共同镜像是真实结构歧义；有限分辨率外包包含真值不等于精确集合包含。

已完成53项检查器自测、136个输入校验、16项固定输入代数检查和可选3点平稳GMP实现核查。不能写成B正式定位结果已通过，也不能声称具备两时刻计算可行性、实车保护级或任务安全证据。B状态与最终判断以VALIDATION_REPORT和DECISION_MEMO为准。
