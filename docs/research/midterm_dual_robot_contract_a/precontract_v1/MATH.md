# 全部原相容解为何保留

## 1. 原P4集合与统计事件不变

记u=p或s，两辆车的二维天线位置均未知。四个a_i为已知、精确、同坐标系锚点。原域D0=P0×S0，bias闭区间B=[β−,β+]，观测区间I_j=[l_j,u_j]，正定对角R=diag(v_j)，原九维阈值q9=26。

沿冻结合同，

    C4(I) = {(p,s)∈D0 : A_p(p)+A_s(s)+dist(||p−s||, I_peer−B)^2/v_peer ≤26},
    A_u(u) = Σ_{i=0..3} dist(||u−a_i||,I_{u,i})²/v_{u,i}.

这是存在原观测表示值及同一个b∈B的五维集合的位置投影。前处理没有改变C4、q9、R、bias或观测。完整九维事件只使用一次，不能另给两车各26后声称新集合等价，也不增加八个方向的概率风险。前处理是C4的必要条件而非新的统计估计器。

## 2. 从原联合约束到每车锚距外界

由于所有项非负，对任何C4内位置，每个无偏差锚点项≤26。故存在读数z∈I满足|z−d|≤sqrt(26v)，其中d=||u−a_i||≥0。
用原整数平方根核取可靠上界rho+≥sqrt(26v)，得到

    L=max(0,l−rho+),  U=max(0,u+rho+),  L≤d≤U,
    L²≤d²≤U²,  ||u−a_i||≤U.

如果u+rho+<0，原相容集已为空；本版仍允许使用截成U=0的弱外必要条件（空集包含于任何集），不擅自用负上界平方。一般先与非负距离域相交再平方，不能把跨零的[l−rho,u+rho]直接两端平方。这使零距离有效，不需导数、除以距离或Jacobian满秩。

rho采用q9=26，不用q8或拟合自由度。各条锚距界分别使用26只是将原联合球放宽到分量外界，会丢失共同预算约束；它们没有被冒称独立新观测。B只作用于peer，八条无偏差锚点行推导不减bias。I_peer−B及两车共享关系仍由原P4目标检查。

## 3. 平方测距差与可检验凸外松弛

对同一未知位置u和两个已知锚点，精确恒等式

    ||u−a_i||²−||u−a_j||²
      =2(a_j−a_i)^T u + ||a_i||²−||a_j||²

消去同一个||u||²，给有向必要半空间

    c_ij^T u≤h_ij,
    c_ij=2(a_j−a_i),
    h_ij=U_i²−L_j²−||a_i||²+||a_j||².

使用全部i≠j，连同原二维域和四个上界球得到凸外集K_u。真实每车投影包含于K_u，但K_p×K_s通常严格大于原C4：球壳内孔、共享平方距离变量、联合噪声预算、peer及bias耦合被部分放松。尤其将每条成对平方差独立区间化，比Calafiore共享同一ξ的差分多面体还松；不宣称等价于原文X_d或取得其最优SOCP外盒。

只有已知固定a_i才能得到这些固定系数。另一车s未知时，||p−s||²中有−2p^T s和||s||²；把s估计值代成a_i并不保持全部相容状态。最小反例：p=(2,0),s=(3,0),peer读数1,b=0真实相容；若错固定s0=(0,0)，即使B=[−.6,.6]，最小错误peer残差仍.4，v=.0016时贡献100>26，直接剔除合法p。第37测试给出完整九观测零原残差例。

## 4. 八个方向的有理外界证书

每车v∈{−e_x,+e_x,−e_y,+e_y}，目标是证明sup_{u∈K_u}v^T u≤H，而不是求得一个可行点。对重建的线性必要行c_i^T u≤h_i，给λ_i≥0；可另给球乘子w_k∈Q²、t_k∈Q，检验t_k≥0且t_k²≥w_k^T w_k（精确二阶锥条件）。由Cauchy–Schwarz，

    w_k^T u ≤ w_k^T a_k + t_k U_k.

令r=v−Σλ_i c_i−Σw_k。无论r是否为0，都有

    v^T u ≤ Σλ_i h_i + Σ(w_k^T a_k+t_k U_k) + h_{D0,u}(r) = H,
    h_{D0,u}(r)=Σ_j r_j (upper_j if r_j≥0 else lower_j).

这是真正的原域最坏残差修正。不能用“小KKT残差”、经验epsilon或截断负乘子替代；负λ或未证明的锥条件直接拒绝。r=0是精确对偶可行的特例。校验器从原输入重建所有c,h,U，完全不信任求解器保存的矩阵、端点、support_upper、success。

对上方向，候选上端必须≥H，采用min(原上端,候选)；对下方向v=−e_j，候选下端必须≤−H，采用max(原下端,候选)。全部运算用Fraction；外部实现若转十进制，上端向+∞、下端向−∞，再由比较检查，不能四舍五入到内部。闭等号保留，不增加经验容差。

某方向超时、无证书或异常时，记录原因，proof=null，最终采用原端点；即使有看似不错的候选也不使用。其余方向可独立认证，不要求八方向全部收紧。若认证下端严格大于认证上端，反证原C4为空；下端等于上端是合法闭退化盒，不能判空。

## 5. 复合包含证书

设经上述八方向得到D1⊆D0。每个C4内位置满足每个采用方向端点，所以C4⊆D1。创建仅将四个位置域替换成D1的受限输入x1，原观测/variance/q9/bias/预算等字段完全不变，重新计算input_hash。于是

    C4 = C4∩D1 = C4(x1).

后半段旧V2检查器严格核查树根恰等于D1、完整父子覆盖、所有可靠排除叶/内部盒/未决叶/PENDING队列以及逐车投影、圆半径和偏差恢复，得到C4(x1)⊆O_tree。因此C4(original)⊆O_tree。根域外被排除部分的证明来自前半段，不能只把旧证书根改小或伪造旧input_hash。

复合封套绑定original_input_hash、preprocess_hash、restricted_input_hash；checker自行构造x1，不接受调用方提供的任意受限输入。允许P4模式，不接受J5/N4混用或q8。若前半段已证空，必须tree=null，不制造零半径搜索输出。

原V2对内部盒的语义仍是“每个位置组合存在合适bias和观测表示值”；不改变为“所有bias都可行”。预算中止完整队列继续保留全部原相容位置；预收缩并不赋予删除镜像支或未决叶的权限。旧domain_contact现描述D1接触，复合返回另算original_domain_contact，避免把算法截盒边界误称原物理域边界。

## 6. 保证边界

上述覆盖是对整个原数学相容集的包含证明，不依赖有限个真点抽查。概率解释仍条件于原模型、真状态在原D0×B、表示包含等前提；不在收缩后额外要求一个未经证明的“真值在D1”假设。不会收取额外风险，也没有证明平台标定或任务安全。

完整SOCP最优性、最紧外盒和性能收益不在本版承诺中。线性/球必要条件可能很松，共线镜像可被凸外盒填平，中止时可能完全不缩域。安全但无收益是允许结果。
