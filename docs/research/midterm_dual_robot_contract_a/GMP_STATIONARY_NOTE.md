# 可选附加：平稳GMP六时刻小型验证

只验证一个通道、6时刻、固定线性G；不与本轮定位输入连接，不产生随机样本。参数是研究假设：σ²=1，a∈[1/3,7/9]，R(a)ᵢⱼ=a^|i−j|。平稳外包R̄ᵢⱼ=2·(3/5)^|i−j|，包括初始方差2，绝不使用PR126反例已否定的初始方差折减。

## 完整域证明（不是靠三点采样）

g(a)=(1+a)/(1−a)在声明域单调，g∈[2,8]。外包â=3/5有ĝ=4，k=2。
离散平稳谱S_a(z)=(1−a²)/(1+a²−2az)，z=cosω∈[−1,1]。分母正；kS_â−S_a乘以两个分母得到关于z的仿射函数。在z=1端，kĝ=8≥g(a)；z=−1端，k/ĝ=1/2≥1/g(a)。故全部a和z均非负。
任意有限向量v的差二次型是非负谱差乘|Σv_j exp(ijω)|²的积分，所以R̄−R(a)半正定，包括6时刻。固定G左右相乘保序：G R(a) Gᵀ≼G R̄ Gᵀ。该证明不适用于数据依赖的非线性G，也不自动给非Gaussian尾概率保证。

## 实现核查

最多3个参数点预定为1/3、5/9、7/9。G第一行均1/6，第二行为(−1,0,0,0,0,1)，分别为均值与末首差。Fraction精确核查每个6×6差矩阵全部63个主子式非负，再核查2×2响应差全部3个主子式。
3/3参数点通过，0失败，0随机样本；完整有理结果见GMP_RESULTS.json，代码gmp_stationary_check.py。数值只核实现，全部参数保证来自上一节解析证明。没有重复论文完整系统、没有推广到未知跨车交叉谱或时变bias。
