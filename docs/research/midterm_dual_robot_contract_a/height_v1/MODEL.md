# 单历元斜距合同 v1

输入见 input.json。单位 m，p=Car1，s=Car2，未知量依次为 px,py,sx,sy。记录的两车源时刻相差 5 s，作为单个配对历元。四个已知锚点和两车天线高度均为同一 moon_map Z-up 下的给定常数。#137 的源到地图变换 diag(1,−1,−1) 是正交变换，斜距不变；已导出的地图坐标直接使用。当前接口只接受此地图框架。#137 未声明独立任务地图硬边界。若今后采用地图硬域，须另有两车处于域内的任务假设及源框架端点变换凭据。

JSON 数值几何以精确有理字符串给定。若冻结源为 IEEE 浮点，应使用其精确整数比；十进制文件若声明为精确小数可按十进制解析。原始斜距可为单点或向外取整的闭区间。高度是条件量；不确定高度不在此版合同内。输入身份为删除 input_hash 后的 UTF-8 JSON (sort_keys, separators=(',',':'), ensure_ascii=False) 的 SHA256。四个锚点、两车顺序、时间、偏差域、域来源及预算均绑定于哈希。

预测为两端三轴差平方和的平方根。八个锚距无偏差，第九个 peer 预测加 b∈[Bₗ,Bᵤ]。独立高斯原始斜距误差方差为输入 variance，月面冻结值均为 1/625。N4 只用前八行，允许直接传八行输入。P4 使用九行。联合事件是加权残差平方和 ≤ q，q8=24，q9=26；沿用原 Chernoff 阈值证书。偏差消元不改变原始误差维数。

任一相容点的每条无偏锚距均满足 d≤U=y_upper+sqrt(26 Rii)，因为单项非负且 q8≤q9。U 使用上向平方根。若 U<|dz|，两种相容集均空。否则水平半径 ≤ sqrt(U²−dz²)，再次上向取整。逐车将四个锚点的 [ax±radius] × [ay±radius] 取交得到根盒。任一闭区间左端严格大于右端证明空；相等保留。忽略 peer 只放宽上界。此根域来源是原观测事件的必要条件，不需要轨迹、初值或地图域内假设。

对盒内每对坐标取区间差 [a−d,b−c]，平方下界在跨零时为零，否则取两端平方的最小值；上界取最大值。加入已知 dz² 后求和，按 10⁻³⁰ 网格用整数平方根向下、向上包住真实平方根。对距离区间与观测闭区间，残差绝对值下界取区间间隙，上界取两个预测端点到观测区间距离的最大值。P4 peer 将目标换为 [yₗ−Bᵤ,yᵤ−Bₗ]，等价于对 b 和观测值取最小残差。各行残差界平方除以方差再求和，L>q 才可排除，H≤q 可判内部。P4 内部量词是每个位置组合存在相容 b。其余盒保留或分割。

固定位置的八项和为 S，peer 斜距 d。若 S≤26，全体可行 b 为 B ∩ [yₗ−d−r,yᵤ−d+r]，r=sqrt(Rpeer(26−S))。recovery 分别以 S 下界和上界计算外、内半径，并按端点符号选择 d 的上下界。闭区间相切保留；内界为空不单独证明不可行。

证书沿用 #138 的树节点、闭轴分割、counts、queue、projections、cost、bias_recovery 和量词字段，schema_version 与 source_commit 见样例；mode 为 4d 或 no_peer，threshold_certificate 用冻结 core.threshold(9/8)。根盒必须等于 event_root。逐车矩形、中心、外半径和面积上界均按所有 INSIDE/UNDECIDED/PENDING 叶重算。原域空时仅发送身份、模式、观测 ID、阈值、status=EVENT_ROOT_EMPTY，无树。预算停止须保留完整有序 PENDING 队列。时间和峰值内存为执行端记录，独立树验收可复核处理节点计数。
