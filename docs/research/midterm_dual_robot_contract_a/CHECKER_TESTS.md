# 独立检查器测试

53项unittest通过，完整命名清单与结果见CHECKER_TEST_RESULTS.txt。25项以上涉及故意损坏或拒绝输入，覆盖删队列、漏子支、改阈值、重复原始观测、伪造OUTSIDE/INSIDE、父子不覆盖、根域缩小、孤立/循环/重复节点、错误投影和半径、错误恢复、伪空集、量词错误、成本计数、非对角R、多链偏差、时变bias、真值字段泄漏等。

非拒绝检查包括：完整根域与分割；三种模式；空集与null半径；真实的五维/四维量词差异；零距离；精确零余量相切及退化bias；有理MGF尾证书；固定方向能量；单位/坐标/车辆交换/镜像不变性；模型对齐的参考单点切片；完整三方法归档验收及分母损坏。

测试构造手工证书，不调用定位器、不运行搜索Monte Carlo。测试成本是夹具数值，不冒充实测性能。检查器仅给证书有效性；不信任success/lower/upper。核心可信计算以Fraction/isqrt重新计算各叶上下界、偏差恢复、全部投影和半径。测试通过不等于B正式记录通过。
