# 正式输入、评价隔离与预登记

零噪声或预定方向 ε=.04·(1,−1,1/2,−1/2,1,−1,1/2,−1/2,1)m，其完整白化能量6<26，前8行能量5<24。在任何正式求解开发/执行前由本次输入提交冻结，不根据结果调整。平方根生成距离用整数平方根有理上下界，真实合成读数严格包含在保存区间内。

另4个：empty_in_domain将第一读数改为100m（域内最大对应距离sqrt(181)，可靠下界已足以判空；评价中的原生成噪声不再适用，此例是故意不相容输入）；domain_closed_contact真p=(6,0),s=(2,0),b=.6，位置与bias都在闭域边界；coincident_zero_distance两车(1,1),b=0；forced_budget正常输入但max_nodes=1。

代数测试另覆盖真值域外、错误链路、多/重复数据、非对角拒绝、m/mm一致缩放、刚体坐标变换、车辆身份交换、共线镜像、精确相切、退化bias、同九行模型的参考位置单点切片。它们不是新增定位案例。

inputs/random_conditional.json 共120个=3几何×2真实b×20个新seed，每条件20个独立seed，六条件不重复；同一输入的5d/4d/no_peer严格配对。seed范围2026111709000000…2026111709000119，登记中列出全部。
仅生成，A不执行定位Monte Carlo。CPython random.Random(seed).gauss生成9个标准Gaussian伪随机IEEE数，转换其精确二进制有理值后乘1/25。保存完整读数区间和输入哈希。没有依据事件内外、可解性或结果筛seed。有限精度PRNG样本是实现层条件性随机实验，不是连续Gaussian精确采样的形式化证明，也不能用120个样本认证尾风险。

评价真值、噪声、seed只在evaluation_only.json和登记中；正式搜索输入没有真值。A核拒绝附加truth字段。B应只接受单个输入对象；评价程序在搜索结束后独立读取评价文件。
核对共同起点全部名称含seed/registry的77个已跟踪文本/gzip文件并保存每文件哈希，无新seed碰撞。范围不含外部未登记或将来提交；不得宣称全球唯一。输入冻结后不要重新运行生成器覆写它，复现应在临时checkout比对字节。
