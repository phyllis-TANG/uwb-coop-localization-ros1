# 模型与参数

q=(p_t,c,xy)，24个位置分量；M0忽略peer，M1加入peer且不估偏差，M2增加自由常数 b0，M3增加 b0+b1(t-.5)，b0单位m、b1单位m/s。anchor residual=(||[p,h]-a||-y)/.04；peer residual=(distance+b-y)/.04；motion residual=(p[t+1]-p[t]-u)/.02；prior residual=(p[0]-prior_center)/.5。目标½Σr²，无偏差先验。状态尺度位置1m、偏差.1m、趋势.1m/s。初始化由 noisy prior 累加 noisy 增量，加历史固定偏移(.2,-.15,-.2,.15)m；不用真值初始化。方程及初始化在开发集与固定 PR125 完全对照。

|因素|定义/注入位置|依据与适用范围|
|---|---|---|
|white|u=Δp+σz, σ=.02m，z边/车/轴独立|PR125研究设置，未实物标定|
|correlated|e0=σz0；ek=.8e(k-1)+σ√(1-.8²)zk；Cov(ei,ej)=σ².8^|i-j||同方差AR1失配假设，不对应已测轮胎过程|
|scale|white基础上Car2加 .05Δp，相当尺度1.05|5%工程敏感性假设；静止车几乎无影响|
|slip_proxy|white基础上Car2第2索引增量加 .15[cosψ,sinψ]m，ψ来自生成端已知姿态|局部一边短时异常，轮滑影响的观测层代理；未验证轮地接触或月壤动力学|
|normal|peer b=0|历史条件|
|constant|peer六点+.3m|历史条件|
|step|peer前三点0，后三点+.3m|历史条件，估计端不知道切换时刻|
|ramp|peer [0,.06,.12,.18,.24,.30]m|历史条件；M3表示为 b0=.15m,b1=.3m/s|
|time±|peer记录t，但Car2几何取t±.05s；其它传感器不变|独立固定时间偏移假设，不称时钟标定|
|height±|估计端Car2供给高度加±.15m，实际观测高度不变|与PR125 .15m量级一致；确定性双符号敏感性，无真实分布假设|
|missing|peer索引2和3缺失，所有方法相同掩膜|固定丢测窗口，非可信地形遮挡/无线传播仿真|

.04/.02/.5m、1.16m高杆、.3m故障是历史研究设置；rho=.8、5%、.15m短时异常、±.05s是本轮预先冻结的工程假设，不从实测拟合残差宣称校准。每种扩展只改变一个因素，控制组来自核心normal/white同窗口同seed。
