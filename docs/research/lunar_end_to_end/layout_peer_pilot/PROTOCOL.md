# 配对锚点布局与车间测距单历元试跑

本方案先于任何本轮求解或评分写定。基准 main 为 c7d53da2bb989f73514a6ce540813c379d698897。试验使用米和已知天线高度；仅研究给定误差事件下的几何可行性。

* 开发：Moon_1 原主段索引 0、11，原记录的双车位置、天线高度、九个测距噪声，来自 round2_radius/inputs/zero 的 main_start_normal、main_mid_normal。注入车间偏差为零。
* 留出：预先指定一条新的平面合成双车路线，不是独立月表采集序列。t=0…22 秒。车1 (4+0.65t, 4+1.2 sin(t/6), 0.97)，车2 (6+0.45t, -1+1.1 cos(t/5), 0.95)；取 t=4、14。九链噪声用 NumPy PCG64(2026112307) 一次取 23×9 标准正态后乘 0.04 m。同路段共享种子；两时刻两车各有一行，不能当作四次独立试验。
* 原布局与改布局共享同一时刻的真值和生成噪声。改布局把原矩形锚点转为同中心、同占地面积、同锚点高度的正方形，保持锚点所属象限。按三维斜距重新生成八条锚距；同一时刻两个布局的车间观测相同。
* 每布局比较八条锚距、八条锚距＋车间距（未知车间偏差允许±0.60 m）。另作机制诊断：八条锚距＋车间距且车间偏差精确已知为零。三种模型共用同一个 q=26 的残差平方和预算和每链 σ=0.04 m，比较新增约束的信息，不宣称相同概率。发布点由同一布局的八条锚距一次求得，剔除真值，用归档的平方斜距差平面最小二乘算法，其输出在三种模型中保持相同。
* 每车以两个严格可行联合状态的投影间距之半给出任意圆心下界 L，以原求解器的四维包围盒投影至同一发布点的最远角给出上界 U。使用全局根、外舍入有理区间和统一 0.05 m 末端盒宽，无删减未决集合。L>0.10 m 为排除，U≤0.10 m 为保证，其他为未定；真值、模型事件及预算另外逐项记录。节点上限 150000、每项 CPU/墙钟预算 240 s（若达到限额，保留剩余盒并诚实报告）；用于寻找可行点的数值优化不作为证明。
* 在八条锚距的保留盒内同时记录全部可能车间距的外区间。若区间落在第九项自由偏差带 [y−0.60,y+0.60] 内，则额外证明该情形整个可行集合完全相同。比较连续半径本身时，较松的上/下界或重叠区间不足以证明真实最小半径变动。
* 保留所有条件和两辆车，结果按开发/留出分开，绝不替换未跨 10 cm 的条件。若需要区分布局与随机因素，须另做正交扩展；本轮的复验同时更换路线与噪声。
