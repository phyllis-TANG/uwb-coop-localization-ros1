# 观测契约

坐标 moon_map、米/秒；固定6时刻0,.2,...,1s。每个窗口每个 seed 的四个方法读取相同字节观测。模型接口严格拒绝额外字段；观测与 reference 分目录，运行ID是不可读条件的24位哈希前缀，测量ID为 `input_id:t#:r#`。估计器不导入生成器或读取真值、故障标签；调度器读取 reference 仅交给独立评价函数。公开高度是 oracle 高度基线，不是完整3D估计，也不是向估计器提供整条真值轨迹。

每时刻8锚距加1单向peer测距。锚距与peer由三维天线距离生成；噪声每条独立 N(0,.04²)m²。XY 全局增量由真值差分加误差生成，不称为轮速计测量或直接复用真实 odom。初位置先验 N(true XY,.5²I)，估计端只见 noisy prior。增量模型白化σ=.02m，无论真实注入是否相关；高度固定不估计。高度误差会同时影响锚距/peer几何。

AR1与白噪声的每边际方差相同，白化矩阵不随条件改变。随机流按 SeedSequence([seed,window,stream]) 分为range=1、motion=2、prior=3；跨条件复用创新用于配对。独立统计单元是10个 seed 簇；同 seed 下所有窗口、条件、方法相关，六时间点不是六次独立实验。

F0—F3 与 M0—M3 不能仅凭编号等同：PR130 是局部SE(2)位置/朝向及杆臂，按dt的运动权重与稳健pseudo-Huber测距，fullbag无起点先验；这里是天线XY、固定高度、全局XY增量、普通Gaussian平方损失及独立初位置先验。没有朝向状态，也未添加朝向先验。静止朝向问题仅做单独SE(2)杆臂零方向解析验证，不能由本轮核心RMSE证明已解决。

真值和故障实现只供生成/评价；M2/M3 只知道候选偏差模型，不知道实际normal/constant/step/ramp类别及切换时刻。局部GN协方差仅诊断该失配残差模型的曲率，不提供PL/HCPL或安全概率。
