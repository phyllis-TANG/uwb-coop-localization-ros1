在 PR #144 的 188 项归档中，只取种子 2026111801、normal、P4(26)。主段 24 点选索引 0、11，偶数中点取较早者；第二段 23 点选 0、11。索引从 0 开始，四个历元与旧门槛诊断同名。选取及成本过高时的补测规则在首次搜索前提交于 26e1048277f01f1d012c7c3ba8bc07720b65805c。所有读取以 Git 对象标识定位，无需改动 #144 归档。

**对象与半径。** 从原树和已知高度合同读回输入哈希、车号、状态时刻、发布天线 XY 和各车投影。用 #142 对应的 covering_radius 从发布点对全部保留二维矩形的四角计算最远水平距离，并向上开方。粗网格所得有理数半径须逐车等于 #144 的 services 记录。真实误差仅在评价时由原参考天线 XY 与同戳发布点计算。逐车复用了同一发布点；没有重新定位。配对中的输入哈希因预算中的分辨率字段改变而重新计算。

**执行与预算。** 求解器以 #141 原始版本为基础，仅将 UNDECIDED 叶停止宽度参数化。搜索仍使用相同锚距、peer 斜距、给定高度、偏差域、P4 门槛、闭根域、最长轴中点分割和队列顺序。主段首历元完整配对通过后才处理第二组。先保留归档的 50,000 节点 / 30 秒预算，将分辨率改为 1/40 m；达到预算的尝试连同未决队列作为 PARTIAL 存档。随后按预登记规则，在同机串行、双方均 300,000 节点 / 240 秒的条件下从原根重新运行粗、细搜索。粗网格的科学证书必须与旧归档一致；每组粗细运行间唯一不同的求解参数是终止分辨率。每次使用固定 A 检查器重开并独立验收压缩证书，另外显式检查未决叶的最大宽度和队列清空。部分完成证书只证明当时的保守外包。节点统计含分割和叶，候选叶为 INSIDE、UNDECIDED 与 PENDING 之和。

matched_coarse_s 和 fine_s 计入该机的搜索、证书转换、压缩写入、解包、A 核验与分辨率检查。时间截止于核验结束，未包含随后逐车半径读回；同组两次采用相同计时边界。historical_coarse_s 单列，是 #144 原运行的服务时间，测量边界和负载不同。每组仅一次，实测耗时不构成重复试验的速度估计。

**范围。** 这是四个指定历元在一个种子上的水平半径敏感性。门槛按状态时刻直接比较 PL≤AL。未重算 FIFO、截止、失效或到达时刻；不能把跨越半径线解释为新的在线可用记录。此轮亦不支持对其他路段、噪声、锚点布局或真实月壤场景推广。
