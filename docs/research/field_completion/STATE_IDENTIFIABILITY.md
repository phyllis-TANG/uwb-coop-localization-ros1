# 状态可辨识性与数值界限

状态为两车全段车体XY/yaw，输出评价使用经旋转杆臂后的天线XY。全部起点先验移除，模型初始化只读观测，不借助终点/故障类型。

当车辆完全静止时，测距主要确定天线位置，单一刚性安装的天线无法单靠静态距离确定底盘朝向：可以同时改变底盘朝向和底盘XY而保持天线位置。原始局部odom也没有足够运动激励提供绝对朝向。无噪声静态小切片的数值秩不足与此一致。没有添加任意强朝向先验来改变这一事实。

全段拟合时，估计出的微小平移/转角随残差和杆臂共同作用，可让Jacobian在机器阈值下满秩。这不是现实朝向获得了强独立信息，也不是统计意义上的稳健可辨识。必须同时查看最小奇异值、条件数和最弱方向。

results/WEAK_MODES.csv以固定物理尺度后的J做SVD，报告最弱右奇异向量在逐车XY/yaw以及偏差状态中的平方能量。它是局部线性诊断，不是全局唯一解证明，也不是概率覆盖保证。

P0/P1阶段，一静一动两包的缩放条件数约7.6e3—3.5e4，而双车运动两包约1.2e3—1.4e3。前者预算耗尽、后者通过驻点门槛，这与弱激励相关，但仅凭该关联不能把所有误差归因为朝向。P2统一恢复完整保留，最终接受状态以results_p2/NUMERICS.csv为准。

本轮不输出Hessian逆所构造的保护区域。测距工程权重、伪Huber鲁棒损失、方向相关性和未标定外参不满足已验证的概率解释条件。全秩和小梯度都不等于真实精度已验证。
