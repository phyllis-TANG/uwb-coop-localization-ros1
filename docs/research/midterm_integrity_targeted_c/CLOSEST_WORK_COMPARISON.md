# 最接近工作差异表：目前不预设创新性

本表以当前实际实现为基准：六时刻双车XY为24维；B2加一条预指定peer链路的单常值偏差为25维；B3知道注入幅度；运动为全局位移加噪声；固定先验中心不随机重采样。当前曲率/噪声传播候选区域及几何诊断尚非保护级。固定证据分别为PR118所在main `b492c17d719013c31a93168994afe40beed5001f`、PR119 `e35f94fb89a71236bd04c7f25fc318b016ba592d`，详见[桥接审计](PR119_BRIDGE.md)。

|最接近工作|已经公开解决/提出的相邻问题|与本项目实质差异|还缺什么才能比较或提出研究贡献|
|---|---|---|---|
|Drevelle–Bonnifait2013|非线性定位置信域、短历史、区间传播、容许一定数量异常的多假设集合；不是本项目首次提出这些概念|单车位姿/GPS钟差/强道路地图；我们是双车测距与固定survey、已知peer常偏差。其低维当前域与我们的全窗25维不同|固定偏移与相关噪声的独立依据；证明外包/时间概率合同；相同信息与预算下的可用性比较。换成UWB或月球题目本身不构成创新|
|Rohou等2017|整段连续轨迹的可信管传播和非线性约束收缩；支持传播前后时刻信息|原文连续动力学/输入界；我们目前只模拟离散全局位移。其管保解不等于概率风险或故障覆盖|若真实运动需要连续保证，先补整片运动误差界；若仍用离散模型，明确为何无需引入tube。不能将其保证当自己的新定理|
|Hafez等2020|固定窗机器人完好性、故障假设与SS风险分析；非GNSS已有方法|随机历史先验、地标/IMU状态、局部线性化；本项目固定survey与非线性多端点。B2/B3的故障知识更多、尚无未知故障管理|逐假设可辨识性与真实随机块；非线性分支/选择后分布的控制；同等故障知识下的比较。不能把oracle B3优势称为检测收益|
|Kuwada等2026（最接近协同线索）|正式题名/官方摘要明确协同CAV故障模式与完好性；摘要区分个体与共同故障并报告不同收益|**全文未得，方法/保证/模型/代码差异无法判断。** 本项目不能用“未读到”作为方法不重复的证据|先取得全文逐项核方程、位置/幅度知识、模式概率、相关性、子解和成本。未完成之前，新颖性结论保持开放|
|CARNATIONS报告附录A（背景）|协同信息与故障检测，公开报告可定位排除某些跨车估计偏差情形|CEKF/DMV与LiDAR/INS；不是2026论文，也不代表其最终假设|分别定义“原始peer测距有偏”和“共享别车状态有偏”，两者会造成不同相关性与故障传播，不混为同一实验|

最可审查的下一步贡献形式应是**清楚的模型条件、可验证的区域包含及失败边界**。这些结果可能表明当前信息不足或计算成本不合适；可靠负面结论仍有研究价值。但在完成同等条件对照及取得最接近工作全文前，不声称已建立新颖算法或优于已有方法。
