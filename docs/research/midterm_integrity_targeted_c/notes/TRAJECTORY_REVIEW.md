### 面向本项目的独立核查

1. **保证分层。** 给定输入区间、运动模型、地图和搜索域包含真值，contractor及SIVIA的任务是确定性保解。这一层不要求噪声独立。将它称为给定风险的置信区域，还需第二层：这些前提联合成立的概率。位置盒风险、全部输入联合风险和长期任务风险是不同对象。原文的当前位姿外包不能直接推出持续运行期间从不失包。

2. **时间独立性仍是条件。** p8空间采样动机是减少相关；减少并不证明独立。历史盒由同地图、相近卫星、共同偏移和数据选择形成；原始量测独立也不足以自动证明选择后盒的同分布独立。因此我们不能直接使用式(8)的二项式尾来处理跨时刻常偏差。父报告THEORY_AUDIT给出独立推导与相关反例。式(6)的乘积可作为独立量测失包的风险分配；反演后位置失包通常只被它上界，不能不加条件宣称相等。

3. **固定先验/相关噪声。** 论文以地图、初始域、输入界作硬约束，不提供本项目survey固定偏移四维集合的外部依据。采用置信区间而非确定界时，速度/转率、地图、初始域的失包事件也应纳入。按真实联合噪声事件构造，或在有边际界时用不依赖独立性的保守合成，是我们的迁移义务，不是原文已经完成的结果。

4. **故障删除和可辨识性。** q-relaxed的集合并不等价于识别出唯一故障后丢掉该项：允许解集会随q增加而变大。当前B2已知peer且有一个常b，不能把它解释为“o个历史盒中最多q错”。若故障跨窗口持续，坏盒数可能超过q。移除关键测距后，位置域可能分裂、宽大或无界；保留多支是正确的负面结果，不能强行唯一化。

5. **数据选择和外包。** p6的历史管理规则依赖观测盒。它可改变概率样本的分布，但只要每次选择后所有所用约束确实成立，确定性包含仍可成立；两件事应分别论证。p5道路筛面也要求筛选不排除真实道路；本项目没有可直接替代的精确月面可行道路图。

6. **搜索域/未决/空集/无界/超时。** Alg.2明确只在初始盒内反演。小到阈值但未认证的盒必须保留。论文提到超时策略，但没有给可直接移植的外部结果状态合同；我们必须把尚在队列的盒并入返回外包，或拒绝输出。空集可表示模型/区间/域不一致，不能解释为误差为零；有界搜索盒不能证明原问题不存在域外或无界解。论文不提供本项目无界场景的PL规则。

7. **有限“盒粒子”不自动有证书。** 原文使用subpaving并做预测，术语中出现box particle；要核查其所有父盒是否经包含映射保留，不能只凭名字等同随机粒子，也不能把有限随机粒子当完整外包。本项目若保留完整盒覆盖及全部未决项，有限盒数量可有外包意义；如果随机选盒/按权重删盒，就需另外证明。

8. **实验/成本适用性。** 实测能支持该场景中的可行性，却不能用相关历元次数验证罕见尾部。CPF的局部Gaussian表示、滤波输入处理和区间方法的强地图约束并非完全相同；论文没有给所有误差分布/调参/算力一致的通用优越性证明。其输出到20 Hz包含低延迟预测，不能当每次完整鲁棒反演均在50 ms完成。当前位姿3维、GPS子问题4维、Appendix q-relaxed在(e,n,cosψ,sinψ)四维；不可外推到本项目24/25维全窗反演成本。未找到经固定版本核实的2013原系统代码与许可证，不能声称可开箱复现。

**分别评价：** 证据质量为“全文可核、数学前提明确但概率独立性与部署域仍需审计”；迁移适合度为“区域集合/保留歧义/有限窗结构高，GNSS地图数据及二项式风险数字低”。不因概率迁移受限而否定其确定性方法。

## 2. Rohou等2017：连续轨迹的可信传播模块，保守性和循环网络代价应保留

正式条目：Simon Rohou、Luc Jaulin、Lyudmila Mihaylova、Fabrice Le Bars、Sandor M. Veres，*Guaranteed computation of robot trajectories*，Robotics and Autonomous Systems 93:76–84，2017，[DOI](https://doi.org/10.1016/j.robot.2017.03.020)。[机构仓库](https://eprints.whiterose.ac.uk/id/eprint/114446/)明确已发表及accepted version身份；本轮精读[作者稿](https://simon-rohou.fr/research/tubint/)9页。不是预印本结果冒充未核实的正式发表。

### 原文锚点

|模型与保证|p1式(1)微分方程及已知噪声界；p2式(3)–(4)区间积分；p3式(7)–(10)contractor收缩、保解、切片外包。|
|实际新模块|p4式(11)将方程拆成ẋ=v及v=f(x,t)；式(14)–(15)、p4–5 Alg.1–3按整个时间片导数范围前后传播。|

|维数与实验|p6式(16)3维Dubins状态；式(18)–(19)2维位置及一二阶导数；p7式(22)AUV位置/体速的3+3维演化、姿态等为输入管；p7–8实测用两次位置观测收紧全轨迹。|
|可用代码入口|p8 §7作者软件入口；现已演化成Codac，不能混称论文原版本。|

### 独立推导与迁移判断

保解关键不是“步长足够小”，而是整片导数包含。对时间片[a,b]，若边界状态x(a)∈G且每个τ∈[a,b]均有ẋ(τ)∈V，则对t∈[a,b]有

$$x(t)=x(a)+\int_a^t\dot x(\tau)d\tau\in G+[0,b-a]V.$$

与已有片盒求交仍保留真轨迹；反向同理。这里V必须包住**整个片**，不能以端点导数f(x(a),a)替代后把有限Euler步叫精确。该推导解释式(14)–(15)及Alg.1–3的包含机制，也避免将式(12)的微分步形式误用为无余项的有限步等式。没有据这一记号推断作者实现错误。

- **概率、偏移、相关性：** 方法是对既定误差界及动力学的确定性包含，不给Gaussian尾部或固定survey偏移的概率。固定未知常参数应跨片共享；若逐片各设独立自由区间，外包可能仍正确但丢掉相关约束而更宽。未知故障位置管理不在该模块中。任何先验硬域都需要独立依据。
- **多解与可辨识性：** 管可以包含所有合法轨迹而同时很松；点态包络中的不同时间点不一定能拼成一条合法轨迹。收缩到固定点不等于可行集已精确求出，非空也不证明有解。删观测不能增加信息，剩余管可能不可用；原文没有逐故障秩监控或solution separation合同。
- **域与异常：** p6可从全实管开始再由初值收缩，不代表所有系统最后必有有限域。空管是约束不一致；非空管可能未决；停止传播时只要每步保解，当前管仍是外包，但尺寸可能过大。原文没有为本项目定义超时后的可用率/有限保护级标准，应由我们的协议另定。
- **实验/比较：** Dubins示例与CAPD比较了包络尺寸；没有从该图得到跨硬件、同预算的速度排名。AUV例支持实际数据融合可行，不是独立重复的概率覆盖试验。全文未给可用于本项目估算的统一计时/峰值内存表；不能填写“实时25维”或固定耗时。
- **实现成本：** 以N片、d个标量管计，单次前后扫片约O(Nd)是我们按算法结构的计数；完整非线性循环网络还乘以迭代及函数contractor成本，没有给出统一迭代上界。25维空间全局分支枚举与低维管的收缩是不同复杂度问题。

**分别评价：** 证据质量为“可核全文、保解定义和构造充分、性能比较范围有限”；迁移适合度为“运动约束可信传播模块高，当前离散位移模型的必要性中等，概率风险和未知故障覆盖低”。目前首个低维验证可以直接用离散运动等式，暂不增加连续动力学假设；之后有IMU/连续时间需求才引入该模块。

## 4. 向后扩展与本轮排除记录

[Rohou等2018](https://doi.org/10.1016/j.automatica.2018.03.074)，*Reliable non-linear state estimation involving time uncertainties*，Automatica 93:379–388，正式出版页及[作者全文](https://simon-rohou.fr/research/tubeval/)已取得。它把量测时刻区间作为约束处理；本轮仅核获取及后继身份，未计为第五篇核心逐式精读。当前仿真时间戳理想，先加时钟模型会扩大范围，故暂留背景。

2013论文中的基础方法指向区间分析、SIVIA及robust set inversion；1993 SIVIA基础文献由本轮主审单独核查。概率外包与管传播可组合，但本轮没有构造或验证完整多机器人系统，更没有运行Monte Carlo。时间独立、错误先验、长期故障和域外真值等不利情况应作为方法边界保留，而不是为了保持原论文的风险数字而删去。
