# 定向文献矩阵：证据质量与迁移适用性分开评价

检索日期：2026-11-17。核心精读 **4篇**，其中1993基础文献和2020 SS文献在PR118基础上定向复核，2013短轨迹及2017轨迹管为新增主线。Kuwada2026虽最接近协同故障主题，但未取得全文，**不计精读、不推断其公式**。版本清单见 `notes/*ACCESS.json` 和 [检索日志](SEARCH_LOG.md)。

“证据质量”只评价本轮可核查程度、数学条件、实验与代码证据；“迁移适用性”评价与当前双车模型的对应。可靠但不利的方法边界不会被降为证据薄弱，也不按期刊或年份给总分。

## 5. 可靠的负面证据和未取得证据

- **可靠负面证据：** SIVIA高维/高精度成本；C3循环约束可能收缩不佳；PR119轻扰动未修复车2覆盖；标准SS对子解信息的需求。它们约束方案适用域，不应删掉。
- **可靠元数据但尚无公式证据：** Kuwada2026。官方摘要关于车辆特有故障收益有限的表述可登记为待全文复核的负面线索，不能升格成已验证定理或忽略它。
- **背景而非新增核心：** Nicola–Jaulin2020（PR118已读作者稿，用于Gaussian输入事件）；Rohou2018（已取得作者稿，仅核后继身份/时间不确定性主题）；CARNATIONS机构报告（相关故障假设，非2026正文）。
- **不作为安全证书：** 有限粒子/多初值/密集网格、未经来源支持的偏差域、未绑定代码版本的计时、截断搜索域后假称全局、删除不可用或不利故障模式。
