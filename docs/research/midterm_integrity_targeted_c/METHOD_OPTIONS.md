# 最多两条候选路线与实施顺序

**推荐下一轮先实现“低维非线性可行集的可信外包验收模块”。** 首先完成仿射解析基准和二维测距双解，不直接替换定位器，也不立即扩展到双车六时刻。它能直接检验当前最缺的“全部可行分支有没有被保留”，并清楚区分信息不足、概率模型不足和计算不完整。这里是建议，尚未实施。

排序不以经验覆盖能否更好为前提。PR119较强几何扰动的有利结果说明存在更适合局部近似的条件，但轻扰动不利结果、固定五初值和点/轨迹差别仍在，详见 [PR119_BRIDGE.md](PR119_BRIDGE.md)。

## 路线1：测量事件反演＋可信外包，先作离线参照

**只实施的模块。** 对预给域与非线性观测约束求保留所有解的外包。第一版 q=0，已知模型；不同时加入未知故障排除、偏差学习、鲁棒核或连续时间管。保留原定位中心作为区域半径的参考点，中心落在哪支不决定删去哪支。

**依据。** C1给外包不变量，C2给短历史/多假设约束结构；概率入口按本轮THEORY_AUDIT的联合噪声事件重推。C3只提供未来需要时可用的可信运动传播模块，不是第三条并行路线，也不代表现已完成连续时间建模。

**准入条件。**

- X、固定偏移D和候选故障/常偏差域U包含真值有独立依据；若仅作条件研究，必须逐项写明条件。缺D依据时不凭覆盖调半径。
- 已知联合噪声事件的概率；可用真实相关Gaussian椭球，或有依据的边际区间合成上界。没有时间独立证据就不用二项式风险。
- 模型和区间实现保持包含；所有未决/待处理盒都保留。离散运动先按当前代码模型，不增加未完成的IMU假设。
- 在目标投影非空、有界且计算证书完整时才评估有限保护半径。任务AL/告警时限/最终风险仍待定义。

**成本与阶段。** 二维解析例需要区间基本算术、一个集合反演循环、完整状态账本和几何度量；可选经固定版本核查的IBEX/Codac依赖，未给工时承诺。静态合同通过才到两时刻4维，然后评估是否值得24/25维。C1明确的维数成本、C3的循环收缩不足、实际固定偏移/相关性依据都是实质风险；不保证高维可用。

**否证条件。** 在声明域、输入事件和模型内存在可行点被外包排除，否定当前包含实现；如果所有合法解都保留但区域大到不可用，这是信息/保守性或计算效率的负面结果，不否定集合逻辑。若只能通过删队列、缩域或挑最优支得到有限小区域，拒绝其保护区域资格。

**为何先做。** 不需要把非线性估计误差设为Gaussian，不要求先确认唯一分支，也不依赖已知故障率；能用解析例检验边界和失败语义。代价是外包可能很大、很慢。这是可审查的离线安全量化基础，不是宣称已经有在线保护级。

## 路线2：预定故障模式的 solution separation，先做可监控性门槛

**只实施的模块。** 先建立有限故障族、逐假设删行/清洁子解及关注方向可辨识性检查；再在仿射模型核SS事件。未通过前不写非线性在线检测器，不把它和路线1拼成一套未经验证系统。

**依据。** C4是有全文的固定窗机器人SS基础。N1 Kuwada2026是最接近协同研究线索，全文未得，因此它的具体方程、保证和性能不作为实施依据。该访问限制应保持到取得原文为止。

**准入条件。** 故障发生位置集合必须覆盖真实模式，区分单测距、整条持续peer链路、共同偏移和传递别车状态误差。删除后要有至少一个正确清洁且目标可辨识子解；自由b失去全部支撑后必须重新定义。固定survey与随机历史先验分开推导；全解/子解相关性、选择和故障假设之外事件均进入合同。没有模式概率依据时只给每模式条件分析或最坏界，不虚构总体风险分配。

**成本。** 故障族增大带来更多子解及秩检查；局部非线性还可能跨分支，使简单Gaussian分离界不适用。C4中检测阶段与风险界求值阶段的成本优势并不相同，不能整体宣称SS更快。作者代码可读但论文对应版本/复用许可未确认，暂只借事件接口。

**否证条件。** 允许模式下无清洁可辨识子解、固定偏移使分布不符、全解/子解停在未控制分支、或拒绝模式被删出统计，均否定该条件下的可用实现。改善全量几何不保证删除关键边后仍成立。若只调阈值才能掩盖这些问题，暂缓实施。

## 条件式分流

|后续证据|应优先做什么|何种结果会削弱该解释/路线|
|---|---|---|
|直接求解的仿射参照都异常|先核随机块、固定先验、相关性、维数、选择规则；用A1解析集检查|错误全部纠正后仍异常，应重新核事件定义；不能归咎非线性|
|仿射正常，非线性异常|路线1二维多支/边界与近似余项；对照原定位中心和外包|已证全分支、全部模型条件正确仍漏包含，否定实现；若只是区域很大，说明可用性问题|
|如PR119较强几何改善|保留其局部适用域证据，同时查全部解与联合事件|全局歧义仍存在或轻扰动未改善，不能把“破共线”设为通用安全充分条件|
|破共线仍不改善|核固定偏移、噪声/运动模型、选支和接受规则|在这些前提被独立控制后仍失败，削弱纯几何解释，不通过追加幅度寻找有利结果|
|D内有效、D外失效|明确D的独立依据和条件结论；不向外推|D内且噪声事件内的可行点被外包排除才是包含反例；单个Gaussian尾部失覆盖不是|
|数值接受/超时主导|先完成输出状态与未决队列合同，报告可用率/大小/成本|保留证书后仍无法提供有用区域，否定当前预算可用性；不能删除失败提高覆盖|
|允许故障删测后失去锚定|路线2先判不可用，保留该模式|若目标实际不受零空间影响可重审目标可辨识；不能用全状态满秩作为唯一或伪造必要条件|

本轮不调整现有门槛，不追加实验，不设最终风险目标。完整未来用例和验收规则在 [VALIDATION_PROTOCOL.md](VALIDATION_PROTOCOL.md)。
