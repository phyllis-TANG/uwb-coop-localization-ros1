# 低维验证方案：先验证外包合同，再讨论安全性能

状态：**拟议协议，未执行、未启动 Monte Carlo、未开发新定位器。** 这里的尺寸、输入和代数例是将来确定性验收用例，不是修改 PR119 的实验设置或已有接受门槛。下一轮实施前须提交代码版本、算术后端、预算和完整用例清单；不能看到结果后改变合同。

## 1. 首个实施对象与隔离原则

先实现一个独立的二维集合反演/外包验收模块，保留项目现有定位器。输入是声明的域、约束和噪声集合，输出是内盒、未决盒、待处理盒、拒绝证明与状态标签。第一轮只做已知量测模型，q=0；未知故障容错和 SS 另作准入检查，不同时集成。当前六时刻24/25维问题暂不扩展。

目标不是让区域更小，而是确认：完整可行集是否始终被外包、哪些条件下没有有限有用的区域、计算预算是否允许进一步研究。严格包含来自数学不变量和可靠算术；有限测试只能发现反例，不能代替证明。

## 2. 输入及计算合同

- 搜索域必须先声明并解释来源。测试域是合成问题定义的一部分；实际部署域需独立依据，不能取真值附近或最佳局部解附近。
- 区间系数/超越数使用可靠包含，分裂共享闭边界。不得把普通浮点 sqrt 的结果冒充精确 $\sqrt2$，不得因“离边界很近”删除盒。
- 记录后端版本、完整 commit、舍入模式、编译器/优化选项和所有传递依赖；不使用可能破坏舍入的 fast-math。检查零距离、零宽度、无穷端点及 NaN 的处理路径。
- 主预算采用固定节点数以可复现，另记墙钟时间。设置中断点为尚未处理、处理单盒后及分裂后等固定步骤，以检验队列账本；不是随结果延长预算。数值精度、节点上限及硬件记录在实施轮冻结文件，本文不对实车给时间承诺。
- 停止不改变包含方向：未决和队列留在外包；不能返回内盒或已完成分支当全局域。无完整账本则不可用。

## 3. 用例和解析对照

|编号|问题定义/输入|独立解析参照|必须观测的失败与准入条件|
|---|---|---|---|
|A1 仿射满秩|$y=A\theta+\epsilon$，$A=\left[\begin{smallmatrix}1&0\\0&1\\1&1\end{smallmatrix}\right]$，$\theta\in\mathbb R^2$；$R=s^2\left[\begin{smallmatrix}1&1/2&0\\1/2&1&0\\0&0&1\end{smallmatrix}\right],s>0$。先用声明的确定性阈值 κ，再给概率语义|令 $M=A^TR^{-1}A$，$\hat\theta=M^{-1}A^TR^{-1}y$，$d=\min_\theta(y-A\theta)^TR^{-1}(y-A\theta)$；集为 $(\theta-\hat\theta)^TM(\theta-\hat\theta)\le\kappa-d$|κ>d椭圆、κ=d单点、κ<d空集三类齐全；若赋Gaussian概率，κ取 $\chi_3^2(1-\alpha)$ 而非残差自由度1。遗漏相关项应由对照发现|
|A2 固定偏移|在A1基础上增加 $c-E\theta\in D$，E预定、D为预定闭区间/盒；比较固定非零在界内、恰在边界和界外|椭圆与固定条带/盒的交；固定 c 不重新抽样，D不作为Gaussian行|在界内且噪声事件成立的可行见证被排除即失败；界外失覆盖不能否定条件性定理，界外偶然成功也不验证D依据|
|A3 秩亏/无界|$y=\theta_1+\epsilon$，未给 $\theta_2$ 先验|全状态为无界条带，$\theta_1$投影有界、$\theta_2$投影无界|不能把任意有限搜索盒解释为全局域；拒绝全二维有限PL，允许单独注明可辨识目标。有限域内的计算结果应标domain-limited|
|R1 双解|锚点 $(-1,0),(1,0)$，两距离均 $\sqrt2$，测试域 $[-2,2]^2$，先精确距离后给预声明正宽区间|精确可行点恰 $(0,1),(0,-1)$；正宽时为双环带交|两支都必须保留；没有内盒不表示没有解。多初值/粒子或网格只作见证比较，不充当解析参照|
|R2 加信息|在R1增加锚点 $(0,2)$，第三距离1；或明确有独立依据的半平面约束|精确三距只剩 $(0,1)$。对照半平面若无独立依据不得加入实际问题|比较全分支区域变化；丢支只能由约束排除证明支持。两个锚点无论怎么摆放仍共线，不能把移动其中一个叫解决一般二维镜像歧义|
|R3 边界/切触|R1将正支置于搜索域闭边界；另以两半径1、中心 $(-1,0),(1,0)$ 的相切圆|闭边界真解必须保留；相切点 $(0,0)$ 为零面积可行集|分裂缝、严格/非严格不等号、错误平方根舍入均可能漏解；可靠算法可只给未决外包|
|R4 空集|同上两锚点半径均小于1，例如精确 $1/2$|两圆距离不满足相交条件，严格不相容|全域排除后才标certified-empty；只因所有局部优化失败、没有内盒、预算不足都不能判空|
|T1 超时|在R1以固定节点预算强制停止，顺序换成不同合法分裂策略|两真解仍在“已保留＋队列＋当前盒”并内|队列必须进入外包；未完成时不得用已发现一支给紧区域。比较保守大小及可用率，不以速度掩盖丢解|
|Q1 容错结构准入|同一二维问题预定3个有限绝对测距约束，声明至多1个不可靠；逐一解析各2约束交后取并|3个子集交的并是 q-relaxed 定义；子集可为空，有限环带使非空子集仍有界；无界删约束另在A3/S1构造|只挑残差最小子集不得取得完整容错标签。此项先纸面/解析验收，尚不把容错模块集成第一版|
|C1 时间相关反例|两历史盒失败指示完全相同，o=2/q=1；同时列独立与任意依赖边际情形|完相关超预算概率r、独立为 $r^2$；一般边际按已证明界|无需抽样即可否定无条件二项式假设；不从空间采样或窗口长度推独立|
|S1 删测后可辨识|线性小网络分别给足锚定及删除关键锚定边的情况；自由偏差只在一条边出现|逐假设矩阵秩/零空间；关注目标F须消灭全部不可辨识零空间，即 $\ker A_h\subseteq\ker F$|删边后的无信息b必须显式移除/改合同；失秩模式不得从假设族或可用率中消失。这里只核SS准入，不写检测器|

A1 中可通过取在 $R^{-1}$ 度量下与 A 列空间正交的残差构造三类 d，与选择的固定 κ 无关；无需寻找有利随机输入。概率解释用完整三维噪声，不能把“解析可行椭圆”与标准两维估计误差椭圆混淆。两者都是可讨论对象，但对应不同事件和保守性。

A1的初始搜索盒由解析约束推出，不能任意裁切 $\mathbb R^2$。独立手算为

$$
M=\frac1{3s^2}\begin{pmatrix}7&1\\1&7\end{pmatrix},\quad
M^{-1}=\frac{s^2}{16}\begin{pmatrix}7&-1\\-1&7\end{pmatrix},\quad
d=\frac{(y_3-y_1-y_2)^2}{4s^2}.
$$

当 κ>d 时每个坐标的完整外接区间为 $\hat\theta_i\pm(s/4)\sqrt{7(\kappa-d)}$，实现须向外舍入；κ=d时保留单点，κ<d时解析认证空。A2在该盒内增加固定约束即可。A3的全域无界性质单独解析判定，不宣称第一版已支持一般无限初始盒的全局求解。

## 4. 短轨迹扩展仅作为第二道门

只有静态二维合同通过才设计两时刻二维状态（4维），加入当前项目已有类型的离散全局位移约束。先保留对称双支的零横向位移，再加入有独立依据的横向信息；不用真值选择分支。逐步记录因子相关性、初始域和偏差域，不把三维平面车位姿论文直接映射为双车24/25维。

若未来需要连续时间，再用 $\dot x(t)=t$、$x(0)=0$、$x(t)=t^2/2$ 的解析 tube 用例核整片导数包络；只在采样点画正确曲线不够。该连续时间例是 Rohou 公式的验证方案，不是本项目已经具有的 IMU/轮速融合模型。

## 5. 同时评价覆盖、大小、可用率和成本

每一计划输入都保存一条记录。静态确定性用例先报“已知全部可行解/解析集的包含核验”，不把测试通过比例叫罕见风险覆盖。若以后单独授权随机验证，需要另冻样本量、联合输入分布、独立单位和统计计划，本轮不设置/执行该矩阵。

|维度|必须记录|解释边界|
|---|---|---|
|包含/覆盖|解析点/集是否被外包；证明依据；未来随机时分别给点和整条状态入集|只核有限见证不是全解覆盖证明；随机事件外失覆盖不等于包含实现错误|
|大小|目标投影面积上下界、直径/半径上界、盒数、未决体积、分支结构；无界写∞|有重叠盒的体积和只能当上界，不能直接当精确面积；零面积真集也可能有正外包面积|
|可用率|全计划分母；输出、certified-empty、unbounded、domain-limited、timeout-with-enclosure、numerical-uncertified分类|区分“有可靠区域”与“满足任务大小/时限”的可用；没有AL与时限不得报告运行可用率已达标|
|成本|墙钟时间、CPU/内存峰值、节点数、收缩调用、外包质量、硬件/线程/编译选项|未决宽时的快返回不能与高精度完成直接比快慢；超时全保留|

如比较局部椭圆、有限多初值或粒子输出，应共用输入/域/预算并明确其不具包含证书；两种方法不能用不同先验、不同数据筛选或不同故障知识后直接比较安全性。区域质量与定位中心误差分别评价。

## 6. 通过、否证与退出

通过二维合同只允许进入4维方案评估，不宣称当前系统 PL 有效。出现噪声事件内、域内、模型一致的可行点被“可信外包”排除，立即否定该实现证书并定位区间运算/剪枝/状态账本。解析集很大或预算下外包很宽，应记录信息不足/计算不可用，不能调先验域或裁掉不利支。

若二维都无法在记录预算内给有意义外包，暂不扩到24/25维；先区分信息不足和收缩效率不足。若二维可靠而4维成本快速增长，可考虑依赖图/投影和更强收缩器，但每次只改一个模块并重走包含合同。不得把通用区间工具库的保证直接视为整条应用程序的保证。
