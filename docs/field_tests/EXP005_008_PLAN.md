# EXP005--008 双车实验计划

## 硬件分配

已知可用硬件暂按 `3 × LinkTrack P-B + 1 × LinkTrack P-A` 记录。第一轮使用两个
P-B，每辆车一个；第三个 P-B 作为备件并为后续“一车双节点、另一车单节点”方案保留。
P-A 不进入第一轮基线，除非其型号、固件、频段和参数兼容性经过单独只读核对。

严禁在本计划中刷固件、恢复出厂、修改墙上节点、给不明线路通电或发送未知串口命令。
如确需修改手持设备参数，必须先保存完整原始配置并另行审批操作步骤。

## 统一真值定义

- 使用卷尺测量两块 UWB 天线统一参考点之间的直线距离；
- 优先让两天线处于相同高度，并记录高度、朝向和参考点照片；
- 地面贴标记，记录卷尺读数到厘米；
- 不使用车壳、保险杠或车轮间距代替天线间距；
- 每段实验开始前口头报出实验编号，并在记录表中写下开始时间。

## EXP005：双车静止 LOS 真值测距

目标：首次得到可用于误差计算的绝对距离真值。

| 项目 | 方案 |
| --- | --- |
| UWB | 两个 P-B，每车一个 |
| 距离 | 1、2、3、4 m |
| 时长 | 每点 60--90 s |
| 姿态 | 等高、同向、无遮挡 |
| 必录 | 两侧 `/uwb/ranges`、`/uwb/frame3`（如两侧均接入 ROS） |
| 结果 | bias、MAE、RMSE、标准差、P95、空帧率、双向差 |

通过条件：四个距离均获得稳定非零测距，bag 可回放，卷尺真值和安装照片完整。

## EXP006：双向一致性与姿态敏感性

目标：比较 `N0 -> N1` 与 `N1 -> N0`，并检查天线朝向改变是否产生系统差异。

1. 选择 2 m 和 4 m 两个距离；
2. 每个距离先保持推荐朝向 60 s；
3. 仅旋转其中一辆车 90°，再采集 60 s；
4. 不移动卷尺参考点；
5. 比较双向测距、FP RSSI、RX RSSI、丢失节点和电压。

## EXP007：双车人工推动 LOS

目标：建立 UWB、odom、IMU 与 TF 的动态数据接口，不要求立即完成融合。

- 先只读确认两车实际话题名和 `frame_id/child_frame_id`；
- 记录两车系统时间、ROS Master、IP 与 chrony 状态；
- 直线人工推动，低速往返，不开自主导航；
- 建议 2--3 次，每次 90--120 s；
- 至少录制两车 UWB、odom、IMU、`/tf`、`/tf_static`。

## EXP008：双车人工推动人体 NLOS

目标：在与 EXP007 相同路径和速度下加入人体遮挡，观察正偏、突变和 RSSI 变化。

- 遮挡者位置和持续时间需要记录；
- 原始数据不能在录包阶段删点；
- 分析时同时报告完整数据和明确规则下的异常统计；
- EXP001--004 的约 `+0.39 m` 只能作为现象参考，不能直接补偿 EXP008。

## 推荐 rosbag 内容

实际话题名需先由 `rostopic list -v` 核实。命名空间完成后建议：

```bash
rosbag record -O EXP007_two_car_manual_push_LOS.bag \
  /car1/uwb/ranges /car1/uwb/frame3 /car1/odom /car1/imu/data \
  /car2/uwb/ranges /car2/uwb/frame3 /car2/odom /car2/imu/data \
  /tf /tf_static
```

如果两车尚不能共用 ROS Master，两车分别本地录包，文件名加 `_car1`、`_car2`；
同步问题留到离线处理，禁止为了赶进度直接覆盖系统时间配置。

现场开始时可在每台计算机分别运行只读快照脚本：

```bash
rosrun uwb_coop_localization collect_field_snapshot.sh \
  /home/wheeltec-client/uwb_experiments/EXP005_snapshots
```

脚本只读取主机、时间、网络、ROS 话题和串口枚举状态，不打开串口，也不改变设备配置。

## 到场停止条件

出现以下任一情况时停止动态实验，保留证据后回到诊断：

- 型号或节点 ID 与记录不一致；
- 串口稳定路径消失或权限异常；
- 两车时间差无法解释；
- TF 中出现同名 `odom`/`base_link` 冲突；
- UWB 输出为空或距离不随物理移动变化；
- 任一设备异常发热、反复掉电或线缆松脱。
