# 2026-10-18 双车现场工作清单（8 小时）

## 当天目标与完成标准

优先获得能够复查的双车数据，并尝试首次双车离线联合估计。
当前已有成果是单车固定高度二维离线批量因子图；在线双车融合尚未验证。

- 必须完成：两车同时录制有效 UWB、Odom、IMU，保存时间诊断、天线安装信息、人工参考和 SHA-256；至少包含双车静态与一车静止一车运动。
- 争取完成：在相同输入、初始条件和参数下，对比两车独立估计与加入车间距离约束的联合估计。
- 额外目标：角色互换或两车同时运动。实时双车结果留待录包回放验证之后。
- 不预设融合必须优于 Odom，也不把端点误差当作整段轨迹 ATE。

## 4. 时间检查

- [ ] 对两车与虚拟机记录系统时间及现有时间同步服务状态。
- [ ] 采用多次请求和往返时间记录时钟差估计；一次 SSH 读时不能作为毫秒级同步证据。
- [ ] 同时保存消息 header 时间和 bag 接收时间，检查倒退、重复、延迟和偏差随时间变化。
- [ ] 同一 ROS Master 不会自动同步两车时钟。时钟偏差未查清时，先收集静态数据并记录限制，不声称已完成同步动态融合。
- [ ] 调整时钟或重启节点必须在正式录包前完成；发生跳时后单独重新录制。

## 5. 最小双车实验集

### S1：双车静态（每个布置 30 秒）

- [ ] 两车固定在独立测量的点位，记录两根天线中心三维坐标与朝向。
- [ ] 至少测量一次两天线间距离；条件允许采用两种间距，各录一包。
- [ ] 人员退出 UWB 连线；记录车间双向测距、墙节点测距、Odom、IMU、电压。
- [ ] 标定数据与之后评价数据分开；若估计链路修正，冻结参数后再录评价重复包。
- [ ] 双向测距不默认是两条独立信息；联合模型先选定单向或保守聚合，避免重复计权。

### D1/D2：一车静止、一车运动（同一路线重复两次）

- [ ] 首先固定 Car1，Car2 沿已标路线运动；出发前、途中可测停点和结束后各静止至少 10 秒。
- [ ] 固定车的位置仍有测量和估计不确定度，不能无条件当成零误差移动基站。
- [ ] 明确每车位置/朝向先验、墙节点观测和车间距离的使用方式。
- [ ] 记录实际起终点；运动过程中不靠人站在连线旁持续测量。
- [ ] 先使用已有验证过的单车控制方式，避免同时调试两车控制和融合。
- [ ] 一份包同时录两车实际发现的 UWB、Odom、IMU、速度指令、电压话题；有 TF 则一并录制，无 TF 则记录缺失及外参。
- [ ] 无速度指令话题的静止车可以照常记录，但注明并非通过该话题确认静止。

- [ ] `rosbag info` 能读、已结束录制、无遗留 `.active`；各必要话题持续有消息。
- [ ] 检查运动段与静止段、Odom 位移、车间距离变化、各链路异常和时间间隙。
- [ ] 保存 SHA-256、人工坐标、朝向、外参、时钟记录、照片及失败原因。
- [ ] 给重复包预先固定同一模型与参数，比较“无车间距离”和“有车间距离”。
- [ ] 二维联合图联合估计两车状态，车间因子使用两根天线的三维距离（包含高度和水平偏移）。
- [ ] 一条瞬时车间距离不能唯一确定二维相对位置或朝向；当前初步实验依赖初始参考、Odom 和可用墙节点约束。
- [ ] 用独立测得的停点/终点评价，汇报测量不确定度；残差减小或轨迹看起来平滑不等于精度提高。
- [ ] 不用同一条 Odom 既筛选观测又当真值，也不从同一底盘来源的 IMU yaw 与 Odom yaw 推断有独立双重证据。
- [ ] 通过离线回放后再实现按时间顺序运行的在线版本；在线运行不等于已证明实时性能或准确率。
