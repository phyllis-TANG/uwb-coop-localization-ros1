适用于正式实验 v1.1 的 `results/REPORT.md` 与 `results_reviewed/REPORT.md` 中 metrics.csv 行数说明。原文“全部72个‘24次运行×3方法’指标行”只描述了诊断子集，遗漏开发行。准确表述是：

**metrics.csv 共 87 个数据行（不含表头），其中开发 15 行（5 次独立运行 × M0/M1/M2）、诊断 72 行（24 次独立运行 × M0/M1/M2）。**

两个既有目录的 CSV、报告、图表均保留原字节。本说明作为额外审阅勘误，不回写旧报告；`tools/report_single_car_integrity.py` 的报告模板已修正，未重新生成旧报告。审核器和新增测试分别读取实际 CSV 断言 87/15/72。

行数不是独立实验次数，不把开发运行混入 3 次名义诊断的正常误报分母。名义 M1/M2 共同可监测时长仍为 261 秒；M2 报警 13 秒约 5.0%，来自一次连续事件 [4,17)，不代表 13 次独立误报或长期误报概率。历史实测仍只报告报警占比。没有调整阈值、重新评价误差或重新执行估计器。
