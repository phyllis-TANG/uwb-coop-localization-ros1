## 共同科学与执行约束

- 模型使用每车[x,y,yaw,b_gz]；联合时8维。输入为Odom.twist车体线速度与IMU发布角速度减残余零偏。允许板端已校零，但不声称两路统计独立；不将IMU姿态作为绝对房间yaw，不进行加速度双积分。
- 在新模型运行中，Odom pose仅可用于预先声明的一次初值/参考绑定及冻结旧基线；不持续引入其yaw/角增量或随yaw旋转过的pose增量来掩盖陀螺仪替换。测距几何和杆臂传播必须与新运动模型一致。
- 必须有四种运动输入对照：冻结旧Odom-pose基线；相同body线速度＋Odom角速度；相同body线速度＋IMU角速度且残余bias固定0；相同body线速度＋IMU角速度并估计bias。中间对照用于分开传播表示和IMU的贡献。本轮优先独立/固定peer联合两类融合，可靠性九策略保留为既有成果，待新模型稳定后另作适配，不强行套6维索引到8维。
- 默认关闭IMU。关闭路径必须调用冻结旧实现并保持结果；不能用“gyro替代odom但变量名没变”充当关闭回归。
- 按接收时间因果回放，源header/receive以整数ns保留；2ms最近匹配仅是审查方法，不是在线输入规则。不得拿稍后才到达的IMU反向填进先前区间；不得从视频/人工终点/留出结果估计时间或零偏。
- 量测噪声、过程噪声、bias初值/随机游走、IMU轴/符号、时间映射/缺口门槛逐项写单位、来源和适用范围。记录协方差常量及静止候选统计不自动成为标定；敏感性步长也不是误差界。
- 第一轮实包限T10与T08。T10成功重试SHA f2853240661be0cef53e77cee9a5a33f74cfb1524231d2eb94b2dcacaa57c558；T08 SHA cf3b4de0f20424d02779aeeb416a4fb16d77bb1f5333344d48ebf446a3884ada。T09/T11/T13/T15整包留出，不解码/评价；T12/T14本轮不扩展。
