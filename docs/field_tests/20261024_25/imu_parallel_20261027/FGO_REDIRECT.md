## 共同算法路线

基于main 397beb6dbe0a60dd64e39eb186345014d3a54b16中的tools/single_car_fixed_lag.py、single_car_sequential_replay.py、run_single_car_fixed_lag.py及docs/field_tests/single_car_fixed_lag_20261022/protocol.json。沿用20秒固定窗口、1秒关键帧、原测距聚合/发布等待和有界缓存；本轮主算法是固定窗口因子图，不迁移至EKF。

第一版为平面IMU融合：保留UWB测距因子及原Odom平移约束，加入gyro_z角增量因子、每关键帧残余零偏和bias随机游走。状态由[x,y,yaw]扩为[x,y,yaw,b_gz]。这不是完整三维加速度预积分；不把加速度直接双积分或将厂商IMU四元数当绝对房间yaw。

因MCU可能已处理gyro，默认IMU实验臂以gyro因子替代原Odom yaw因子，避免将其视为另一份独立航向约束重复叠加。原Odom平移增量仍依赖Odom坐标表达，相关性假设须披露；不得声称消除了全部上游关联。若保留两份角因子，须单列模型并说明交叉相关/保守权重依据，不能默认为独立测量。

固定对照：F0原因子图；F1同平移因子但按相同积分规则使用Odom角速度；F2同平移因子＋IMU角增量、bias固定0；F3同平移因子＋IMU角增量、估计残余bias。这样分别检查角增量表示变化、IMU输入和零偏估计的作用。初值、UWB修正/权重、窗口、参考和评价口径逐项匹配并记录，不能只比较跨求解框架的结果。
