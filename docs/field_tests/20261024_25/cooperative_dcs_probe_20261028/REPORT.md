# 最小DCS对照：开发结论

**本轮固定Phi=1的DCS能抑制直接peer偏差，但没有同时保住共同墙偏差下的Car1收益与Car2代价。** 这是三个已暴露seed的开发诊断，不是独立验证、完整性保证，也不证明所有连续降权方法无效。36逻辑单元齐全：27个D0–D2逐源码/输入/配置/产物SHA一致后复用，仅新增9个D3；没有参数搜索、实包或IMU运行。

D0独立；D1原pseudo-Huber联合；D2原q>3固定门控联合；D3仅替换peer为DCS标量适配。Phi=1在结果前依据[原文V.A默认值](https://www.ipb.uni-bonn.de/wp-content/papercite-data/pdf/agarwal13icra.pdf)冻结。墙/Odom/几何/初值/sigma=.2m/20秒窗口/1秒接收等待均未改。公式、真实接受目标和IRLS曲率的区别见[对应表](FORMULA_MAP.md)。执行源码`19f1bbaa42d6631cc3c2d8660953d13a17ae76de`，读取main为`ca8fbac4dbdf678074be5fb80bf6aff472d258e6`。

两种比较不能互换：同一故障输入下，D3相对D0的Car1故障窗RMSE分别减少83.9/87.1/88.4mm，Car2增加58.1/95.0/57.3mm；同方法故障相对配对正常，D3的Car2增加56.2/94.0/60.9mm。恢复窗[38,48)相对D0的Car2代价仍为62.2/68.8/36.0mm。[两种配对图](figures/paired_tradeoffs.png)与[逐项差分](results/paired_contrasts.csv)分别列出参考对象，无团队平均掩盖代价。

机制直接证据：共同墙偏差故障窗的全部1596/1449/1491次活动peer线性化权重更新中，**s²全部为1**；最大名义残差仅.148/.157/.159m，未超过Phi=1对应的.2m转折。联合解能让peer残差小，同时将错误绝对信息传播至Car2。DCS此时对peer的约束比原pseudo-Huber更强，Car1较D1再改善约6–7mm，Car2较D1再恶化约7mm。[同期图](figures/car1_common_wall_bias_synchronous.png)、[内部权重](results/internal_weights.csv)支持该机制；不以小残差当真值保证。

反例与未出现现象：直接peer +1.2m时D3故障窗平均信息权约.00314/.00317/.00319，相对定位RMSE为.0219/.0260/.0380m，D1为.2920/.2916/.3082m；D2也有效，D3并未逐车全面优于D2。正常情况下D3与D1接近；D3相对D0的Car2全程共同accepted代价为+0.452/+0.753/−2.202mm，不能称各车一致改善。D2在共同墙偏差故障窗42/42次均准入，没有该段健康peer误拒绝。[正常](figures/nominal_synchronous.png)与[直接peer故障](figures/peer_bias_synchronous.png)均覆盖三个seed。

全部2268次联合发布有限，2196 accepted，72启动预测；每车有限均2268，求解失败/缺peer/缺Odom均0，D2有18次启动unknown，与故障分开。13项新合同及27项旧合同通过，1890次边缘化均由独立公式/有限差分回读。D3每63帧回放含IO约1.16–1.47秒；与复用旧时机成本不可作同期速度优劣结论，virtual发布时间不是ROS延迟。

已消元peer权重冻结于完整联合prior，未回滚；59秒时故障相邻聚合因子已离开活动窗但仍有15个对应peer身份进入prior，不能据20秒窗口宣称历史影响消失，也未做干预来量化其独立误差贡献。此结果支持继续讨论“如何保留协同收益并控制健康同伴代价”的问题，但**不预设新算法必要性，不批准候选路线**；其他Phi、真实空间/时钟误差及未见场次均未检验。本轮本地保存，未推送/建PR/合并。
