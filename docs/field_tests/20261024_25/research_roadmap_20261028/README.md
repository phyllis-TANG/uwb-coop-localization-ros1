## 研究问题与贡献门槛

当某车的局部绝对定位信息有偏，而车间距离仍正常时，如何限制协同给双方带来的位置改变，同时保留有价值的帮助？中期报告以安全性量化为总方向；会议先研究可检查的协同影响，不声称已有绝对保护级、概率完整性风险界或月面实证。

PR70 的已暴露开发例显示：DCS 可抑制直接 peer 大偏差；局部墙链有偏时，正常 peer 仍可传播绝对偏差。具体结论只适用于原配置、开发种子及评价窗，不能扩大成“所有鲁棒核都无效”。[PR70](https://github.com/phyllis-TANG/uwb-coop-localization-ros1/pull/70) 的原报告与结果应独立保留。

本次解析分析把上述机制化简到可逐式检查的模型。它还显示，简单预算可能同时压缩帮助与伤害，甚至与廉价裁剪等价。**只有验证了相对简单缩权／裁剪的必要优势，才值得扩大性能实验。**三角不等式、加约束或换求解器本身不作为主要创新。

## 候选方法的一页合同（尚未实现）

1. **状态与参照。** 原二维固定窗口图保留其模型。每车另存自启动起从未接收 peer 因子、协同后验或其边缘先验的参照图。参照与联合解使用相同观测前缀、状态时刻和坐标定义；不要求二者统计独立，也不假定参照准确。
2. **控制对象。** 令实际发布的天线水平位置为 `a_i = XY(p_i + R_i * lever_i)`。拟研究 `||a_joint_i - a_ind_i|| <= b_i`，两车都检查，不使用仿真健康标签选择受保护方。仅约束线性增量或底盘点不满足该合同。
3. **历史与求解。** 联合图保留完整交叉 prior；当前 peer 权为零不等于历史无协同。不得拆 prior、清空历史或把双独立运行伪装成联合求解。新求解器需有相同求解器关闭控制的回归对照。
4. **预算与在线输入。** 主预算尚未确定。只能据任务允许影响、正常代价、参考能力和开发协议选择，并在未见评价前冻结。解析文件的 0.04 m 仅是解释数值，不是部署推荐。任何质量自适应必须写清输入、因果时序与预算变化规则；不假设非线性解随 peer 权单调。
5. **输出政策。** 在加入实图前，先固定启动、参照缺失、超预算、超时、历史污染和恢复的政策。成功、参照回退、unknown、未发布必须分开记录。若回退到独立状态，不能把拼接的位置／航向／协方差称为一致联合后验。此处没有批准一种尚未定义的协方差修复方法。
6. **有限保证。** 实际位置满足预算时，距离真值的误差变化绝对值最多为预算；同一固定样本集合有 `RMSE_joint <= RMSE_ind + RMS(b_t)`。这不提供绝对精度、概率覆盖、故障相对正常的界，也不保护未约束的航向。
