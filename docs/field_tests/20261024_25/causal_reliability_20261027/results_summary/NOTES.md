# 报告补充与图表审阅

本目录只读取冻结结果，不运行估计器、不改变配置或阈值。自动报告及旧图保留于report/。新热图使用独立色条轴，避免色条压住Car2末列；新增计算时间、发布轴gate转换和全部可用性/回退行数。

normal、peer_bias、pulse、ramp中的role=car1仅是角色不改变输入后的规范索引，不表示发生了Car1墙故障。其他场景role表示墙支持/故障或Odom缺失车辆；所有场景仍只有Car1→Car2 peer更新。

gate转换表是首次在发布轴观察到闭合/重开的时刻；精确逐peer事件转换仍在events.jsonl.gz。状态时刻与发布可获得时刻分列，不把延迟/保持状态解释为当前车辆保护。availability行数含窗口外EOF陈旧保持，不把这些行数当独立试验或风险概率。
