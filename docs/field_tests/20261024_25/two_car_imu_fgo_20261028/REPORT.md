冻结基础核为`ca8fbac4dbdf678074be5fb80bf6aff472d258e6`，核对远端main仍相同。M0/M1调用原六维F0；M2/M3为八维gyro+bias，M1/M3均保留原单向pseudo-Huber peer。20s/1s/1s、墙链、权重、几何和非IMU参数不变；未加入质量控制、门控或回滚。缺gyro无角边、预测保持yaw，不暗退Odom转角；完整8维联合prior保留交叉、affine和常数。M0/M1 bias=null/CSV空值，真实零估计正常计算误差。

**合成结果不支持把IMU接入直接解释为收益。** 两个已暴露seed全部报告，四种条件差分在同一时刻计算。正常场景Car1的共同有效XY RMSE，M0→M2为23.55→23.22 / 16.46→16.50 mm；M1→M3为22.02→21.53 / 15.59→16.67 mm，变化很小且不一致。对应yaw RMSE，M0→M2为2.15→3.06 / 1.37→4.04°，M1→M3为2.06→2.88 / 1.46→4.50°，均恶化。恒bias场景仍有明显yaw/bias误差；不能把数值满秩或收敛当bias可观测。

**协同传播仍出现。** Car1四墙同时+.30m时，健康Car2故障期XY RMSE的M1−M0增量为55.0/88.6 mm，M3−M2为58.9/96.7 mm；恢复期分别63.5/70.2与59.3/65.6 mm。IMU没有隔离传播。Car1全程yaw RMSE，M2为21.33/20.96°、M3为14.57/14.16°，比F0大；同期bias响应与墙故障一致，但没有干预实验支持“唯一根因”断言。原peer偏差同样未被IMU消除。正常协同代价、反例、全有限/每车有效/共同accepted和共同有效分母均在[完整表](SYNTHETIC_TABLES.md)与[阶段A最终报告](STAGE_A_FINAL.md)。
