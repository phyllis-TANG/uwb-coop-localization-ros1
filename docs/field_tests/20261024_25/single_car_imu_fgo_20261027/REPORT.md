# 单车20秒固定窗口IMU：A端一页结论

**实现和合成验证完成；没有证据支持把IMU设为默认或宣称现场精度提高。** F0调用原因子图；F1仅把角增量改为Odom角速度积分；F2改为IMU且残余bias固定0；F3估计bias。四臂使用相同平移、UWB/P1、初始输入及1秒发布等待。本轮未访问任何实包、留出、视频或车辆。

冻结执行源码 `e3a20fe04a6d53973696ec055dbc71eb135e0f77`，协议SHA `b377df4988b6307d8edb31f6291c79237324de962a2f41d8397836353e260520`。8场景×3开发种子×4臂，**96次回放、4704次发布全部完成**。80项测试通过（新43+原37）；96次独立回读通过。没有正式运行失败、求解失败或F2/F3 Odom角回退；负例/失败注入测试另列，不能从“0失败”推断长期可靠性。

F3相对F2能缓解有偏gyro，但仍不及本生成器中未注入gyro故障的Odom基线。**24组输入中F3的全量XY RMSE有17组劣于F0、13组劣于F2。** 正常场景也付出代价；偏测距可被错误吸收到bias。轮速滑移中F3的XY略好，yaw RMSE却由F0的.142rad增为.260rad；不能只报位置收益。静止零杆臂时F3 bias RMSE仍约.025rad/s，yaw RMSE约.725rad，没有实现可靠零偏辨识。精确零位移单元测试也验证bias信息不会凭空增加。

所有4704次都有有限pose；求解尝试4512次、失败0次，另有192次前两帧暖启动。常规每臂每次有效47/49；缺口场景F2/F3有效43/49，四臂共同有效也为43/49，其余场景47/49。**全部覆盖、失败率和共同有效RMSE同时见[96行指标](review/metrics.csv)，没有因缺IMU删除试次。** 当前有效只表示数值收敛/当前角覆盖，不等于位置可信认证。

IMU源缺口[18,22)s使`state_time_s=19,20,21,22`四个关键帧缺角，23恢复当前完整角边；过去发布不重写。对应合成真值原点的时刻另加.01s，整数ns保留于CSV。正常F0状态时刻XY RMSE约2.20cm，而同一延迟输出在虚拟计算可用时刻约11.44cm；F3约2.48/11.55cm。**1秒等待不能当当前车辆位置的及时输出。** 全样本平均完整更新F0/F1/F2/F3约2.61/6.88/7.01/8.56ms，单次最大F3 30.63ms；只代表本机离线测量，非部署时延保证。

下一步最值得做：①B按冻结接口整理004023/005135真实gyro及原输入SHA并复现F0；②相同输入/参数跑F0–F3，独立回读角积分、回退与含bias边缘化，保留全覆盖和共同有效表；③核实安装轴/符号、时钟和Odom上游依赖，在合格独立参考验收后另起版本决定噪声/零偏或缺口策略，不按人工终点调参。
