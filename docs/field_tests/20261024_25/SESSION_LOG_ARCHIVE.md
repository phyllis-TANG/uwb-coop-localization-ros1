## 10. Car2 源码与模型审查

用户已上传 car2_base_source.tar.gz 与 V550_mec_robot.urdf，原件保持不变。
源码归档在 VM 上通过 `gzip -tv`；分析端安全解包45个条目。

- CMakeLists.txt将 wheeltec_robot.cpp 与 Quaternion_Solution.cpp 编入 wheeltec_robot_node；backup.cpp不是该目标的构建源。
- 控制板同一24字节串口帧返回 vx、vy、角速度和板载IMU六轴数据。ROS侧用速度与主机时间间隔积分XY/yaw。
- Odom姿态使用积分yaw；不直接读取 /imu 的姿态四元数。下位机角速度是否由编码器、陀螺仪或两者融合产生，仍未知。
- /imu姿态由上位机根据陀螺仪与加速度计算，源码采用固定20Hz步长。不能直接认定Odom与IMU是独立噪声源。
- Publish_Odom 把积分yaw同时写入 position.z；该字段不能当真实高度。当前不修改车端驱动，离线处理需明确忽略其高度含义。
- 源码的协方差是常量模板，不是本次实验标定结果；IMU姿态范数在检查包中约0.998313，原样保留，后处理使用前需明确归一化策略。
- URDF轮关节前后间距0.1576m、左右间距0.19658m，平均位置相对base_link为[-0.0028581,0.00001345,0.0167]m。
- 实车用户测得前后轮轴心距0.175m（已复测），左右轮中心距约0.195m；裸露铁轴0.165m是另一测量对象。
- 模型前后尺寸与实测不同，尚不能直接据此确定物理Odom参考点。URDF本身没有base_footprint和gyro_link；launch的零水平/零gyro变换只是模型定义，不足以证明实物重合。
- 当前源码归档尚未与运行二进制建立构建哈希对应，也不能自动证明历史版本一致；下位机固件/运动学定义未取得。
