# 单车质量 FGO 失效解释：一页结论

本轮解释已有合成结果，未重跑正式96组、未改v1内核/阈值/结果。共同基准`868349b`，执行证据固定`12a1d943`；完整归档及2138个文件实读SHA匹配。8个健康链误降权事件全部重建，3个共同故障seed全部分析；它们是3个共同原因实验，不能把12条相关链当独立样本。

**健康链误降权来自受污染的参照。** 同seed原始输入证明健康测距、Odom、gyro和真值与nominal完全一致；触发两帧的健康测距误差为−3.64～+3.66cm，影子预测误差却达约0.27～0.40m。每张影子只排除自身目标，健康链影子仍以g=1消费故障node_10。主图将故障链停用并不能净化这些影子。8次均由两次高分进入g=.1，无健康链停用。ramp/443更在故障结束8.01秒后才误降权，不能解释为新测距故障。

**共同故障造成错误但自洽的选择性降权。** node_2/3的影子常吸收约0.26～0.29m共同偏差，分数偏低；node_10/8优先被抑制。Q3当前UWB最弱XY方向曲率的故障段中位数只剩Q1的10%～14%。单天线瞬时UWB不能独立约束yaw，运动与gyro的yaw–bias耦合允许偏差被吸收：gyro残差更小，真yaw/bias反而更差。
