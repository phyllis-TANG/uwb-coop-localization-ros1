P/Q坐标是指导摆位，未取得逐点复量和测量不确定度；Q视频对应仍为暂定。名义Q点未参与拟合，但不能升级为独立尺量真值。Car1的名义位置差只是给定假设下的诊断，`actual_independent_position_error_m`保留null；Car2三个检查点缺可靠提取。正式空间容差未由协调端预先批准。

## 时间及运动覆盖

公式以bag首条接收epoch ns（十进制字符串）为原点：`receive_relative_s = a * video_PTS_s + b`。不读取视频文件名时间当同步，不使用理论sleep，不用待评价的融合轨迹。

|实验|匹配边界数|候选时间关系|
|---|---:|---|
|T08|2|a=1.000000, b=83.294s；未验收|
|T09|2|a=1.000000, b=-25.488s；未验收|
|T10|2|a=1.000000, b=-24.955s；未验收|
|T11|2|a=1.000000, b=-16.799s；未验收|
|T12|3|a=1.009611, b=-27.146s；未验收|
|T13|3|a=0.999691, b=-12.104s；未验收|
|T14|1|单边界对应多个阶段，保留偏移候选族，不选定映射|
|T15|1|单边界对应多个阶段，保留偏移候选族，不选定映射|

这些是运动边界拟合候选，0.02s等小残差不是独立同步精度。边界要求前/后有真实静止观察，重新可见和跟丢均不算起步/停车。2Hz采样、1s视觉中值滤波、0.25s odom位移窗及物理响应差均保留；总时空误差界未知，正式映射不获准。

T08–T13在相应候选映射下名义运动时间跨度被视频覆盖，但这不等于全程标记可用或位置参考合格。T14/T15目前不能唯一确定全动作时间覆盖，不能据视频/bag时长不同认定视频损坏或截断。
