# 协同影响控制：第一轮最小开发结论

**合同成立，尚无足够证据支持扩大候选性能实验。** 图内双车天线XY预算能在保留完整联合历史的条件下限制发布位移，并保留部分协同帮助；但本轮相对同预算直接裁剪没有稳定、必要的优势，计算成本明显更高。建议停在最小开发阶段，先明确裁剪无法满足的实际需求，再决定是否重定机制；不追加seed/阈值寻找优势。

**相对直接裁剪增加的是“在图内寻找满足发布约束的状态”，尚非已验证的性能必要性。** K004对C004故障窗改善仅Car1 0.579mm、Car2 0.105mm；恢复窗Car1改善0.078mm、Car2恶化1.001mm。双方最大轨迹差约3.47/4.79mm，显示非线性/历史下并非严格等价，但不等于稳定优势。61个参照有效时刻两者都可发布；C004有21次post_clip，不能因其不叫联合优化成功而宣称K可用率更高。PR71对称一维边界的SLSQP与直接裁剪确实相等，未发现额外优势。

正常输入4cm预算未激活：K004相对I全程参照有效61帧的RMSE变化约Car1 −1.533mm、Car2 +0.272mm，与J/裁剪接近。同SLSQP关闭控制U与原J最大天线差为0.0592mm；1m预算K100与U最大差小于0.000086mm，未激活。数字路径变化已单列，不把它当控制收益。[全部逐车分段表](TABLES.md)、[含启动全有限表](ALL_FINITE.md)、[差异同期图](figures/candidate_differences.png)保留所有对照、help/harm及分母。

实际双车发布预算均通过预登记1e−7m容差，K004最大正超量1.14e−10m；C004约8.05e−16m。1008逻辑发布全部有限，各单元前2帧unknown，共32；开发中fallback/timeout/求解失败均0，相关负例合同已测试。原参照的状态和私有prior在全部时刻与I一致，完整联合交叉prior保留；59秒K004仍有38个已消元peer身份和非零跨车信息，未清历史。未做干预分离prior的独立误差贡献，不把移窗当遗忘。
