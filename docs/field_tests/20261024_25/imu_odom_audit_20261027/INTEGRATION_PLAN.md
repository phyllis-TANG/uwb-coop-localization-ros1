1. 收入Car1当前底盘src/include/launch及两车版本/可读活动二进制SHA；与旧Car2源码比对。未运行节点时仍可收集源码，不为取证启动底盘。当前采集与历史部署分开标记。MCU未公开时不假装odom和IMU独立。
2. 显式配置gyro_link到body的旋转/平面Z符号来源；T08 Car2已有同号转弯趋势，Car1现有两开发包缺有效大转弯激励，保留未知或明确工程假设。首先仅做平面Z角速度，不将完整IMU平移外参/相机标定全部作为写原型的前置条件。
3. 按到达顺序保持独立的odom/IMU源时钟和状态时刻，使用真实相邻gyro时间间隔，不沿用固定20Hz积分。拒绝未来/过期/过长缺口，保留初始化、等待和恢复记录。2ms离线最近配对工具不能直接当在线准入器。

5. 零偏初值和随机游走/噪声参数必须有来源或明示工程假设。当前5秒候选统计不自动成为标定；不能将ROS硬编码1e−6视作实测噪声，不能用T10终点/未验收视觉调参。
6. 合成测试覆盖恒偏置、角度wrap、IMU先到/后到、时间缺口、单位/轴符号、漂移、启用/关闭回归；冻结协议后，在T08/T10开发包做有/无bias及原基线对照。诊断IMU不可用时的回退，不默默插补。现有位置参考未验收时只比较响应/一致性，不宣称现场精度提升。
