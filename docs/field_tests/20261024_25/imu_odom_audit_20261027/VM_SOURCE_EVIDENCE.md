# 商家虚拟机源码补证

本次新增材料是用户从录包虚拟机 `wheeltec_robot.zip` 取出的四份源码，合计46,235字节。本轮只读取和比较文本，没有执行、编译厂家C++或访问设备；没有新的定位回放、标定或精度评价。原18项测试记录不增加计数。

## 来源边界

这套代码登记为**商家虚拟机参考源码**，不登记为Car1或Car2实验时实际部署源码。压缩包清单中的2022年时间是成员时间，不是控制板固件版本；原ZIP未在本次上传，未核验整个ZIP的SHA。已对四份实际上传文件逐一计算SHA256，见[静态比对结果](vm_source_comparison.json)。没有向公开仓库复制四份厂家原始文件或私有访问链接。

## 已确认的具体实现

以下行号均指用户本次上传文件。

- `wheeltec_robot.cpp:368–393`：底盘角速度Robot_Vel.Z来自串口索引6、7；gyro_z来自索引18、19。陀螺仪字段仅作有符号数转换和单位缩放，再作为IMU角速度发布。本上位机路径未见对该发布角速度作零偏扣除；控制板发送之前的补偿仍未知。
- `wheeltec_robot.cpp:423–445`：Odom以发布主机时间间隔积分底盘速度，航向由Robot_Vel.Z积分；另调用Quaternion_Solution计算IMU姿态，没有将这份IMU四元数写入Odom航向。
- `Quaternion_Solution.cpp:3,26–29,37–80`：姿态算法使用陀螺仪和加速度方向反馈，固定20Hz步长，twoKp=1、twoKi=0。四个文件中未见后续增益赋值。**Kp不是“编码器/IMU融合比例”；Ki=0只表明这段上位机姿态函数关闭积分反馈，不证明控制板没有校正陀螺仪零偏。** 未输入磁力计或外部绝对航向，不能将输出当房间绝对yaw。
- `wheeltec_robot.cpp:142–152`：注释中“运动时IMU更可靠”对应实际操作为选择并拷贝两套Odom协方差；没有在该分支进行状态融合。这可供外部滤波器使用，但不证明外部滤波器在实验时运行。
- `wheeltec_robot.cpp:94–114`、`wheeltec_robot.h:42,47`：分别打发布时戳，gyro比例为0.00026644、加速度除数1671.84；协方差固定，不能从常量或注释推定已标定噪声。

两份主驱动有一个与版本核对有关的差异：Car2归档首次积分前检查_Last_Time是否为0，而本次虚拟机版本没有该保护。若首次非零速度对应未初始化时间间隔，旧版本可能积分过大；本轮未建立部署绑定，**没有将此风险诊断为任何历史包的故障，也没有修改厂家程序**。四元数快平方根的long位宽/别名问题与原审查相同，仍只作待确认可移植性风险。

## 对IMU接入的影响

虚拟机确实补充了有价值的驱动实现证据，并与Car2已归档实现的一部分一致。未知项现已更集中：MCU怎样生成发往ROS的底盘角速度、内部零偏/融合处理，以及两辆车实际部署的历史版本。

这些未知项不阻塞默认关闭的离线原型。仍采用body线速度和gyro_z−bias作传播，替换旧Odom角运动输入；保留两路上游可能相关的假设，避免再把Odom航向、IMU四元数和原始gyro当成独立信息叠加。本轮**尚未实现或启用IMU融合**，未更改原三基线/PR54，不读取T09/T11/T13/T15留出包。
