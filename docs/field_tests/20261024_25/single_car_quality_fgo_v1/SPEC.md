# 单车逐链路UWB质量控制 v1：实现前规则

每关键帧每墙锚的原±.4s raw中位数构成一条UWB因子。检测参照是同F0/F3骨架、从初始化起永不消费该锚的四张影子图；各自维护完整状态、历史和边缘化prior，不从主图复制。影子图其他链路仅原伪Huber，信息倍率恒1，不递归自适应。共享Odom/gyro/初始化/其他墙误差意味着它不是独立真值。

在当前t+1s cutoff、主图解算之前，比较该锚raw减一次P1的中位数与其排除影子图在t的天线斜距。工程分数abs(range-prediction)/.20m，保留带符号原残差、原Huber量与来源；没有标定预测协方差，不称NIS/PL。原quality NaN/null完全不使用。影子求解未接受、F3当前缺角/秩不足、其他有效墙少于3或XY测距Jacobian奇异值比<.15、缺待检测距时为unknown，不强行判健康/故障。

唯一规则：正常倍率1，分数≥1.5连续2次降权至信息倍率.10；≥3连续2次停用为0。低于等于.75连续3次进入恢复试用.25，再连续3次低分恢复1。恢复中一次高分≥1.5退回.10、≥3退回0。unknown重置连续计数、保留此前倍率；初始unknown保留基线1，明确不表示可信。缺测时actual multiplier=null、information_admitted=false；不把缺测当停用。

信息倍率g只以sqrt(g)乘**既有伪Huber之后**的残差/Jacobian，名义R/P1/Huber不改。首次入图冻结并写不可改账本；重线性化、消元仍用同倍率，只消元incident因子，保留完整位置/yaw/bias交叉和affine。g0实现零信息行并显式标记，不声称以前的非零因子或prior已被清除。本轮不历史回滚、不锁bias、不切换定位器。

主/影子图使用同一1s等待和有界缓存；影子先处理同cutoff，主图仅引用精确同state/cutoff快照，禁止读更晚快照。日志提供prior链、每因子原记录header/receive整数ns和输入依赖DAG；分数及初次倍率在主解算前冻结。Odom/gyro角冲突只记录诊断，不用于判谁错或调整非UWB因子。
