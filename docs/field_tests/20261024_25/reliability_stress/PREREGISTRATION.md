# 合成可靠性实验预注册

基准为 PR45 合并提交 `4a379da4044a5fd6d36cb8c3e2c53f4a7d120d5b`。本文件和 frozen_config.json 在第一次实验运行前提交。开发种子只用于正确性和实现检查；验证种子只运行一次正式批次，看到验证结果后不改数值算法、配置或评价标准。代码修错导致验证失效时必须保留旧运行并标无效，不能伪称首次验证。最多六小时累计工作预算，起始 UTC 2026-10-26T05:56:50Z。

## 可反驳假设

- H1：有偏 peer 因子在联合解中改变两车，含正常墙观测的另一辆也会产生相对独立解的附加误差；残差反馈可能令偏差变得自洽，Huber 未必阻断传播。
- H2：用永不接收 peer 反馈的独立影子解检查创新，并限制每辆输出相对影子解的位移，可限制错误传播。对被判为健康的车，在任意 tick 有 `||x_firewall-x_independent|| <= 0.06 m`；这是位移界，不是真实误差界。墙几何弱时上限为 0.35 m。
- H3：撤掉影子隔离、允许输出反馈（其余门控、状态机、位移上限不变）会使持续/缓变故障下的传播变差。若不变或更优，则该实验不支持隔离的必要性。

主指标：故障窗内另一辆车的逐种子 RMSE、P95 误差及相对独立解的附加 RMSE；两辆均报告全时段/故障窗/撤除后指标、误差超过 0.5m 的比例和任何超限运行比例。主比较 firewall 对 fixed、Huber、no_firewall，正常代价对 independent。结果按完整种子配对，bootstrap 置信区间以种子为单位；同一种子的场景、镜像、帧不能当独立重复。

恢复：从 30s 故障撤除起，第一个连续 2s 满足 `error_method <= error_independent+0.03m` 的时刻；未恢复写 null/右删失，另报告 gate 重新开放时间。零表示撤除时已满足。缺测、几何恢复也用相同规则。正常场景无恢复指标。

## 固定设计与比较公平性

12 个场景、源车镜像、开发 3 种子、验证 20 种子，具体值在 frozen_config.json 中。每条轨迹 48s、5Hz，故障窗 [12,30)s，随后完整恢复；验证使用不同轨迹、1.3 倍观测/里程噪声和更大故障幅值。包含正常、单向/共模持续偏差、尖峰、单向缺测、异步延迟/重复乱序、单墙、薄几何、单墙与偏差叠加、缓变小偏差，以及墙和 peer 同源自洽故障的失败案例。合成故障不是现场 NLOS 标签。

各方法每 tick 都分配同一计算上限：一个独立影子更新和一个对照更新，各含墙后验与 peer 更新两个阶段，每阶段固定 4 次 Gauss–Newton 迭代，合计 16 次 4×4 线性系统求解。即使无 peer 也执行空 peer 阶段；禁止按方法自适应加迭代。完整 4×4 协方差保留车间相关性，不能把相关后验当独立先验。所有对照共用相同初值、Odom、墙/peer 输入与准入规则。记录实际线性系统次数与耗时，工作量上限相同不保证墙钟时间完全一致。首次实验前实现审阅将原先草拟的分块墙更新改为此完整相关性更新；未根据任何数值结果修改。

复用 PR45 的三维 antenna/wall_distance 几何与 run.json/estimate.csv 契约。为隔离 peer 传播，使用二维 base XY 状态及仅由 Odom 积分的 yaw（不是完整 SE(2) FGO/实包定位基线）；固定高度和 lever arm 只来自合成配置。所有方法同样处理 yaw 与协方差。每步 Odom 先验、墙观测由固定迭代 MAP 更新；Huber 只对 peer 标准化残差作 IRLS。

## 因果、身份与相关性

估计器只接收已到达 Odom 和测距；不接收 truth、故障标签或场景名。精确整数 ns 表示采样/到达时间；合成时钟映射已知。通过已到达 Odom 增量把采样时刻的几何搬到当前状态，禁止把异步距离直接当同步距离。超龄、未来采样、坏身份、重复记录、bridge 非主观测分别拒绝并计数。真实时钟映射未知时接口应阻塞，不把接收时间当采样时间。

每 unordered peer 对、每 200ms 四舍五入采样窗至多一个因子；同窗双向用预设奇偶方向优先规则择一，晚到反向也不能再用。所有保留/抑制保留有向来源。此规则承认双向相关，不声称时间窗内两次独立；真实相关时间长于该窗时仍可能过度自信，需现场独立确认。

## 解释与失败条件

候选是工程机制验证，不是已经确立的算法创新，也不等于 NLOS 识别。健康判别依赖独立墙几何而非真值；墙也被污染、两车都弱、时钟映射不对、故障在门限内或健康车被误判时可能失败。隔离可能损失正常 peer 信息和弱车长期收益。必须完整报告所有场景和配对种子，不能只挑最优实例。实包精度结论继续 BLOCKED。
