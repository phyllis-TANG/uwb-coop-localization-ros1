# 首轮结论与模型差异

D0/D1的24组预登记合成运行与独立回读全部完成。本轮建立了20秒联合固定窗口最小模型；
没有加入IMU、PR61质量策略或新的peer质量筛选，没有把旧全历史图改名当固定窗口。

共同有效61时刻、3个seed的**逐seed RMSE算术均值**如下（不是置信区间，也不是合并样本RMSE）：

| 场景 | D0 Car1/Car2 XY RMSE m | D1 Car1/Car2 XY RMSE m |
|---|---|---|
| 正常 | .02060 / .01893 | .01962 / .01867 |
| peer +1.2m | .02060 / .01893 | .06949 / .08796 |
| Car1单墙链 +1.2m | .07081 / .01893 | .06941 / .01998 |
| peer缺测恢复 | .02060 / .01893 | .01985 / .01889 |

正常位置收益不到毫米量级的均值变化，个别车/seed及yaw会退化，不能写统一“提升”。peer偏差场景中，
Car2在故障窗相对同seed正常的RMSE增量为 .1379–.1575m，恢复38–48s仍残留 .0494–.0740m；
同期图保留了恢复后较晚的改善/恶化。Car1墙链偏差在D1对Car2影响较小且符号随时间/seed变化，
恢复窗Car2相对正常增量为 −.0003–+.0064m。拟合peer残差下降不参与准确性论证。

| 对比 | 本轮行为 | 影响/来源 |
|---|---|---|
| 单车F0 → D0 | 同一图中每帧两份SE(2)，各自固定天线杆臂/高度；无车间因子 | 目标可分离；联合停止准则有<1e-5数值差，失败/缺Odom按共同输出处理 |
| D0 → D1 | 只加固定Car1→Car2的3D天线斜距 | 同输入、初值、墙/Odom、权重、聚合和截止；反向只诊断，raw不计入 |
| 先验 | 联合6×6 square-root矩阵及仿射offset，保留交叉项 | 不回喂另一车点估计；缺peer不清掉过去已形成的相关先验 |
| 旧two_car_offline_graph | 只作历史参照，不作因果基线运行 | 旧图全历史/接收时间关联/双向中位合一政策不同 |
| IMU | 保留诊断事件/后续扩展位置，首轮不加因子 | 后续须新登记消融，不混入D0/D1 |
| 几何/修正 | 合成采用显式synthetic_design安装数值、零偏差 | 不据此验收历史外参，不迁移Car2 P1，不解决后来的符号争议 |
| 时序/计时 | F0等待和截止；统一common网格；virtual队列仅联合处理耗时 | 整流大缺口限制、前端/I/O耗时范围见VALIDATION |
