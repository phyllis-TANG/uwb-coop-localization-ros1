# UWB实验原始数据与备注归档

本目录包含74份实车bag与2份仿真bag。源文件原样复制，原文件名、旧备注及更正前记录保留。GitHub为公开仓库。

## 使用索引

- `catalog.csv`：逐包用途、实验状态、人工参考、限制、存储路径及SHA-256。
- `catalog.json`：完整历史证据和本次副本校验信息。
- `YYYYMMDD/bags/`：实车原始bag。`notes/`为原始记录，`metadata/`为已有检查与校验表，`supporting_sources/`为附属源码。
- `simulations/`：仿真文件，与实车分开。
- `provenance/user_confirmations_20261020.md`：用户后续确认与更正，不改写旧备注。
- `provenance/source_files.csv`：原文件及备份成员的所有来源，包括内容相同的副本。
- `SHA256SUMS.txt`：本目录全部文件的校验值（校验表自身除外）。可在目录内运行 `sha256sum -c SHA256SUMS.txt`。

## 可用性边界

文件完整可读、实验按计划完成、人工参考完整和定位质量是四件事，不能只用一个“成功/失败”概括。低电量中止、启动停滞等失败包仍保留，供故障诊断。没有人工坐标的手推包只能作过程分析，不能作绝对轨迹精度样本。

本次只做文件复制、SHA-256和bag格式头检查，没有重新逐消息解码，也没有运行实车、仿真或定位算法。此前已逐消息读取的52份与其余文件分别注明，未知值不按文件名补造。
