# 有限单因素合成敏感性检查

只用PR46的 `noisy_nominal` 合成场景、12s、原固定种子7/19/43/91/137；每种子仅生成一次观测，再用于7种配置（原配置、时钟±20ms、杆臂X±5cm、初始yaw±5°），合计35次。参数路径和步长在[sensitivity_protocol.json](sensitivity_protocol.json)预先登记。**这些是人为检查步长，不是任何真实标定误差范围。**

改变的是Car2单个配置叶子：UWB header→master偏移、base→antenna水平X、初始body yaw。初始base XY保持不变，不作补偿拟合；杆臂/yaw变化引起的天线位置变化是模型的确定性结果。所有噪声、原始观测、接收顺序、权重和已有时间门槛均相同。逐种子观测SHA一致性、单叶变化、Car1独立解隔离、时钟/杆臂扰动时Odom-only不变的检查均通过。没有开发可靠性策略，没有现场输入或留出定位评价。

下表为**joint相对同种子原配置的XY变化RMS**，取5种子的最小/最大，单位mm；它不是现场定位误差，也不是对真实数据的可接受误差阈值。比较只在相同状态时间与双方有效发布行上进行；完整生成真值指标、状态和计数见[结果JSON](results/sensitivity_summary.json)。

+20ms的Car2 UWB映射令其名义测量时刻超过该合成场景的接收时刻（原生成延迟12ms），每种子触发600条已有的future-time拒绝。因而该行包含**观测可用性改变**，不能解读成平滑的20ms误差传递系数。−20ms没有触发同一拒绝，但改变了测距所对应的运动状态。两者均不支持从实包receive-header中位数选固定修正。

水平杆臂误差直接改变旋转后的天线位置，转向段的影响随body yaw变化；初始yaw改变全程odom到room的传播方向，也改变杆臂投影。当前测试在固定base初始XY下定义这两个单因素，不把它包装成固定天线初值的另一种试验。结果仅说明模型依赖，不能给出现场精度、机制收益或标定建议区间。所有原配置和两侧扰动都保留，没有挑最优种子/条件。
